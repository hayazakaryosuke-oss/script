# 本読み準備　『ノンスリーパー』第24稿（改訂26）

## 目的
AIの審査では分からない3点を、人の声と耳で確かめる。
1. 長さ：実際に何分か（脚本冒頭の「約75分」は推定）
2. 伝わり方：第12条・開講日の例外・証人の規則が、初見の人に一度で通るか
3. 泣きどころ：40の最後の5分で、何人が「分かった」より先に「来た」と感じるか

## 配役（最少8人で回せる）

| 読み手 | 役 | 台詞の量（台詞の数） |
|---|---|---|
| 1 | カイ | 多い（40） |
| 2 | 教官 | いちばん多い（85） |
| 3 | 真壁 | 中（25） |
| 4 | 蓮見／担当者 | 中＋中（30＋17）※蓮見は23で退場、担当者は3・37・39・40 |

- **カイと教官とハルの3人だけは兼役にしない。** この3人の声の距離が、作品の芯だから。

## 進め方（約2時間半）

| 時間 | 内容 |
|---|---|
| 0:00 | 趣旨説明（5分）。規則の説明はしない。初見で読んでもらう |
| 0:05 | 通し読み（第1幕〜第2幕前半、1〜20）。ストップウォッチで計る |
| 0:40 | 休憩（10分）。この時点で下の「質問A」だけ書いてもらう |
| 0:50 | 通し読み（第2幕後半〜第3幕、21〜40） |
| 1:40 | 質問B・Cを書いてもらう（10分）。話し合いの前に書かせる |
| 1:50 | 話し合い（40分）。作者は反論しない。メモだけ取る |

- 40の砂の20分は、ト書きの読み手が**実際に1分黙る**。長回しの体感を、ここだけで測る。
- 読み手のほかに、**脚本を読んでいない聞き手を2〜3人**入れる。いちばん大事なのは、この人たちの答え。

## 質問シート（紙で配る。名前は書かなくてよい）

**質問A（休憩時）**
1. ここまでで、いちばん先が気になった場面はどこですか。
2. 「砂時計を返した人が証人」という規則を、自分の言葉で説明してください。
3. 真壁は、何をしに来た人だと思いますか。

**質問B（読み終わった直後）**
1. 40でカイが眠ったとき、それは「負け」でしたか、「作戦」でしたか。いつ気づきましたか。
2. ハルは最後に、何を手に入れて、何を捨てましたか。
3. カイの胸に置かれた封筒の中身は、何だと思いましたか。
4. 途中で「今のはどういうこと？」と止まった場面を、いくつでも書いてください。

**質問C（全体）**
1. いちばん心が動いた場面を一つ。
2. 友だちに一言で勧めるなら、なんと言いますか。
3. 長いと感じた場面を一つ。
4. 教官はどんな人だと思いましたか（35の「母が、朝の五時に」の一行をどう受け取ったか）。

## 当日、作者が見ておくところ
- **37の署名：** 聞き手の顔が、紙を「読む」顔か、カイを「見る」顔か。
- **40の電子音三つ：** 誰のアラームだと思ったか（質問B-2と照らし合わせる）。
- **最後の「寝息が、二つ」の後：** 誰が最初に声を出すか。沈黙が何秒続くか。

## 結果の使い方
- 質問A-2と質問B-1に答えられない人が半数を超えたら、5・28・37の規則の置き方を直す。
- 質問B-4で同じ場面が3人以上から挙がったら、その場面を直す。
- それ以外の「好み」の意見は、次の稿では直さない。
