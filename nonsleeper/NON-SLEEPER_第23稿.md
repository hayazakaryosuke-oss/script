# ノンスリーパー ／ NON-SLEEPER
（旧題『ドント・スリープ』。2026-09-17に改題）
脚本 第23稿（通し）　結末改訂：カイが開講日に眠る　2026-09-24　約75分（本読みで実測）
原案・脚本：早坂亮輔

凡例：〔色〕〔音〕その場面で初めて出る色と音／教官（声）＝スピーカーからの声／「――」＝時間の省略

## 人物（名前はすべて仮）
- カイ（28）　昼は倉庫の派遣、夜は軽バンで配達
- 教官（50代）　NON-SLEEPER PROGRAM の教官
- 真壁（44）　女性経営者。契約書を全部読む
- 奥田（38）　勤務医
- 蓮見（26）　二世。父は上場企業の会長
- レオ（24）　ホスト。生まれつき、ほとんど眠らない
- ユウキ（22）　YouTuber
- 近藤（48）　中小メーカーの社長。一括払い。大友と事実婚の夫婦
- 大友（52）　飲食店の経営者。女性。ローン払い。近藤と事実婚の夫婦（籍は入れていない。店も財布も別）
- ハル（20）　カイの弟
- 担当者（30代）　プログラムの営業
- 卒業生1（30代）　動画の中だけ
- 第40期の男（30代）　前期の脱落者

撮影メモ
- 白い部屋・前室・応接室は、すべて白ホリの飾り替えで撮る。外は「アパートの駐車場の軽バン」（2・一晩）と「施設の扉の外の駐車場」（38・夕方）の2か所
- 白い部屋の椅子は、扉の側を開けた馬蹄形に並べる。カメラは開いた側から撮る。**偽の窓の壁＝閉じた側（教官の立つ壁）**。9で受講生が見るのはこの壁、19の橙はこの側の天井から受講生の顔へ差す、34でカメラが初めて回るのはこの側から
- 部屋の光は、天井からの影のない柔らかい光だけ。影の縁が立つ光は、40の外の朝日だけに使う
- 床は白い塩ビシート張り（水・汗・血の跡を積み重ねるため）。S1〜S10は順撮り。39の塗り直しは撮影最終日に本当に行う
- 扉のある4枚目の壁は平台1枚で建てる。トイレ・教官室・廊下は、38の施設ロケ地で1日と1晩にまとめる
- 契約書・封筒のオレンジと、19の偽の夕焼けの橙フィルターは、同じ色の値に合わせる（時は金なり）
