# 第4周（素材の作り直し）の共通ルール

第3周の審査（最低7.1／平均7.8）で残った問題：
1. シーン18：気持ちと動機を台詞で言い切る（2周連続）。削ると「した」が通じなくなる。→ 台詞でなく物と動作で暴露する形に作り直す。
2. 中盤のカレンダー仕掛け（招待・削除・承諾・保留中）が細かく、追うだけで疲れる。→ 下の「5つの拍」だけにする。
3. 後半の回収が整いすぎて答え合わせに見える（19の「妻」、22の水サーバーの拍手、23の「折り返して」、24のきれいな結び）。
4. 野々村の恋の筋が本筋と結ばれず飾りに見える（20）。
5. 「戻ってきて」「戻らない」が予想できる（22）。
6. 長い静かな場面で取りに行くものがない（16の後半、11の寝る場面、23の図案）。
7. シーン02の「写真をまとめる／予約を一つに／お金払うから二時間」が、誰が誰にいくら払うのか分からない。

## カレンダー仕掛け：残す5つの拍（これ以外の「削除」「承諾を押す押さない」「保留中」「通知」の画面描写は削る。「通院 n/10」の招待を送る一言は軽く残してよい）
- 拍1（シーン01）：ナオが「来られなかったら、ボタン押して。向こうに通知いくから」と言う。ハルは承諾。
- 拍2（シーン13）：ナオが「通院 7/10」を送ってしまう。ハルが4月をなぞって指が止まる。ナオは出口の外で削除しようとして、「通知が送信されます」で親指が止まる。
- 拍3（シーン17）：ハルの車内。「通院 7/10」を消さず、返信もしない。
- 拍4（シーン18）：ハルが無言で自分のスマホの画面をナオに向ける。「通院 7/10」「8/10」…未返信のまま並んでいる。これが暴露。
- 拍5（シーン21）：ナオが送った「通院 10/10」にハルが「承諾しました」。
上の他の場面にある招待の細かい描写（承諾の押す押さない、保留中を見る、削除に指が止まる、日付を動かす、など）は、切るか、「招待を送る」だけにする。
