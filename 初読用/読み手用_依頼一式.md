# 読み手用　依頼一式『なぜ彼女は飛車を食べた？』

このファイルの文面だけを、読み手に送ります。あらすじと受け取り方は、別ファイル（社内用）です。

| 順番 | 送るもの | タイミング |
|---|---|---|
| 1 | 依頼メール（A）＋ ログライン | 最初に |
| 2 | PDF送付メール（B）＋ `nazekanojo_2026-09.pdf` | 引き受けてもらえたら |
| 3 | 質問メール（C） | 「読み終わった」と連絡が来たら |
| 4 | お礼メール（D） | 感想が届いたら |

---

## ログライン（依頼メールの下に貼る）

> 将棋のタイトル戦、最後の一局。相手の反則に気づいた女性の指し手は、それを口にする代わりに、相手の駒をつまんで飲み込んだ。
> 二年後、彼女は、これまで男性しかなったことのない「棋士」になるための試験に挑む。試験の相手に選んだのは、あの夜の対局相手だった。

## A. 依頼メール

件名：脚本を一本、読んでいただけませんか（早坂）

```
〇〇様

お世話になっております。
早坂です。

突然のご相談で恐縮です。
長編の脚本を一本書き上げまして、
〇〇さんに、最初の読み手になっていただけないかと思い、ご連絡しました。

『なぜ彼女は飛車を食べた？』という、将棋の世界の話です。
タイトル戦で相手の反則を見た女流棋士が、それを言う代わりに、
相手の駒を飲み込んでしまうところから始まります。
将棋を知らなくても読めるように書いています。

PDFで29ページ、上映時間にして90分前後の想定です。
まだ直すつもりの稿で、企画としてお持ち込みするものではありません。
読み終えたあとに
「どこで引き込まれたか」「どこで止まったか」を
短く教えていただけたら、それで十分です。
直し方のご提案まではいただかなくて大丈夫です。
ささやかですが、お礼をさせてください。

お引き受けいただけるようでしたら、PDFをお送りします。
〇月〇日（〇）ごろまでにいただけると助かりますが、
難しければ遠慮なくお断りください。

よろしくお願いいたします。

早坂亮輔
FILMOQ
```

**将棋を知らない一般の方に送るときだけ**、「将棋を知らなくても読めるように書いています。」の次に、この3行を足します。あわせて「まだ直すつもりの稿で、企画としてお持ち込みするものではありません。」の行を「まだ直していく途中の原稿です。」に差し替えます。

```
脚本を読むのが初めてでも、小説のように上から読んでいただければ大丈夫です。
読むのに1時間半ほどかかると思います。
映画を観るつもりで、気楽に読んでいただけたらうれしいです。
```

## B. PDF送付メール

件名：Re: 脚本を一本、読んでいただけませんか（早坂）

```
〇〇様

お世話になっております。
早坂です。

お引き受けいただき、ありがとうございます。
脚本のPDFをお送りします。

読みながら、止まったところがあれば
ページ数だけメモしておいていただけると助かります。
理由はあとで思い出せなくても大丈夫です。

まだ外に出していない原稿のため、
お手元だけでお読みいただけますと幸いです。
読み終わりましたら、ひとことご連絡ください。
短い質問をいくつかお送りします。

よろしくお願いいたします。
```

## C. 質問メール

件名：Re: 脚本を一本、読んでいただけませんか（早坂）

```
〇〇様

お世話になっております。
早坂です。

読んでいただき、ありがとうございました。
2と3だけお答えいただければ十分です。ほかは、答えやすいものがあればで構いません。
褒めていただくより、止まった場所を教えていただけるほうが助かります。

1. 読み終えて、最初に浮かんだことをひとことで。
2. 一番引き込まれたのはどこですか（ページ数か場面の中身で）。
3. 読むのが止まったのはどこですか（飽きた／分からなくなった／引っかかった、どれでも）。メモがあればそのまま。
4. ヒナが駒を飲み込んだ理由を、ご自分の言葉でひとことで（正解はありません。感じたままで）。
5. 最後の場面で、ヒナに何が起きたと受け取りましたか。「……き」「……し、です」を読んだときの気持ちも、あわせて教えてください。
6. 一番印象に残った人物は誰ですか。
7. 行動の理由が分からなかった人物はいましたか。いれば誰の、どの場面ですか。
8. この映画が公開されたら、どうしますか。
   （公開してすぐ劇場で／評判を聞いてから劇場で／配信になったら／たぶん観ない）
9. 将棋のことで、分からなくて困ったところはありましたか。
10. ほかに、何でも。

よろしくお願いいたします。
```

```

お世話になっております。
早坂です。

ご感想、ありがとうございました。
〇ページのご指摘は、自分では見えていなかったところでした。
ささやかですが、お礼を別便でお送りしました。
直した稿ができましたら、改めてご報告させてください。

よろしくお願いいたします。
```

（「〇ページのご指摘」は、実際にもらった指摘に差し替える。定型のまま送らない）
