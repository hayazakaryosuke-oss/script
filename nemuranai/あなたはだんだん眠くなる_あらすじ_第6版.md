# あなたはだんだん眠くなる
あらすじ　第6版（原点回帰／乗っ取りはリバーサルとして）

---

## ログライン

（物語）
恋人が眠らなくなった理由を知るために、インチキ催眠術師は眠るのをやめた。
そして「あなたは、だんだん、眠くなる」が、本当になる。

（フック）
インチキ催眠術師が、眠らないことを売る男の王国を、眠りで乗っ取る。

---

## 主人公

倉田修（31）。インチキ催眠術師。芸名「ドクター・スリープ倉田」。
夜は温泉旅館の宴会や商店街の祭りで、日当五千円のサクラを使った催眠ショー。
昼は家具店のマットレス売り場で実演のアルバイト。売り文句は「あなたは、だんだん、眠くなる」。
それはマットレスの謳い文句だった。
客より先に、自分が三秒で眠る。このマットレスはよく眠れるから、よく売れた。
住まいは東京の九平米。ロフトから天井まで五十センチ。顔の真上に、雨漏りの染み。

## 一　眠れる男（九平米・4:3・笑い）

三年前、僕が眠っている間に、ミオは消えた。
ミオが消えている間も、僕は寝た。眠っている間はミオを忘れられたが、ときどき夢を見た。

ある晩、ミオが帰ってくる。眠らなくなって。
眠らない男を連れて。睡眠の先生、真壁。ノンスリーパー・プログラム。
二人がどういう関係なのか、わからない。ミオは、彼のおかげで眠らなくなったのだという。
「お試しは、二晩でございます。お宅に伺いまして、夜を見守らせていただく」
九平米に三人。真壁は、はしごの三段目に正座する。

夜が来るたび、眠ってしまうのは僕だけだった。
朝になると、卵が減っている。隣の枕に、くぼみがある。
「僕が眠っている間、君は何をしていたの？」
ミオは答えない。工場で梅干しを入れていた夜の話をする。指をなめていた、しょっぱいの、と。

僕は気になって、眠れなくなっていく。
自分に言う。「あなたは、だんだん、目が冴える」。三秒で眠る。
スマホで録画する。映っていたのは、目を開けて歩く僕と、レンズに近づいてくる真壁の顔。

真実の片鱗。毎晩三時四分、ミオは懐中電灯を持って出ていく。
次の夜こそ、ついていく。そう決めた日、僕は売り場のマットレスで、客の横で、眠ってしまう。
目が覚めると、ミオは消えていた。川べりに、白いスニーカーがそろえて置いてあった。

## ミッドポイント　向こう側へ

「お会いになりたいのでしたら、こちら側にいらしていただくほか、ございません」
僕は、ノンスリーパー・プログラムに申し込む。298,000円、36回払い。
駅に直結したビルの最上階。エレベーターの扉が開くと、画面が横に開く。白い部屋。
署名する僕の後ろ、鏡の向こうに、ミオが立っている。（観客だけが知っている）

## 二　眠らない部屋（白・シネスコ）

ルールは一つ。「寝たら、負け」。「眠ったかどうかは、見ていた人が決めます」。
深夜の瞑想の時間。受講生たちは半眼で座り、浅く眠り、クリッカーで戻されて、「起きてました」と答える。
僕の湯のみだけ、中身がスーパーの二百円のほうじ茶になっている。誰が淹れているのか、僕は知らない。

日に日に眠れない。むしろ冴えていく。
十年、サクラの顔色を読んで食べてきた目が、本物になっていく。
配信者の受講生の耳もとで、いつもの台詞を言う。彼が、本当に眠る。いびきが配信に乗る。「今の誰の声？」
あなたは、だんだん、眠くなる。それが、本当になりはじめる。

真壁は眠らない男だ。
夜、座ったまま首が落ち、自分で「……起きております」とつぶやく。
給湯室でほうじ茶の袋の匂いを嗅いで、目を閉じる。子守唄を、いつも同じところで間違える。
眠っているサクラを見て、ひとこと。「……いいなあ」。

ミオとは、自販機の前で一度だけ話す。
「熱、出ればいいのにって。毎晩」
明け方、ミオは一人で非常階段にいる。三年前の宴会の録音を、何度も巻き戻して聞く。眠れない。梅のおにぎりを食べて、指をなめる。
給湯室で、ミオは言う。「……起きてて」。

真壁は、宣伝のために生配信を仕掛ける。
三秒で眠っていた男と、眠らない男。「先に寝たほうが、負け」。

## 三　一つの大きな事件（生配信の夜）

七十二時間目。世界中が見ている。
決め台詞は効かない。真壁は「存じております」と返す。
僕は、九平米の天井の染みの話をする。大きいのと、小さいのと、爪の先ほどの。数えても、数えても、朝にならない夜のこと。
そして、十年一度も言ったことのない言葉を言う。「……眠って、いいですよ」
眠らない男が、世界の前で眠る。

眠った真壁の口と鼻に、僕の手がかぶさる。数えている。自分でも、何を数えているのかわからないまま。
ミオのカメラは、真壁の鼻の上で画を切っている。配信には、穏やかな閉じた目だけが映る。
三十二で、手が止まる。ミオが、カメラを下ろして、自分の目で僕を見ていたからだ。

## 反転　乗っ取り

翌朝、受講生たちは、眠っている真壁ではなく、僕を見る。
眠らないことを売っていた王国が、眠らせることのできる男の手に、落ちてくる。僕は何も奪っていない。取りに来たのは、ミオだけだった。

真壁は、配信の録画で、はじめて自分の寝顔を見る。「……よく、寝てたな」
十一年、眠っていないはずだった男は、本当は毎晩少しずつ眠っていた。知らなかったのは本人だけだった。

そして観客は知る。全部、ミオの筋書きだった。
三年前の九月十四日。熱で眠れなかった僕の寝言の台詞で、ミオは生まれて初めて本当に眠った。三時四分。
熱が下がると、僕はまた三秒で眠る男に戻り、声は二度と効かなかった。
眠れない自分が眠るには、僕が眠れなくなるしかない。眠らない男を眠らせられるのも、眠れなくなった僕の声だけ。
ミオは僕を眠れなくするために、真壁を連れて戻ってきた。靴も、ほうじ茶も、ミオだった。

僕は、王国を乗っ取ったつもりで、乗っ取られていた。眠りを。

## 結末　今度は、僕が見る

三時四分。白い部屋。椅子の代わりに、ベッドが並んでいる。眠れなかった人たちが眠っている。その中に、真壁もいる。
僕は、真壁の椅子に座る。ベッドの列を見下ろせる椅子。
新しい客の枕もとで、僕は言う。「あなたは、だんだん、眠くなる」。王国の口上。

どこか、僕の知らない狭い部屋（4:3）。
ミオが、イヤホンで、あの夜の配信の録画を聞いている。「……眠って、いいですよ」
ミオは眠る。誰にも見られずに。

スマホに、ミオから。「起きてる？」
僕は、起きている。
目は、閉じない。

## 第6版で決めたこと

| 項目 | 形 |
|---|---|
| 物語の芯 | 嫉妬と謎（「僕が眠っている間、君は何をしていたの？」）→ 眠れなくなって覚醒する → 売り文句が本当になる |
| 主人公 | リアルなインチキ催眠術師（サクラの余興）＋昼はマットレスの実演。題名の台詞は売り文句 |
| 消したもの | 作戦・進行表・チームの潜入・配信の取引・賭けの条件・書類の手続き |
| 一つの大きな事件 | 生配信の夜、眠らない男が世界の前で眠る。そして32秒の手 |
| 乗っ取り | 筋ではなくリバーサル。望まないまま王国が落ちてくる。そして、乗っ取ったつもりで乗っ取られていた（眠りを）。全部ミオの筋書き |
| 答え（ゴーン・ガール的反転） | 彼女は、僕の寝顔を見ていた。僕の声でしか眠れなかった。僕の眠りを取りに来た |
| 結末 | 僕は真壁の椅子で、他人の寝顔を見る側に。ミオは誰にも見られずに眠る。「起きてる？」 |
| 画 | 九平米は4:3、白い部屋はシネスコ。色と光（ネオン、カラーバー、唯一のゴースト）。寝顔を見る主題 |
| 残した発見 | 九平米と天井の染み／非常階段のミオ／「眠って、いいですよ」／真壁の逆説性不眠と丁寧語が外れる六つ／「……いいなあ」／「起きてて」 |

## 決めてほしいこと

1. サクラの男（平野）の出番。今回は第一部の余興と、白い部屋で眠る一画だけに小さくしている。チームとしての潜入は消した。
2. 配信者（ハヤト）は「初めて効く相手」としてだけ残した。取引は消した。
3. 語り。原点の文章は「僕」の一人称。脚本はモノローグなしのまま（あらすじだけ「僕」で書いた）。
