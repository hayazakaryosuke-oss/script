# あなたはだんだん眠くなる
英題案：Are You Awake?

脚本 第109稿（実家版・倉田の手、ミオの選択）　2026-09-26　約95分想定
原案・脚本・監督：早坂亮輔　／　FILMOQ

ログライン
どこでも3秒で眠れるマットレス売りの男の実家に、3年前に出ていった恋人が、眠らない男を連れて泊まりに来る。施設にいる母が一時帰宅する日曜の朝まで。「お試しは、三晩」のはずだった。「この家では、誰も寝ません。……君以外はね」。眠るたびに、家が少しずつ、あの男のものになっていく。――第二部、同じ三晩を、彼女の側から見る。夜勤で男の母の息を数え、眠らない身体が欲しかった女の話。

方針（第92稿から）
- 筋は、誰にでも分かるように全部答える。意味は、画に任せて観客に委ねる
- 人物の心は、台詞で説明しない。物と行動で見せる
- 会話は、すれ違いで転がす。短く、口語で、少しずれる。心の声（モノローグ）は使わない
- 小物と反復で笑わせ、泣かせる（卵、目覚まし三つ、黄色いマグ、植木鉢の鍵、「寝てない／寝てた」、夜の「おはよう」、お試し三晩のルール）
- 前半は笑える。倉田の「3秒で眠る」体質は、前半は笑いに、後半は怖さになる
- 倉田は、眠らないことで覚醒していく。見えていなかった音、色、光、人の夜が、見えてくる。その力で、最後に真壁を眠らせる。代わりに、倉田はもう眠れない

構成
- 第一部「眠る男」（土曜の夕方、倉田が自分の家から締め出されるまで）：倉田の目で見る。倉田が知らないことは、見せない（例外は、眠っている倉田の枕もと＝1・5だけ）。期限は、母が一時帰宅する日曜の朝10時。月曜の夜に二人が来る。月・火・水が「お試し三晩」。木曜の朝、真壁は帰らない（21）。木曜の夜が卒業の夜。土曜の夜が最後の夜
- 第二部「眠らない彼女」：3年前にさかのぼり、ミオの目で、土曜の夜の艇庫まで。第一部で見せた場面は見せ直さない。倉田が見ていなかった時間だけでできている。第一部の謎（枕のくぼみ、録画の影、天井のシール）は、ここで数秒の画で答える。ミオが言えなかったことは、言わせない
- 第三部「あなたはだんだん眠くなる」：土曜の深夜。母の部屋の倉田と、鉄橋を走るミオを、交互に切り返し、午前3時に一つの家で合流させる。そのあと日曜の朝10時の期限まで

日付と時間（倉田の覚醒時間は、木曜の朝7時から数える）
- 先週：2〜4（再会）、5（その夜）。1は5の午前3時の通知を先に見せたもの。36（同じ夜の午前3時を、ミオの側から）
- 月曜の夜：6・7（一晩目）／火曜：8〜11（二晩目）／水曜：12〜19（三晩目。店は定休日）
- 木曜：20〜22（お試し終わり。真壁は帰らない）／木曜の夜〜金曜の夜明け：23〜25（卒業の夜。倉田は眠れない）
- 金曜：26（覚醒29時間）〜30（41時間）／土曜：31（午前3時の土手）・32・33（58時間）・41（最後の夜）
- 日曜：47（午前3時）・51（朝10時、覚醒75時間）
- 10月11日：52

凡例
- 【暗転】＝本当の眠り。第一部では倉田の眠り。画が先に消え、音は一拍遅れて消える。第二部でミオが初めて本当に眠るとき（40）、同じ黒を使う
- 白＝夜のお茶の眠り。飲んだ者は眠るが、本人は「寝ていない」と思っている。画が白く飛び、音が遠くなる。目は開いたまま動くこともある。第一部では一度だけ倉田に使う（19。真壁がコーヒーに葉を入れた夜）。ほかは第二部のミオ
- 〔定点〕＝倉田の部屋（二階）の、毎朝の同じ画。ベッドの足もとから、押し入れと窓と天井の一部が入る構図。三晩とも同じレンズ、同じ高さで撮る。観客が「どこが変わったか」を探せるように、変化は一つずつ
- 〔とぶ〕＝倉田が失った時間。1カットに見えるように繋ぐが、何かが変わっている。受講後（22以降）にだけ使う。「――」はふつうの場面転換
- 〔冴え1〜4〕＝倉田の覚醒の段階。眠れないことで、見えていなかったものが見えてくる。冴え1＝遠い音が聞こえる（冷蔵庫、土手の自転車、最後は鉄橋を走る裸足）、冴え2＝色が濃くなりピントが奥まで合う（天井の木目、母の字）、冴え3＝レンズのゴースト（光の輪）が倉田にだけ「物」として見える、冴え4＝夜が昼のように見える。代償：まぶたの痙攣→鼻血と手の震え
- 〔色〕〔音〕＝その場面で初めて出る色と音
- （声）＝画面の外の声

色の設計
- 黒＝本当の眠り
- 白＝夜のお茶の眠り（ミオ）
- 青＝スマホの光と、夜明け前の川
- オレンジ＝真壁が持ちこんだ古い電気ストーブ。倉田の家に、それまでなかった色
- 緑＝老人ホームの夜の廊下の誘導灯（31・35）と、倉田にだけ見える光の輪（冴え3）
- 白い円／白い線＝押し入れの懐中電灯。倉田の眠りの合図。夜勤のミオが、眠る人の胸に落とす光。第二部では、眠るミオの顔を横切る一本の線（40）と、川の向こうでミオを呼ぶ一点（44）
- カラーバー＝最後の場面だけ。ミオが置いていった古いビデオカメラの出力。この映画に一度ずつ出てきた色が、一枚にそろう
- フレア＝朝日の光の輪。12と49の2回だけ。どちらも倉田の部屋（二階）の窓ガラス。12は倉田が内側から見る。49はミオが鉄橋の上から見る。窓が燃えるように光り、倉田の影が光に消える

撮影メモ
- 倉田の実家：川の土手の下に建つ、古い木造二階建て。一階に、居間、台所、仏間（柱時計と仏壇）、母の部屋。二階に、倉田の部屋と、隣の小部屋。階段は急で、踏むと鳴る。玄関はガラスの引き戸。居間の縁側のガラス戸が庭に面している。倉田の部屋の窓は東向きで、土手の向こうに川と鉄橋が見える。倉田の部屋の天井は古い細い板張り。押し入れが一つ
- 家の支配は、三段で見せる。一晩目＝時計（柱時計の振り子が止まる）、二晩目〜水曜＝母の部屋（真壁が入り、水曜に鍵がかかる）、三晩目＝家族（写真が伏せられ、仏壇の灯りが消える）、土曜＝家（植木鉢の鍵が消え、倉田が締め出される）。51で、倉田が一つずつ元に戻す
- 倉田の部屋の〔定点〕は、セットで組むと三晩の変化を管理しやすい。家の外観・庭・土手・川はロケ
- 川：流れのゆるい一級河川の河川敷。浅瀬、鉄橋（人の歩ける側道つき）、対岸にボート部の古い艇庫。水の場面は、12（夜明けの浅瀬に、ミオが立つだけ）、24（家の浴槽）、第二部の夜明けの浅瀬だけ。すべて安全要員を置く。沈む寄りは吹替
- 35（3年前）は、押し入れのすき間の白い光と、それが届くぎりぎりのところで開いているミオの目から始める
- 12と49のフレアは、同じ窓で、内と外から撮る（物語では別の朝。撮影は同じ朝にまとめる）。49は鉄橋の側道から窓を見上げる長回し。予備日2日
- 40：艇庫の板のすき間から、33で倉田が石の上に置いた懐中電灯の光が、眠れずにいたミオの顔を一本の線で横切り、ミオはその光で眠る。33と40は同じ夜、同じ光。33の本番で、艇庫の内側にもカメラを置いて同時に撮る
- 43・45・47は、懐中電灯をつけてからミオが階段を上がるまでの、母の部屋の長回しを一本撮り、三つに切って使う。42・44（鉄橋を走るミオ）と交互に切り返し、46で庭から母の部屋の窓越しに、ミオの肩越しに同じ芝居を撮る。45では、倉田の数と、遠い鉄橋の裸足の音を同じ速さにそろえる
- 52：最後は黒にしない。カラーバーの光の中の、開いたままの倉田の目でクレジットに入る。ミオの実家の場面は、スマホの青い光だけで撮る
- 母の役は、台詞を少なく。認知症の描き方は、介護の監修者と相談して決める
