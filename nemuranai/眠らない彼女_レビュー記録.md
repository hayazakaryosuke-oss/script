## 最終判断（5周）
最低点：7.2 → 7.6 → 7.6 → 7.3 → 7.2。平均：7.3 → 7.7 → 8.0 → 7.9 → 7.7。
脚本家の点は 7.2 → 7.8 → 8.2 → 8.4 → 8.7 と上がり続けた（論理の穴は毎周埋まっている）。
一方、新しく入る審査員が毎回「別の型」で最低点を付ける（『バーニング』→『岸辺の旅』／観客は答えを、作家側は謎を）。
これは改訂で埋まる差ではない。「この映画は、スリラーか、恋愛の挽歌か」を一つに決めない限り、どちらかの審査員が7点台を付け続ける。
