# 脚本チーム体制（ピクサー型）

作成：2026-10-03

## 役割
| 役 | 担当 | 仕事 |
|---|---|---|
| 監督 | 早坂亮輔 | 最終判断。チームの意見に従う義務はない |
| ストーリー責任者 | Claude | 案をまとめて稿にする。各案のどれを取ったか、なぜかを記録する |
| ストーリー・アーティスト（3人） | エージェント | 同じ場面に、違う方向の案を2つずつ出す（脚本の形で） |
| ブレイントラスト（5人） | エージェント | 稿を通読し、率直に「問題」を言う。直し方は決めない |

## 決まり
1. **率直に言う。**遠慮した意見は役に立たない。どこで退屈したか、どこで分からなくなったかを、ページと行で示す。
2. **問題を言い、答えは監督が決める。**ブレイントラストは直し方を命令しない（例を出すのはよい）。
3. **最初の稿は、だめで当然。**だめな所を早く見つけるために回す。
4. **積み上げる（プラッシング）。**他人の案を否定するときは、それより良くする案を一緒に出す。
5. **作者の固定事項は動かさない**（下の一覧）。
6. **採点は脚本として。**紙に書かれたことだけを見る（演技・撮影・音楽・評判は入れない）。基準作（9.5＝『ドライブ・マイ・カー』『万引き家族』『パラサイト』）とも、完成した映画ではなく脚本と比べる。この決まりは、チームに渡す指示文に毎回書き込む。
7. **改稿の前に**『脚本創作ノート_20260930.md』の「6 東京篇の固定事項」「10 改稿の順序・会話のチェック・採用しない短絡」を読む。他作の文体・象徴・場面は写さない（原理だけ借りる）。

## 作者の固定事項
- 中心の反転：35で倉田は、ミオの「やらないで」を越えて彼女を眠らせる。救いや許しにしない
- 結末：倉田は自覚したうえで、もう一度やる（39）。代価として『ごめん』は未読のまま、母の『待ってるからね』が残る。布団屋で倉田だけが眠れずに終わる
- 力：眠らずに三晩ほど過ごすと戻り、眠ると消える。こらえきれずにもれたあくびで、近くの眠い人が眠る（こらえたあくびでは眠らない）。言葉は、狙った相手に直接効く
- 光の輪（明かりのにじみ）＝眠れていない目のしるしであり、力が戻っているしるし
- 色と光の凡例：夜は暗い青／眠らずに迎える朝は白／自分で眠った人の朝は黄から橙／光は画面の中の光源だけ
- 三年の空白は、一度の説明ではなく生活の細部で見せる
- 38の電車の場面は残す。ミオの明確な拒否も残す

## 一周の流れ
1. 監督が課題を出す
2. ストーリー・アーティスト3人が、それぞれ別の方向から案を出す
3. ストーリー責任者が案を積み上げ、一つの稿にする（取らなかった案も記録する）
4. ブレイントラスト5人が通読し、問題を出す
5. 監督が決める → 次の周へ

## 記録
- 各周の課題・案・採用理由・ブレイントラストの指摘は『レビュー記録.md』に追記する
