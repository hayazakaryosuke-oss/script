# 盲検比較（v46）稿X／稿Y

## 1. 点数と勝敗
- 稿X：8.7
- 稿Y：8.2
- 勝ち：稿X（強い勝ち）。場面ごとの宝は稿Yのほうが多い。それでも一本の映画としては、稿Xのほうが欲と代価が一本の線で上がり、結末が一度きりの出来事として来る。

## 2. 決め手
1. **結末が一度きりか**。Xは2の「あそこで天気やるまで」「毎朝。四時半」と、25の「10/29（木）4:30〜　朝枠（新宿駅前の天気の前後）　沢井案」を仕込んでおき、結末で初めて人の前で力を使う。代価は「次の行から、『0』が並びはじめる」「『反応なし』」。Yは36で、同じ店の前の生中継に「記者の声が、途切れる。マイクを持ったまま、膝が折れる」「スタジオの二人の頭が、机へ下りていく」をすでに見せている。結末はほぼ同じ画の二度目になり、驚きが先に使われている。
2. **誰を眠らせ、何を失わせたかが一段ずつ上がる**。Xは芝生（事故）→年配の配達員→ミオ→アベさんの過去問「白い升目が、九つ」→審査→「やらないで」→生中継と進む。一段ごとに、名前のある一人の代価がつく。審査の後には「アベさん「……次、なかった」」があり、同じ場面の終わりに「倉田様。おめでとうございます」が来る。Yは広場で配達員を何人も眠らせる場面（31）と生中継（36）を足し、さらにタクシーで後を追う場面（28）も入れた。そのため、人前で何人も眠らせる場面が結末の前に三つ（31・36・38）あり、上がり方が平らになる。
3. **ミオが離れていくのを、行為一つで見せる**。Xは10で「振り返る。ミオの顔で、目が止まる。／ミオの指が、袖を、離す。」の一動作で済ませる。Yは同じ流れに20・22・23・28・29を使い、43の後始末でも「決めたの、わたし」「消して」「首。横に、一回。それで、よかった」と言葉で言う。Xは「首を、横に一回、振ってみせる」「これで、よかったのに」で止めていて、説明ではなく行為になっている。

## 3. 短い稿Xで失われて惜しいもの／長い稿Yで要らなかったもの
惜しい：
1. Y4 コインランドリーの告白。窓に向かって「付き合ってもらえませんか」「はい」「……窓にですけど」「百円」「三百円も」。恋に落ちる場面と、他人の生活と、笑いが一度に入っている。35の「こっち、濡れてるんで」で裏返る対も惜しい。
2. Y18 「うつったら負け」「泣いてる」「……あくび」「出てないじゃん」と、ミオが倉田のまぶたを指で開けて片目を撮る不正。ミオが倉田と同じ側にいて、規則を破る側にもいることが行為で分かる。20の「ミオは、手首から、自分の手を離す」も惜しい。
3. Y48 粗大ごみの布団。処理券の『倉田』が、隣の『小松』と並ぶ。もう眠らないという決心に、東京の手続きと他人の生活が一つの画でつく。

要らなかった：
1. Y36・37・44 で、生中継で一度目の寝落ちをさせ、切り抜きを広める流れ。固定の結末の画を先に使ってしまう。
2. Y31 広場で配達員を何人も眠らせて笑う場面と、28 のタクシーで並んで走る場面。人前の大きな寝落ちと、尾行が重なっている。
3. Y13の羊と置き配の寝落ち、22の横断歩道と眠りの外来。寝不足の症状を言い直しているだけで、どれも話を先へ進めない。

## 4. 勝った稿Xの残る弱点
1. 恋に落ちる一押しがない。2の「木　夜　ここ」から、3の外階段で午前三時に待つミオまで、二人が決める場面が飛んでいる。出会いもミオの「眠っている親指をつまんで」に頼っていて、偶然のままで、ミオが自分から動く場面がない。
2. 講座の引力と、お金の代価が薄い。ミオが講座に「内緒で」通うのは8から9の一晩だけで、隠す嘘は「会社に、泊まり。三日」の一つ。倉田はその場で受付票を読んでしまう。真壁の台詞は数行で、真壁は筋を進める役にとどまる。「298,000円」「二年」の分割はその後一度も請求として戻らず、お金の代価が消える。
3. 中盤の倉田が、見ているだけの場面を繰り返す。11でノブを回さない、12で窓を見上げる、16でガラスを向かない、24で歩道から見上げる。倉田が自分で選んで動くのは17の前までほとんどない。また「つられたあくびは効かない」という決まり（7「口から、息だけが出る」、23）は、紙の上で一度もはっきり示されていない。観客によっては、不思議な力が都合で効いたり効かなかったりするように見える。
