# 映画賞の脚本部門に投票するベテラン脚本家 第三幕8.5／全体8.7
効いた：台詞の耳（2「一回、一緒に寝ただけです」「別の席です」→8「付き合って九日です」「三日」「煙の日は、数えない」＝向田邦子・山田太一から続く日常の言い直しを二語・三語まで削る）／画面の文字を台詞として（14『この予定のみ』『これ以降のすべての予定』と窓に裏返しの『会話中　寝落ち』、結末『4:38　0』に『4:38〜　反応なし』＝日本映画の脚本ではまだ珍しい技術）／43「首。横に、一回。それで、よかった」→「倉田は、うなずく」（11で二度うなずいた男がまたうなずく＝仲直りを同じ身振りで潰す、行為で笑える）。
①結末で倉田が何を欲してレンズの前に立つのかが紙で決まっていない（見られたいのか、天気が始まる朝を自分だけ起きて迎えたいのか、壊したいのか）。3の「あそこで、天気が始まるまで」も10の「青だった」も第三幕で一度も呼び戻されない＝叶う形はあるが願いが第三幕の紙に戻っていない＝人物の選択でなく作り手の回収に見える。
②43の読み上げが復習の長さ（新しいのは「四十三日」「朝、目の下、十分」と耳栓を外した理由だけ）。「真壁さんとも、寝てたじゃん」に応じないこと自体は行為として成り立つが真壁の件が宙に浮く。
③ト書きの決まり文句（「眉のあいだが、ほどける。唇が、少し、離れる」21・25・38・42、「上がる。下がる。」6・21・25・38・42、「にじんで、輪になる」34以降7回）。設計は正しいが字句が同じなので42のいちばん大事な差（力で眠らされた眉のしわは「一本のまま」、倉田が寝入った四時に初めてほどける）が一語に埋もれる。読点で刻む短文が113分ほぼ同じ速さ＝山場が洗濯の場面と同じ脈で読まれる。
分からない：19の申込書の画面の読み取り／27『す』（二度読んだ）／43「首。横に、一回」は11を覚えていないと分からない／結末『4:38　0』が沢井案の数字だと分かる手がかりは47の一行だけ。
持ち帰るもの：やっと撮れた青の並びを送る相手がいない朝に『起きてる？』と打つ男。ほぼ合う。ただ最後の三十秒に『お母さん：待ってるからね』と黒の「……あなたは」が重なり、帰る場所と余韻を差し出す＝いちばんひどい形で叶った朝を作り手が少し撫でている。
