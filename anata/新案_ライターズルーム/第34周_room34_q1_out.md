## 0　いちばん効く足し（三つ）

1. **結末：止まった手のまま自動ドアが開くのを待ち、手を膝に下ろして「顔を、開いたドアへ向ける」**。あくびに「向き」がつく。勝手に出るあくびは狙わない。症状ではなく選択だと、説明なしに一枚で読める（39で「待たない」男が、ここではドアが開くのだけを待つ。台詞では言わない）。
2. **結末のミオの一枚：ベッドではなく低い机に伏せ、第一幕1の「腕の上の横顔が、こちらを向いている」を、目が開いたまま、後ろに整ったままのベッドを置いて**。「腕に頬をのせて、横向きに伏せる」が一場面に三度並ぶのを避ける。倉田が最初に見た寝顔①を、見る人のいない部屋で、目を開けたまま置く。
3. **40：ミオが見下ろすのは寝顔ではなく「その口」。手のひらは「置かれる」から「置く→体の重さを、かける」へ**。寝顔を見る一拍と、胸の上下を手で感じる一拍（名残り・許しに読める二つ）を消して、43の「開きかけた口に、耳栓」へつなぐ。

## 1　39（原稿cの本文に足す・削る）

### 1-1　光の輪の位置
- どこを：「ミオが、頭を上げる。倉田の目。縁が、赤い。まばたきを、しない。／窓の外の街灯が、倉田の目に、輪になってにじんでいる。」
- どう変える：輪の行をミオの見る行の後ろから外し、倉田が起き上がった直後へ移す。形を結末とそろえる（「にじんで、輪になる」）。

```
　倉田が、起き上がる。
　窓の外の街灯が、倉田の目に、にじんで、輪になる。
　倉田は、人差し指を一本、ミオの目の前に立てる。
```
- なぜ：今の位置だと、ミオが倉田の目の中に輪を見ているように読める（輪は倉田の目にだけ、の決まりとぶつかる）。起き上がった直後に置けば、「力はある」と倉田が知り、それから指を立てる順になる。結末も「輪を確かめる→手を下ろす」の順。二つの夜で、輪の後に倉田が選ぶ。語ではなく、手順がそろう。

### 1-2　耳栓の手を、右に決める
- どこを：「ミオは、片方の耳栓を、指で抜く。手のひらに、握る。」「耳栓を握った手が、抜いた耳を、ふさぐ。」
- どう変える：

```
　ミオは、右の耳栓を、指で抜く。右の手に、握りこむ。
ミオ「……寝ないの」
（中略）
ミオ「やらないで」
　握った右手が、右の耳を、ふさぐ。
```
- なぜ：四時の「右手」と40の「布団の上で、ミオの右手が、軽く握られている」まで、同じ手が一本の線になる。「片方」「手のひら」のままだと、握った手と、ふさぐ手と、一晩握っている手が同じかどうか、読む人が確かめに戻る。

### 1-3　ト書きの主語（握る手に意思を残す）
- どこを：「布団の上で、ミオの右手は、握られたまま。」
- どう変える：「布団の上で、ミオの右手は、握ったまま。」
- なぜ：「握られた」は受け身なので、誰かに握らされた手に読める。眠っても手はミオのもの、を語尾で守る。

### 1-4　まつげの行を削る
- どこを：「倉田が、顔を近づける。まつげの一本一本。崩れない。」
- どう変える：削る（−1行）。「親指と人差し指が、顔の上で、開く。顔は、大きくならない。」の次は「まばたきを、しない。」へ。
- なぜ：三行のうちに、第一幕10の頬杖・71:59の開く指・10bのまつげの四角と、反響が三つ続く。サンダンスの言う「韻の管理」にいちばん聞こえやすい所。残すなら、写真の仕草を本物の顔にする指（狂い）のほう。まつげの行は「本物は写真より良い」という満足に読め、倉田が欲しかったものが手に入ったように見える。

### 1-5　四時の最後の対句をほどく
- どこを：「ミオの眉のあいだが、ほどける。唇が、少し、離れる。／握った手は、ほどけない。／倉田の目は、閉じている。」
- どう変える：

```
　ミオの眉のあいだが、ほどける。唇が、少し、離れる。
　ミオの右手は、握ったまま。
　倉田の目は、閉じている。
```
- なぜ：「ほどける／ほどけない」を並べると、作者が「救いと拒否は両方本当」と言っているように聞こえる（読み手に答えを渡す対句）。動詞をずらせば、同じ一枚に両方が黙って並ぶ。

### 1-6　残すもの（触らない）
- 「眠れるよ」（第二幕30の身勝手な言い換え）・「決めるの、わたし」・「……あのね、修」→「ミオが、息を吸う。」→「倉田は、待たない。」の三行。5人全員が効いたと言った所。輪も手の行も、この三行のあいだには入れない。
- 「眠れるよ」を舞台の丁寧語（「眠れますよ」）にする案は採らない。常体のまま言うから、倉田は本気で彼女のためだと思っている、が残る。そのほうが怖い。

## 2　40（原稿cの本文に足す・削る）

### 2-1　目を覚ます音に、他人の生活の具体を一つ
- どこを：「壁の向こうで、掃除機の音。行って、戻る。」
- どう変える：

```
　壁の向こうで、掃除機。行って、戻る。壁に、ごつん。
　ミオの目が、開く。目の前に、倉田の喉。開いた口。寝息。
```
- なぜ：「ごつん」で目が開く理由がはっきりし、生活の用事の笑いになる。夜に壁越しにいびきの聞こえた隣の人（第二幕32・原稿bの45）が、日曜の二時に掃除をしている。倉田の知らない他人の生活。

### 2-2　寝顔ではなく、口を見る
- どこを：「ミオは、倉田の寝顔を見ている。／ミオの手のひらが、倉田の胸に、置かれる。手の下で、胸が、ふくらむ。しぼむ。／ミオは、手のひらに、体の重さをかける。」
- どう変える：

```
　ミオは、その口を、見下ろしている。
　ミオは、倉田の胸に、手のひらを置く。体の重さを、かける。
　胸が、ふくらまない。
　倉田の喉が、鳴る。目が、開く。
　ミオは、手を離す。目は、倉田の口を見ている。
```
- なぜ：
  - 「寝顔を見ている」一拍と「手の下で、ふくらむ。しぼむ」一拍は、第二幕16・35の休む画をそのまま呼ぶ。救いの後に寝顔を見つめ、胸の上下を手で確かめると、名残りや許しに読める（第33周で2人が40の手のひらに言ったこと）。
  - 見るのを「口」にすると、彼女を眠らせた物（あくび）を見張る目になる。後の「目は、倉田の口を見ている」とつながり、43の「開きかけた口に、耳栓」へ渡る。
  - 「置かれる」（第二幕35の、意思のない手の語）を「置く」に。起こす時刻を決めるのはミオ、が語尾に出る。

### 2-3　頬をこする手から、説明の句を外す
- どこを：「ミオの目が、倉田の胸へ行く。自分の頭の、あった所。／ミオの手の甲が、自分の頬を、こする。胸にのっていた側。／もう一度、こする。」
- どう変える：

```
　ミオの目が、倉田の胸へ行く。
　ミオの手の甲が、頬を、こする。
　もう一度、こする。
```
- なぜ：「自分の頭の、あった所」「胸にのっていた側」は、画が言っていることを字でなぞっている。目が胸へ行き、次の行で頬をこすれば、どの頬かは読める。

### 2-4　最後の行の前に、隣の掃除機をもう一度（足してもよい）
- どこを：「ドアが、閉まる。／隣の枕に、頭の形のくぼみ。スタンドの首で、画面は、暗いまま。」
- どう変える：

```
　ドアが、閉まる。
　壁の向こうで、掃除機が、行って、戻る。
　隣の枕に、頭の形のくぼみ。スタンドの首で、画面は、暗いまま。
```
- なぜ：倉田の顔に拍を置かずに（原稿cの方針）、部屋の外の生活が何も知らずに続く。最後は物で終わる。予備：入れない（−1行。笑いの音が後味を軽くすると監督が見るなら外す）。

### 2-5　台詞（残す・予備）
- 残す：「やらないでって、言った」「……聞こえてた」「聞こえてたのに？」「寝れたじゃん」「寝れたよ。……それで？」「何、してたの」「見てた」「何時まで」「……四時まで」。倉田の台詞は全部常体＝本当のこと（台詞の型どおり）。言い訳で逃げる丁寧語を一度も出さないから、「寝れたじゃん」は本気の言い換えとして刺さる。
- 予備（ミオの口の型＝数字）：「……四時まで」の後に、ミオ「五時間」を一語。見られていた時間を、運用担当の口で数にしてしまう（感情を出さずに引き受ける手）。強くなるが、皮肉の決め台詞に聞こえる恐れがあるので予備。

## 3　45（原稿bの本文に足す・削る）

### 3-1　「にじまない」を外し、落ちかけを寝息にする
- どこを：「窓の外の白い街灯を見ている。にじまない。／顎が、胸へ落ちる。口が、開いていく。／跳ね上がる。」
- どう変える：

```
　窓の外の白い街灯を見ている。
　顎が、胸へ落ちる。寝息が、一つ。
　跳ね上がる。倉田は、手のひらで、自分の顎を押し上げる。
```
- なぜ：
  - 「にじまない」は、41の「車内灯は、にじまない」（裁定：「力がない」を見せるのは41の一回だけ）、結末の頭の「見上げている。にじまない。」と合わせて第三幕で三度目になる。結末の一度は、同じ場面の中の仕込みと回収なので残し、45のは外す。
  - 「口が、開いていく」は39・結末であくびの記号。三晩目の入口で「あくびが来た」と読まれると力の話が濁る。「寝息が、一つ」なら、数分でも眠れば消える＝三晩が水の泡になる危うさが音で立つ（サスペンス）。

### 3-2　深夜枠：41の三行を画面に見せ、45は「その先」を押す
- どこを：「『水　0:00〜4:00』。親指が、『予約する』を押す。／下の行。押す。下の行。押す。下の行。押す。」
- どう変える：

```
　スマホを出す。配達のアプリ。深夜枠の一覧。
　上の三行に、『予約済み』。
　その下の行。親指が、『予約する』を押す。
　下の行。押す。下の行。押す。
　週の表示の、零時から朝までが、一晩ずつ、白い箱で埋まっていく。
```
- なぜ：裁定では41で三晩を全部予約する。45で同じ手をもう一度やると、反復の相手・目的が変わらない（創作ノート10の5）。41は「力を取り戻すため」の三晩。45は戻った後の夜まで埋める＝「力を手放さないため」。上の三行の『予約済み』を一行で見せれば、目的が変わったことが字なしで読める。原点の「イかれてる展開」が、結末の前夜に一段上がる。
- 連続性（小）：深夜枠の曜日の書き方をそろえる。原稿aの41は『日』『月』『火』（その夜の曜日）、原稿bの45は『水　0:00〜』（零時の日付）。零時の日付にそろえるなら、41は『月』『火』『水』の三行。時間の幅（0:00〜4:00か6:00か）も第一幕13・第二幕25の枠に合わせる。

### 3-3　ごみ置き場に「先客」の布団（笑いと他人の生活）
- どこを：「坂の下のごみ置き場。倉田は、網の横に、布団を立てかける。処理券の『倉田』が、街灯の下で、白い。」
- どう変える：

```
　坂の下のごみ置き場。網の横に、布団が一枚、先に立てかけてある。処理券に、『小松』。
　倉田は、その隣に、自分の布団を立てかける。処理券の『倉田』が、街灯の下で、白い。
```
- なぜ：知らない誰かも、同じ夜に寝床を出している。引っ越しかもしれないし、そうでないかもしれない（言わない）。東京ではほぼ全員が眠い、を台詞なしで一枚にできる。名前を書いた二枚の布団が並ぶのは、少し可笑しくて寒い。「二つ並べた枕」（38）の答えでもあるが、語はそろえない。
- 確かめること：名前の欄のある処理券の形（区による。図柄・色は写さない）。

### 3-4　残すもの
- 自分の手のひらで顎を押し上げる（第一幕12でミオが倉田にした手を、倉田が自分に）。「隣の窓から、いびき」。折り目からのぞく枕の角。0:00の依頼を押して坂を下りる。

## 4　結末（原稿bの本文に足す・削る）

### 4-1　選択の一枚：止まった手のまま、ドアが開くのを待ち、顔をドアへ向ける
- どこを（原稿b）：「倉田の目に、天井の明かりの一つひとつが、にじんで、輪になる。」から「店の寝息。外の寝息。」まで。
- どう変える（行の順を入れ替え、一句足す）：

```
　倉田は、女の横にしゃがむ。
倉田「三つ数えると、すっきりと目が覚めます。いち、に」
　倉田の目に、天井の明かりの一つひとつが、にじんで、輪になる。
　倉田は、まばたきをする。もう一度、見上げる。輪は、消えない。
　倉田の喉が、上がってくる。手が、口の前まで上がる。止まる。
　しゃがんだ倉田の目の高さに、女の寝顔。
　鞄を肩にかけた客が、自動ドアのマットに乗る。ドアが開く。朝の空気と、列の話し声。
　開いたドアの四角い青の中、列の後ろで、連れは、まだ靴紐を結んでいる。男は、鞄を提げたまま、それを見下ろしている。
　倉田は、手を、膝に下ろす。顔を、開いたドアへ向ける。
　口を、開ける。長い、あくび。
　ガラスの外で、列の後ろの男が、ドアのほうへ顔を向ける。
　（以下、原稿bのまま。「マットの上の客が、……」〜「店の寝息。外の寝息。」）
```
- なぜ：
  - 原稿bでは、手が止まった直後に女の寝顔を見て下ろす。下ろす理由は読めるが、あくびそのものは「喉が上がってくる」体の側から来るので、「こらえきれなかった」と読む人が残る（症状の読み）。
  - 止まった手のまま、マットの客がドアを開けるまで待つ。ドアが開いてから手を下ろし、顔をドアへ向ける。あくびに向きがつく。狙うのは、外の列まで届かせるため。勝手に出るあくびは向きを選ばない。だから選択が行為で一枚になる（第二幕29で、あくびを自分でマイクへ吐いた手の、マイクのない形）。
  - 39の倉田は、話しはじめたミオを待たなかった。ここでは、人ではなくドアが開くのを待つ。ドアの四角の中では、男が連れを待っている。台詞も副詞（「自分で」「わざと」）も使わない。
  - 起こすと約束した女の顔から目を離し、ドアへ顔を向ける。一人との約束より、全員を選ぶ。「さん」は言わない（原稿bのまま）。
- 字数：原稿bから+9字（「顔を、開いたドアへ向ける。」）。行の入れ替えだけで尺はほぼ動かない。止まった手の間が少し延びる（約+0.05分）。

### 4-2　ミオの一枚：ベッドではなく低い机、冒頭1の文で、目を開けて
- どこを（原稿b）：「四時三十八分。ミオの部屋。カーテンの隙間は、暗い青。／玄関の床に、スマホが、画面を伏せて置いてある。／ベッドの上で、ミオが、腕に頬をのせて、横向きに伏せている。両耳に、ピンクの耳栓。／目が、開いている。」
- どう変える：

```
＊

　四時三十八分。ミオの部屋。カーテンの隙間は、暗い青。
　玄関の床に、スマホが、画面を伏せて置いてある。
　低い机に、ミオが、伏せている。腕の上の横顔が、こちらを向いている。両耳に、ピンクの耳栓。
　後ろに、整ったままのベッド。
　目が、開いている。カーテンの隙間の青が、その目に、細く映っている。

＊
```
- なぜ：
  - **机に伏せる**：第一幕1の寝姿は、帰れない人が店のテーブルで眠る形。ベッドの上だと、うつぶせで寝ているふつうの寝相に見え、店との対が弱い。自分の部屋にベッドがあるのに、机に伏せている。後ろのベッドは37から整ったまま。「もう横にならない」が代価として画に出る。店の倉田（トレイの高さで伏せて、目が開いている）とも、同じ高さの二枚になる。
  - **冒頭1の文を使い、「腕に頬をのせて、横向きに伏せる」を三度目にしない**：結末には、すでに女と倉田の二人に同じ文がある（固定の本文）。ミオにも同じ文を足すと一場面に三度並び、サンダンスの言う「韻の管理」になる。代わりに、第一幕1で倉田が通路の向こうに見た一文（「腕の上の横顔が、こちらを向いている」＝寝顔①）を、そのまま一度だけ使う。違うのは、目が開いていることと、「こちら」に誰もいないこと。第一幕1の次の行（「倉田は、それを見ている」）は来ない。
  - **目に映る青**：光源のない暗い部屋では、開いた目は映りこみがないと紙の上でも画でも読めない。光源をカーテンの隙間の空に限る（画面の中の光源の決まり）。最後の引きの倉田の目は「画面の明かりを映した目」。ミオの目は空の青を映す。説明なしで、二人の違いが一つ出る。
  - 台詞・あくびの声・電話の光は入れない（原稿bのまま）。耳栓は、誰もいない部屋でもしている。それだけで43・44からの代価が読める。

### 4-3　頭の「にじまない」は残す、「のぞいていく」は残す

### 4-4　予備（足してもよい一行。推しは弱い）

### 5-2　43：本文の形（裁定の予備＝胸まで行かない／一度だけ同じ画面）

```

＊

- なぜ（関係）：

### 5-3　44（ミオの側。原稿cの本文に足す・削る）
- どこを：「野口「……耳？」」
- どう変える：「野口「耳？」」

```
　廊下。ミオは、長椅子に座る。膝に、閉じたパソコン。
　隣に、佐伯が座る。
佐伯「おつかれ——」
　佐伯は、手で口を押さえる。あくびを、飲みこむ。
　ミオの手が、ポケットへ入る。もう一つの耳栓を、右の耳に押しこむ。
