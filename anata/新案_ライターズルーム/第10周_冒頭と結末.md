# 第10周　冒頭と結末（主担当）／画と光（副担当）　シーン1とラストの「反復と差異」

前提：骨組み第3版／固定事項（結末・力のルール・色と光）／「説明ではなく行為」。採点は脚本として、紙の上だけで見る。
監督の追加指示（反映済み）：シーン1とラストは、どちらも「一枚で残る強い画」と「その場の出来事」を持つ。ラストは固定事項を守ったまま、冒頭の白煙と同じ強さにする。
→ 両案とも、ラストの出来事を「倉田のあくびが、店の外へ漏れ出す」にした（冒頭の白煙が店から外へ漏れるのと同じ動き）。案Aはガラス戸から商店街へ（目に見える広がり）、案Bは電話の向こうの他人の母へ（目に見えない広がり）。
共通の注意：骨組みにある「白煙の中で目が合う」は、そのまま書くと『寝ても覚めても』の出会い（煙と音の中で見つめ合う）の形に近づく。両案とも、煙の中で二人を見つめ合わせない。最初のやりとりは、起こす／電池を貸す、という用事にした。

## 案A「並びの鏡――ガラスの外の列」

### 一枚の画
- シーン1：店の外の歩道に、逃げた客が横一列。全員がスマホを店へ向けている（録画の赤い点が一列）。ガラスの中は白一色で、その底の端に、伏せた頭が二つ。
- ラスト：開いたガラス戸の向こう、白い朝の商店街。歩道じゅうで人が、座ったまま、もたれたまま眠り、手の中のスマホだけが光っている。戸口の段に、母からの『待ってるからね』を握ったまま眠る妻。店の中で、倉田だけが座っている。

### (1) 反復させる要素と差異
| 要素 | シーン1（24時間店） | ラスト（布団屋） | 何が裏返るか |
|---|---|---|---|
| 場所の形 | ガラスに向いた一列のカウンター席。外に歩道 | ガラス戸に向いて並ぶ展示用マットレス。外に商店街とパーキング | どちらも「ガラスの内と外」。冒頭は外の人が起きて中を見る → 結末は外の人が眠り、中の一人が見る |
| 漏れ出すもの | 他人のリュックの電池から白煙。店の中に溜まり、外の客は逃げ出す | 倉田の口からあくび。開いたガラス戸から外へ出ていき、外の人が眠る | 煙は人を外へ追い出す → あくびは外の人をその場に座らせる（記号5を、行為だけで） |
| 時刻 | 壁の時計 4:12（始発前。出ていくのを待つ時間） | レジの時計 10:31／11:05（開店後。眠ってよい場所で眠れない時間） | 待つのは「出る」ため → どこにも出ていけない |
| 曜日 | 土曜の明け方 | 土曜の午前 | 同じ曜日。二人で始まった土曜が、一人の土曜になる |
| 光 | 暗い青のガラス＋蛍光灯。白煙で蛍光灯が「白い板」になる（輪はない）。外に赤い回転灯 | 白い朝の光＋蛍光灯のまわりに光の輪 | 白は他人の電池の煙から → 自分が眠らなかった朝から。蛍光灯は平ら → 輪 |
| 音 | 非常ベル・自動音声・倒れる紙コップ。その中の二つの寝息 | 開いた戸から入る商店街の音が、あくびのあと一つずつ消え、どこかのいびきだけ残る | 騒音の中で二人だけ眠る → 静まっていく街で一人だけ起きている |
| 人の配置 | 全員が起きて外へ。端の二人だけが伏せて眠る | 全員（店長・夫婦・商店街）が眠り、倉田だけが起きている | 芯の「二人だけ起きていたい → 自分だけ起きている」を、配置そのもので裏返す |
| スマホの列 | 外の客たちのスマホが、眠る二人へ向いて一列に光る | 眠る人たちの手の中で、スマホがばらばらに光る。誰も見ていない | 見る道具 → 見られない画面。その一つが『待ってるからね』 |
| 起こす手 | 店員が倉田を揺り起こす → 倉田がミオの肩の手前で一度止まり、もう一度伸ばして揺する（二人の最初の接触） | 倉田が鍵の輪を夫の耳もとで揺らしかけ、止まり、握って止める | 一度止まってから起こした手 → 一度止まって起こさない手。間に「起こさず眠らせた」中心の反転が挟まる |
| 頼み | 誰も頼まないのに起こされる | 妻「起こしてもらえます？」→「起こしてくれるって言うから、寝たんです」 | 頼まれずに起こした男が、頼まれて起こさない |
| バッテリー | 他人の電池が熱を持ち白煙。店員が火花の止むのを待ち、氷水へ（記号1・2） | 電池そのものは出さない。こらえて、漏れる、を電池と同じ段取りで | 熱を出すのが、他人の鞄 → 倉田の体 |
| 二人の姿勢 | 倉田は突っ伏して口が開き、袖によだれ。ミオは腕に顔を埋め、寝顔を見せない | 倉田はマットレスに座り、目が開いている。ミオはいない | 誰よりも眠れた男 → 一人だけ眠れない男 |

### (4) ねらい
- 冒頭は「外の全員が起きて、中の二人を見る」、結末は「外の全員が眠り、中の一人が見る」。ガラスの内と外で、芯をそのまま裏返す一枚にする。
- 白煙が店から漏れて人を追い出すように、倉田のあくびが店から漏れて街を座らせる。結末の出来事が冒頭の発煙と同じ大きさを持つ。
- 鍵を止める手（起こさない）と、『待ってるからね』を握ったまま眠る妻で、力の代価を、倉田の知らない他人の用事に払わせる。

### (5) 危ない所
商店街が一斉に眠る画は、事故やけがに見えた瞬間に笑えない「被害」になるので、眠り方は座る・もたれる・足をつく・手が止まる、に限り、車道と刃物の先は画に入れないこと（美容室の鋏は「止まる」まで）。

## 案B「熱と声――二つの画面」

### 一枚の画
- シーン1：誰もいない白一色の店。手前で、氷水のバケツが泡を立てる。その奥、仕切りの上に、煙の中から二つの頭がゆっくり浮かぶ。
- ラスト：白いマットレスの枕の上に、並んだ二つの画面。片方は『お母さん　通話中』の秒が進み、受話口から知らない老人の寝息。片方は100%の、既読のつかない『ごめん』。

### (1) 反復させる要素と差異
| 要素 | シーン1（24時間店） | ラスト（布団屋） | 何が裏返るか |
|---|---|---|---|
| 最初と最後の声 | 黒。倉田の寝言「……あなたは、だんだん……ねむ、く……」最後まで出る。誰にも効かない | 黒。倉田の声「……あなたは」。続きは、ない | 眠っているから言い切れて、効かない → 起きていて、言えば効く。だから言わない |
| 漏れ出すもの | 他人の電池の白煙が、店じゅうに広がる | 倉田のあくびが、電話の受話口から、見えない他人の母へ届く（マイク・電話越しでも効く、のルール） | 目に見える煙 → 目に見えない、届いてしまう声 |
| 熱の出方 | リュックがふくらみ、触れた手が跳ねる。店員は近寄らず、火花が止むのを待ってから沈める | 喉がふくらむ。手の甲を押し当て、指が白くなる。こらえきれず漏れる | 他人の電池 → 倉田の体（記号5を、行為だけで） |
| 音 | 非常ベルでは起きない二人が、ベルが止んだ静けさで目を覚ます | 静けさの中で、受話口の寝息だけが続き、倉田は眠れない | 静けさで起きた二人 → 静けさで眠れない一人 |
| 時刻と光 | 4時すぎ、暗い青。白煙で蛍光灯が白い板に | 10時すぎ、白い朝。蛍光灯に光の輪 | 白は煙の白（他人の電池）→ 眠らなかった朝の白（自分の体） |
| 人の配置 | 仕切りの陰の隣り合う二人席。全員が逃げたあと、二人だけ残る | マットレスで全員が眠り、倉田だけ起きている。画面の向こうでも一人眠る | 「二人だけ」→「一人だけ」。眠りが店の外まで届く |
| 最初のやりとり／最後の画面 | ミオの残量1%。倉田が自分のモバイルバッテリーを差し出し、ミオはそれとバケツを見比べる。倉田は引っ込め、オレンジのケーブルだけ出す（挿す所はない） | オレンジのケーブルにつながった倉田のスマホは100%。『ごめん』は未読。隣に、通話の秒が進む他人のスマホ | 渡したい電気が渡せない → 電気は満ちているのに届かない。未読を電池切れのせいにしない（骨組みの注意を100%で守る） |
| 起こす人 | 店員は二人に気づかず、外から「外へ」と叫ぶ。二人は誰にも起こされない | 妻に頼まれた倉田は起こさない。代わりに、母からの電話に出てしまう | 誰にも起こされなかった二人 → 起こす約束の代わりに、別の人を眠らせる一人 |
| スマホ | 客は全員、スマホだけ抜いて逃げる | 妻のスマホに『待ってるからね』、続けて着信。倉田が出る | 真っ先に持って出る物 → 持ち主が眠っている間に、他人が出てしまう物 |
| 他人の一言 | 店員「……いたんですか」倉田「いました」 | 妻「お母さん？」→（寝息）→「目、開いてますよ」 | 見落とされた二人 → 見抜かれる一人 |

### (4) ねらい
- 映画の最初の声（眠ったまま言い切れる、効かない口上）と最後の声（起きていて言い切れない、言えば効く口上）を対にし、力のルールを説明なしで両端に置く。
- 結末の出来事は、起こす約束を破った男が、代わりに出た電話で他人の母まで眠らせること。白煙と同じく、止めようとして止まらない。
- 枕の上の二つの画面（進み続ける通話と、既読のつかない『ごめん』）を、結末の一枚にする。届いてしまう声と、届いて読まれない言葉。

### (5) 危ない所
他人の電話に出る倉田の行為が「やりすぎの仕掛け」に見えると笑いも痛みも消えるので、出る理由は「十時半に起こす約束を破った」直後の埋め合わせだけに絞り、母の寝息は無事な寝息として（『待ってるからね』の後の、ただの昼寝として）書くこと。店員が二人を見落とす冒頭は、仕切りの陰の位置と正しい誘導を残す。

## ショーランナーへのメモ（採否の参考）
- 両案とも、結末の固定事項（布団屋で倉田だけ眠れない／『ごめん』未読／『お母さん：待ってるからね』／黒／「……あなたは」／続きは、ない）とミオ不在を守った。結末は現行36（約150行）を30行に詰めたので、前に現行36の店長との会話（「いつからいるんだよ」「そばにいてもらえますか」）を足してよい。
- 結末を冒頭と同じ強さにするため、あくびを店の外へ漏らした。骨組みの「最後に、あくびという形で街に煙を出す」（記号5）と、力のルール（もれたあくびを聞いた眠い人が眠る／電話越しでも）の範囲内。現行36の「店の中だけで眠る」より一段大きい。監督の判断待ち（仮採用）。
- バッテリーの記号：両案とも冒頭で1・2を使う。案Bは結末に「100%」を足すので、骨組みの記号3か4を一つ削ること。
- 光の輪は冒頭では出さない（冒頭の倉田は眠れている＝力がない）。白煙の蛍光灯は「白い板」と書き分けた。
- 第三幕の「最後に一度だけ暖色」は、両案ともラストに使っていない。ミオが初めて眠れる場面に残す前提。
- 実在の店名・チェーンの見た目は使わない（「二十四時間の軽食店」）。実在の事故は再現しない。けが人は出さない。店員の対処は取材メモの順（近寄らない→火花が止むまで待つ→水に沈める）。
