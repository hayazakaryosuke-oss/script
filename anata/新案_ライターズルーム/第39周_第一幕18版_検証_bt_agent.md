# ロンドンの脚本エージェント 7.3
効いた：1 バッテリーとバケツ→ケーブルだけ（冒頭のテレビの五円玉で催眠の型を先に見せる）／4 窓の告白と百円・落ちた首／11 号令の「深呼吸」、年寄りは落ちず、かぶせる相手が鞄からミオに、うなずく嘘に代価。
①力のルールが紙で立たず、17の時限装置が見えない：「線は原因ではない」は三度（12翌朝・13・17）見せたが、「三晩起きると戻る」の肯定は16だけで、16には眠る人が誰もいない。例：16の通りに一人いて落ちる（新聞配達など）、三本目はその後に引く。
②ミオが講座で何を取りにいくのかが無い（15『入会の条件　72時間』、二十八時が何を約束し、落ちたら何を失うのか。72時間は代価だけで賞品が無い試験）。
③16で倉田の欲が逆向きにぶれる（カードを読んで戻す→「連休は、寝る。ずっと」→肩が下りる：安堵か失望か。17で行き先を知っていて家の向かいで待つ。「相方です」が決意か衝動か）。
分からない：14→15で六日飛ぶことが紙にない、「水曜 26:00」／13 佐伯の電話→立ち会い、誰が誰の代わりか／10「何時」「……五時？」の一人二役／分刻みの時刻が多すぎて「何晩目か」が埋もれる／17 ミオが倉田に気づいたか。
理由：彼女＝半分（隠す理由は読める、講座を選ぶ理由と得るものが無い）。彼＝12ではっきり、14以降の「守るために隠す」は推測。
