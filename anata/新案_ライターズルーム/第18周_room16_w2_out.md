## (a) 11の改稿（監督決定3：日曜 午前二時／二晩眠っていないことを紙で見せる／ミオが眠くない理由／連鎖の後の倉田の行為）

**一枚で残る強い画**：受付の女の手もとで重なった二枚の受付票。上に『43』、下に『1』。
**その場の出来事・ズレ**：四十三時間起きている男は起きていて、ちゃんと眠ってきた人たちが倉田のあくびで順に落ちる。倉田が二度目のあくびを手でふさぐと、目の前を通る眠い受付の女は落ちない。

### 差し替え（新しい行は計27行）

**A 見出し**
- 旧「### 11　西新宿 コワーキングスペース 十四階　土曜 午前二時」
- 新「### 11　西新宿 コワーキングスペース 十四階　日曜 午前二時」

**B 到着**（旧：「ミオが、通用口の前に立っている。首の社員証を外して……」から「倉田「……十分」」までの6行。一行目の「一時五十六分。オフィスビルの夜間通用口。守衛室の小窓だけが明るい。」は残す）

```
　ミオが、通用口の前に立っている。髪を、うしろで一つに結んだばかり。左の頬に、枕の跡が三本。
　倉田が自転車で来る。背中に、四角い配達バッグ。胸で、スマホが鳴っている。『新しい配達』。倉田は『オフラインにする』を押す。
倉田「寝た？」
ミオ「寝た」
　ミオが、倉田の頬を指でなぞる。反対の頬も。跡は、ない。
```
（ねらい）第3版から続いた「寝た？／寝てない」の向きを逆にする。跡はミオの頬にあり、倉田の頬にはない。『オフラインにする』は2の『応答がないため、オフラインにしました』の裏返しで、倉田が今まで寝落ちせずにオンラインだったことを、本人の指が示す。日曜の夜中なので、社員証と会社のパソコンの行は外した。

**C 受付票**（旧「受付の机で、若い女が宅建の問題集を閉じる。」を差し替え、「倉田とミオは、ソファの端に座る。沈む。」の前に置く）

```
　受付の机で、両耳にイヤホンの若い女が、宅建の問題集を閉じる。クリップボードを二枚、差し出す。『体験会　受付票』。いちばん下の欄に、『前回の睡眠から　　時間』。
　ミオが書く。『1』。
　倉田は、ボールペンの尻で指を一本ずつ押さえて数える。もう一度、数え直す。書く。『43』。
　ミオが、それを見る。倉田を見る。
　受付の女は、二枚を重ねて受け取る。上の『43』を見る。ソファを、手のひらで示す。
```
（ねらい）「紙で見せる」をそのまま紙にした。金曜の朝（10の末尾。倉田がミオの『7:30』を止めた朝）から日曜の午前二時までで43時間。指で数え直すのは、眠っていない頭の遅さ。両耳のイヤホンは、後で受付の女が連鎖で落ちない理由になる。

**D 連鎖**（旧：「二時九分。倉田の顎が上がる。」から「受付の女が立つ。眠った列を……あくびを飲みこむ。」までの7行）

```
　二時九分。倉田の顎が上がる。口が開く。手は、膝の上のまま。長い、あくび。
　隣で、ミオが、その口を見ている。笑いを、噛んでいる。
　その隣の学生の首が、横に倒れる。
　ネクタイの男の膝の上で、紙コップが傾く。
　抱っこ紐の女の手の中で、白黒の赤ん坊の画面が傾く。
　その先の三人も、順に。
　ミオの口もとから、笑いが消える。
　受付の女が、両耳のイヤホンを外して、立つ。眠った列を、端から端まで見る。手の甲で口を押さえて、あくびを飲みこむ。
```
（ねらい）
- ミオは、こらえない。そもそもあくびが来ない。眠くない人は、聞いても落ちない（監査 中1）。
- 列の人は、自分ではあくびをしない。うつるのはあくびではなく倉田の声で、力は倉田だけのものだと読める。
- 第5版では、全員があくびをしてから倒れていた。そのままだと、人から人へ移る連鎖に見える。
- 36では「同時に」落ちる。11が「順に」なのは、出かけた力の遅さとして対にする。

**E 連鎖の後の倉田の行為**（旧「倉田は、並んだ膝掛けの山を見る。自分の口に、手のひらを当てる。離して、手のひらを見る。」の1行）

```
　倉田は、並んだ膝掛けの山を見る。
　倉田の顎が、また上がる。倉田は、手のひらで口をふさぐ。肩が揺れる。飲みこむ。
　受付の女が、膝掛けを抱えて、倉田の前を通る。そのまま、歩いていく。
　倉田は、手のひらを口から離す。手のひらを見る。
```
（ねらい）
- ルールの二つ目「こらえたあくびでは眠らない」を、眠い受付の女（イヤホンはもう外している）で一度だけ見せる。
- 倉田が口をふさぐのは、疑い始めた人の行為。36の「倉田の手が、口の前まで上がる。止まる。下りる。」はこの手の続きで、第三幕では、ふさがないことを選ぶ。

**F ロビーの明かり**（監査 小13。旧「暗いロビー。床に、間接照明の暖かい明かりが、点々と落ちている。ソファの脇にも、一つ。」）
```
　暗いロビー。床置きの丸いランプが、いくつか、暖かい明かりを落としている。ソファの脇にも、一つ。低いソファが、ガラスの壁に向いて並んでいる。
```

**G 申込書の出所**（監査 小6。旧「ミオが申込書の紙をガラスに押し当てて、書いている。」「倉田は紙をガラスに当て、」「ガラスの向こうで、立っている男が一人、紙の裏側からそれを見ている。」）
```
　ミオが黒いカードを裏返し、ガラスに押し当てて書いている。裏は、申込の欄。『沢井ミオ』。その下の欄に、『倉田修』。
　倉田はカードをガラスに当て、「イ」と「攵」の間に、棒を一本足す。
　ガラスの向こうで、立っている男が一人、カードの黒い面を見ている。『72時間』。
```

**案B（迷った所。採らなくても成り立つ）**：Dの「壁際の貸し出しのかごから、膝掛けを出す。」の後に一行足す。
```
　膝掛けを掛けていく手の、爪が六色。倉田が、その手を見る。ミオも、見る。
```
→ 喜びの夜の「爪が、六色」（下の(b)の差し込みで、配達先はこのビル）を回収する。二人にとって講座は、広告より先に「配達先」として生活の中にあった、と分かる。足しても28行で、30行以内に収まる。

**そのままにする所**
- 2:24の「倉田の目が、閉じている」→ミオ「起きてます」。連鎖の後なので、ルールには触れない。数分の居眠りで力が消えることは、ミオが膝掛けを止める行為で守られる。
- 真壁の数字、72時間のカード、「修」の縦の棒は残す。

**差し込む位置**：第5版の

>
> ＊

の、最初の「＊」の後、「三時十分」の前に、新しい「＊」で一節を入れる（7行）。

```
＊

　三時。西新宿。オフィスビルの夜間通用口。守衛室の小窓だけが明るい。
　倉田が、配達バッグから紙袋を出す。
　通用口のドアが、細く開く。手だけが出て、紙袋を受け取る。ドアが閉まる。

　黒い壁。上のほうに一段だけ、窓が白い。白の中に、小さな人影が一列、立っている。

```

**一枚で残る強い画**：眠った街の黒い高層ビルに、白い横線が一段。その中に、立った人影の列。
**その場の出来事・ズレ**：
- 配達が終わってアプリは『配達完了』を出す。それでも倉田は帰らずに見上げている。午前三時に、立ったまま起きている人たちがいる。
- 一行目は、11の一行目「オフィスビルの夜間通用口。守衛室の小窓だけが明るい。」と同じ語にした。11の頭で、観客は「ここは、あの夜の配達先だ」と気づく。台詞は要らない。

**付随する一行の直し**（3:10の答えを配達先に合わせる。関係（h）の当てっこの形は崩さない）
- 旧　倉田「チェーンのまま。手だけ」
- 新　倉田「ドア、細く開けて。手だけ」
（「手は」「……爪が、六色」と、鼻が鳴る笑いはそのまま。11の案Bを採れば、六色の爪は受付の女の手になる）

**リアリティ**
- 最初の注文『受取：コンビニ　1.4km』の届け先が西新宿のビル。団地は、西新宿から自転車で十分ほどの所の架空の団地にする（喜びの夜の3:10の戻り、8の朝、8bの中野への帰りと矛盾しない）。
- 夜間の通用口で配達品を受け取る形は、24時間使えるオフィスとコワーキングではありうる。施設は架空にし、要取材とする。

## (d) 36の直し（監督決定4：外の人は座りこむ・もたれる・膝が折れる／二人はドアの前の植え込みまで）

**一枚で残る強い画**：開いたままの自動ドアの四角い白の中。ドアの前の植え込みの縁で、靴紐を結んでいた連れが男の膝に頭を落とし、男がその頭に顎を落として眠っている。
**その場の出来事・ズレ**：
- 五時十分、始発で着いた人たちが、眠る人たちをよけて駅から歩いてくる。誰も止まらない。
- 起きている人は止まらず、眠っている人は動かない。その中で、倉田だけが「どちらでもない」。

（ねらい）
- 「止まる」の語を本文から外した。体はみな下へ折れて、眠った体になる。倒れはしない。
- 自動ドアが開いたままなのは、マットの上に人が座っているから。現実の仕組みで説明がつく。
- 二人は、ドアの前（聞こえる距離）にいる（監査 中6）。あくびのきっかけは、遠ざかる恋人たちから、待つ男に替えた。連れの靴紐を待つ男は、既読を待つ倉田と同じ姿。だから仕返しには読めない。眠らされた二人は、寄りかかって一緒に眠る。倉田には手に入らない形を、倉田が与えてしまう。
- 五時十分に新しく来る人は、あくびを聞いていないので眠らない（ルールどおり）。監査 小16の「新しく来た人もマットの上で止まる」は、ルールに反するので採らない。「三十分、誰も来ない」の不自然さも、これで消える。

**副（冒頭と結末）の確かめ**
- 1との対は三つのまま。①仕切りの陰の二人席、②店員と倉田の二行、③外へ。
- ③は、1では「外へ逃げる」、36では「外で座りこむ」。始発の人たちが通り過ぎる行は、1の「誰も拾わない」（倒れた紙コップ）の裏の音として効く。
- 表の36の行：「店と外の十数人が同時に止まる」→「店と外の十数人が、同時に膝を折る（座りこむ・もたれる）」。〔電④〕を付ける（監査 小19）。

## 副担当の視点を一度ずつ通した結果

- **サスペンス**：
  - 11の受付票『43』は、観客だけが計算できる時計になる。そこから連鎖までの約九分（1:56→2:09）、観客は「この男は、いつ落ちるか」と待つ。実際に落ちるのは、周りのほう。
  - 二度目のあくびを手でふさぐ所で、眠い受付の女が前を通る。一拍の「落ちるか」を作った。
- **身体と生活**：
  - 『43』は配達（昼・夜）と編集の予定表から出る数字で、気合いの数字ではない。
  - ミオの『1』と枕の跡は、ちゃんと眠ってきた勤め人の日曜。
  - 9は、評価の付箋を外しても、体の代価（立ったまま落ちる、0が増える、椅子を戻す）は残る。
- **冒頭と結末**：
  - 11の「手のひらで口をふさぐ」と、36の「口の前まで上がる。止まる。下りる」を一本の線にした。
  - 36は「止まる」をやめて「折れる」にした。1の白煙で「逃げる体」、36で「座りこむ体」の対になる。
  - 喜びの夜の差し込みの一行目は、11の一行目と同じ語にし、場所の反復で講座の初出を作った。

## 確かめること（新たに出たもの）
- 体験会の受付票に「前回の睡眠から何時間」の欄を置くのが、夜間のイベントの体調確認として自然か（要取材。架空の講座の書式にする）。
- 36の日付（9月下旬〜10月の日曜）での、5:10の白さと、新宿の始発が着く時刻。
- 喜びの夜の団地と西新宿の距離（自転車で十分前後）。団地の名は出さない。
