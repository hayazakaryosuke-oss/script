# 第54周 ブレイントラスト　40代の会社員の男性（恋愛映画はあまり観ない）

※採点は「脚本として」。紙に書かれていることだけを見た。基準作とも、その「脚本」と比べている。

## 1. 点
**8.2 / 10**

前半から中盤（1〜13）は、恋愛ものが苦手な自分でも乗れた。あくびで人が倒れるルールが、ジム→鏡→サングラス→教室と少しずつ広がっていくのが面白く、「0KO」のポスターや「窓にですけど」など、前に出た物が後で返ってくるのも気持ちいい。点を止めたのは、後半で倉田に乗れなくなる所が二つあること（ノート1・2）と、終わり方が二重に開いていること（ノート4）。基準作の脚本と比べると、主人公のした悪いことの「代価」の書き方が浅い。

## 2. グッド・ノート

### ノート1（いちばん大きい）
- **どこで**：24（夜間自習室を眠らせて進む所）。「床で、窓際の女のスマホが光っている。画面に、『通話中　家』」「スマホの声（小さく）『お母さん？　……もしもし』」「倉田の足が、一度止まる。またぐ」。続けて、伏せた女の髪をバンテージの指で分け、顔を横に向けて「違う」を三回。その前の警備員も、あくびで眠らせてボタンを押している。
- **観客が期待すること**：18〜19で、ミオに「やらないで」と言われたのに眠らせ、寝ている親指でスマホを開けた。それでミオは鍵を置いて出ていった。だから最後の山場では、倉田が「同じことをしない」か、少なくとも「迷う」のを見たい。
- **人物がしたこと**：迷わず、もっと大きく同じことをする。知らない人を十人以上、本人の許しなく眠らせ、寝ている女の顔を指で動かして確かめる。子どもか家族と電話中の人も、またいで先へ行く。
- **そのズレ**：画面は「走れ、倉田」と応援させる作り（信号を待って走る、テンを数える、拳を止める）なのに、やっていることは18の悪いことの拡大版。
- **なぜ問題か**：倉田に乗れるかどうかは、ここで決まる。応援していいのか、引いて見るべきなのか、紙の上で決めきれていないので、山場で気持ちが二つに割れて、いちばん盛り上がるべき所で冷めた。26で「あなたは、」の指を折る一瞬が償いになっているが、24の重さに対して小さすぎる。
- （一行だけ）24のどこかで、倉田が「やらないで」を思い出して代価を払う瞬間が一つあれば、乗り直せる。

### ノート2
- **どこで**：15〜16。灰色の帯『10/10　6:40〜15:50　記録なし』を指で測る。16で「……あの日、何してた？」「寝てた」「どこで」「修の上」→「俺、寝てたし」「……真壁？」。
- **観客が期待すること**：嫉妬で揉めるなら、真壁が何か怪しいことをしているのを、一度は見せてほしい。
- **人物がしたこと**：ミオは本当のことをそのまま言う。倉田は信じない。ミオは説明せず背を向ける。真壁は、9でバンドを巻き、13と17では寝ているだけ。
- **そのズレ**：後半の大きなケンカの理由が、「本当の答えを聞いたのに信じない」と「説明しない」の両方でできている。真壁は恋のライバルとして何もしていない。
- **なぜ問題か**：恋愛ものを観ない自分には、ここが「作られたすれ違い」に見えて、気持ちが少し離れた。しかも25の「テン」は、何もしていない真壁に向けて数えることになり、0KOの回収が気持ちよく決まりきらない。

### ノート3
- **どこで**：20〜23の前半。倉田は『起きてる？』を送り続けるだけ、21と22はミオが一人で眠る話、23は天井に向かって「ワン。ツー」と会長のジムでのKO。
- **観客が期待すること**：18〜19で関係が壊れたあと、主人公が何かを取り返しに動くこと。
- **人物がしたこと**：倉田は待つ。会社の前に一度行く（20）が、それ以外は動かない。動くのはミオ。
- **そのズレ**：物語を進めているのがミオで、主人公はほぼ受け身の時間が三場ぶん続く。さらに「眉のあいだが、ほどけていく」（全部で5回）や「長い、あくび」「喉が、上がってくる」の決まり文句が重なり、同じ絵を見ている感じが出る。
- **なぜ問題か**：21と22は一つずつなら良い場面だが、続けて読むと、自分はここで一度、時計を見たくなった。23の『既読』で戻ってこられたが、そこまでが長い。

### ノート4
- **どこで**：22でミオが『木　夜　ここ』をアベさんの手の横に置く／26でミオがアベさんの袖をつまんで眠り、倉田の口をふさいだ手を見て「……負け」と目を閉じる／最後の「顎が、開きかける。　倉田の顔。　黒。」
- **観客が期待すること**：最後に、ミオが倉田をどう思っているのか、倉田がこれからどうするのか、少なくともどちらか一つは分かること。
- **人物がしたこと**：ミオは目を閉じるが、アベさんの袖は離さない。倉田はあくびを出すのか止めるのか、決まる前に黒。
- **そのズレ**：ミオの気持ち（許したのか、もう別の場所で眠れるようになったのか）と、倉田の最後の行動（一緒に眠るのか、起きて見張るのか）の両方が開いたまま終わる。
- **なぜ問題か**：「彼女が寝てる間、何してるんですか」「寝てます」「倉田さんは」「……起きてます」の答えは強いので、その後の倉田の一手が見えれば胸に落ちる。今は開いている所が二つ重なっていて、感動より「どっち？」が先に来た。また22で三日月のコップをアベさんに渡す所は、初見では「ミオが二人の約束を別の男に渡した」と読めて、少し痛い。わざとならよいが、26で意味が変わるまでの間が長い。

### ノート5
- **どこで**：12の外廊下。ミオが『寝落ちの記録』のいちばん上『9/17　0:05　修の部屋』を親指で押さえ、「ミオの肩が、下りる。長い、息」。そのあと「ただいま」。
- **観客が期待すること**：ここでミオが「自分の寝落ちの一部は倉田のあくびのせいだった」と気づいたのなら、次に倉田にそれを言うか、態度が変わるのを見たい。
- **人物がしたこと**：何も言わない。13以降も、そのことには触れない。18で「やらないで」と言うので、知っていることは後から分かる。
- **そのズレ**：ミオが倉田の力を「いつ、どこまで」知っていて、それをどう思っているのか（ほっとしたのか、怖いのか）が、紙の上で一度もはっきりしない。
- **なぜ問題か**：ミオ自身にも寝落ちがある（8の朝会、手首の時刻の列）ので、どれが自分のせいでどれが倉田のせいか、観客も整理できない。18の「やらないで」と19の「これで、よかったのに」の重さが、そこにかかっているのに、ぼやける。

## 3. いちばん効いた所三つ
1. **3 コインランドリー**　ミオ（窓へ）「付き合ってもらえませんか」／倉田（窓へ）「はい」／倉田（会長へ）「……窓にですけど」／会長「百円」。告白が百円で値切られる。しかも20で野口に「……窓に、ですけど」と返ってきて、今度は笑えない。同じ台詞で、笑いと痛みの両方を取っている。
2. **7 ジム**　「会長の口が、反射で開く。　会長『ワン、』　会長の顎が、トップロープに落ちる」。力の見せ方として最高。説明ゼロで、ルールも、倉田の『0KO』の悔しさも、一度にわかる。12の「テン、聞いてないんで」とつながるのも良い。
3. **26 軽食店**　倉田（小声で）「彼女が寝てる間、何してるんですか」／アベさん「寝てます」／アベさん「倉田さんは」／倉田「……起きてます」。5や6の「俺が寝てる間、何してた？」「見てた」が、ここで別の男の口から裏返る。この話が何の話だったのかが、二行でわかった。

## 4. 一行で勧めるなら
「あくびで人を眠らせてしまう元ボクサーと、眠るのがこわい女の話。恋愛映画が苦手でも、ボクシングの『テン』で最後まで引っぱられる。」
