## 1　9（ミオの「前」を一拍）

第13版のこの行（9の終わりの七行）：
```
　朝会が終わる。佐伯が、壁際から椅子を一脚引いてきて、ミオのパソコンの前に置く。
佐伯「座ってやって」
　佐伯が行く。自分の席で、電話を耳に当てる。
佐伯（電話に）「何度。……七度八分。……うん。昼で、代わる」
　ミオは、椅子を壁際へ戻す。スマホに打つ。『今日、何時まで？』。送る。
　既読が、すぐにつく。
　ミオは、立ったまま、キーを打つ。
```
→ 新しい行：
```
　朝会が終わる。佐伯が、壁際から椅子を一脚引いてきて、ミオのパソコンの前に置く。
佐伯「座ってやって」
　ミオは、笑って、座る。
　佐伯は、椅子の背に手を置いたまま、電話を耳に当てる。
佐伯（電話に）「何度。……七度八分。……うん。昼で、代わる」
佐伯「明日の夜の配信。立ち会い――」
ミオ（笑って）「いけます」
佐伯「――いける？」
ミオ「いけます」
　佐伯が行く。ミオの顔から、笑いが消える。スマホに打つ。『今日、何時まで？』。送る。
　既読が、すぐにつく。
　ミオは、椅子から立つ。立ったまま、キーを打つ。
```
- 何が変わるか：第13版では、ミオは佐伯の椅子を戻していた（合わせない行為。ブレイントラストが「9でも佐伯の椅子を戻す」と指摘）。新しい行では、①椅子を笑って受ける、②佐伯の電話（熱の子と昼に交代）をすぐ横で聞き、頼みを言い終わる前に笑って受ける。予定表は開かない（行為の省きで見せる。ト書きでは書かない）。③佐伯が背を向けると笑いが消え、倉田への一行を打ち、既読がつくと椅子から立つ。人前で合わせる顔と、倉田に向く顔の差が、一つの場面の中で行為になる。
- 佐伯の「――いける？」：佐伯は「同じ文を一字一句言い直す」人（台詞の型）。答えが先に来ても、自分の文を最後まで言う。ミオはもう一度「いけます」と合わせる（笑いはここで、身勝手でなく律儀な言い直しから出る）。
- 他人の生活：佐伯が頼む理由は台詞にしない。熱の子の電話のすぐ後に頼むので、観客には「佐伯は明日の夜に家を空けられない」と読め、ミオはそれを読んで先に受ける（空気を読む人の行為そのもの）。10の朝の『佐伯：今日は午後からでいいよ　7:12』が、夜を受けてくれた人への返しとして読めるようになる（第13版では理由がなかった）。
- 締めの形：第13版の「既読がすぐつき、立ったまま打つ」を残す。違いは、佐伯の置いた椅子が空のまま横に残ること（戻さない。拒まない）。
- 「笑いが消える」は9だけの語にした（10の「笑いが、引いていく」と分ける。笑いの語の振り分けは下の「組み立てる人へ」4）。
- 時刻：9は9/10（木）10:00。「明日の夜」は9/11（金）の夜＝10bの土曜0:00〜（暦と合う）。10の零時に二人が『毎日』の帯を作るのは、ミオが金曜の夜をもう受けたあと。10bの0:00にその帯の上へ『朝まで会社。寝てて　23:58』が来るのは、ミオが自分で受けた夜（第13版では誰が決めた夜か紙になかった）。

## 2　10（「知ってたの」を一つの読みに）

第13版のこの行：
```
ミオ「かかってた？」
倉田「寝てただけ」
　ミオの笑いが、引いていく。
ミオ「知ってたの」
倉田「十年で、一人も、いない」
　ミオは、倉田を見ている。握った指を、離さない。
```
→ 新しい行：
```
ミオ「かかってた？」
倉田「寝てただけ」
ミオ「うん。知ってた」
倉田「十年で、一人も、いない」
　ミオの笑いが、引いていく。倉田を見ている。握った指を、離さない。
```
- 読みを一つに：「知ってたの」は「（あなたは）知ってたの？」とも「（私は）知ってたの」とも読めた（会社員の指摘）。「うん。」を頭に置いて、ミオの側の告白に決めた。「かかってた？」は、倉田が嘘をつくかの試しになり、倉田が本当のことを言ったので、ミオも本当のことを返す。二人のあいだの小さな取引：ミオの秘密（3の「……かかりました」と5の『かかりました』は、分かって合わせて言っていた）と、倉田の秘密（十年で一人もいない）を交換する。
- 「笑いが引く」を倉田の一行の後へ移した：ミオの笑いを止めるのは自分の告白ではなく、倉田の十年。
- 線：3でミオは見知らぬ倉田に合わせた（拍手の中で「……かかりました」）→9で佐伯に合わせる→10「うん。知ってた」で3が合わせだったと分かり、そのすぐ後の「合わせない」が、初めて合わせるのをやめる一語になる。
- 字数は−2字。

## 3　10bの3:00（ミオが注文した行為）

第13版のこの行：
```
　三時。別のビルの夜間通用口。社員証を首にかけたミオが、ドアの外に立っている。坂を、四角い配達バッグの自転車が上がってくる。
　ミオが、一歩出る。
　配達員が、ヘルメットを外す。知らない女。コンビニの袋を渡す。
　袋の中に、棒のアイスが二本。
```
→ 新しい行：
```
　三時。別のビルの夜間通用口。社員証を首にかけたミオが、ドアの外に立っている。手の画面に、『棒のアイス　×2　配達中』。坂を、四角い配達バッグの自転車が上がってくる。
　ミオが、一歩出る。
　配達員が、ヘルメットを外す。知らない女。コンビニの袋を渡す。
　女は、もうヘルメットをかぶり直している。
```
- ミオが自分で頼んだことを、手の画面の一行で先に出す（俳優の指摘）。「×2」は、喜びの夜の「一本ずつ」の数。誰が来るかは選べないのに二本頼んだ、が「一歩出る」の前にある。「袋の中に、二本」は画面と重なるので外した（4:12のタクシーの「棒が一本と、汗をかいた一本」で二本はもう一度見える）。
- 他人の生活：知らない女は、渡したときにはもうヘルメットをかぶり直している（次の注文へ。ミオの一歩に付き合わない）。倉田がオフラインにした夜も、配達は誰かの仕事として回っている。台詞は足さない。
- 確かめること（取材）：注文の画面に配達中の表示と品数が出る見え方（アプリは架空。確信度：高）。実際のアプリは配達員の名前も出すことが多い。ミオが見ているのは品数と「配達中」だけ、とする（名前は画面の外。要確認。気になるなら『配達中』を地図の自転車の印に替える）。

## 採らなかった案（理由）
- 9で佐伯に「すみません」と頭を下げて受ける：謝る形は「合わせる」より「引け目」に読める。笑って先に受けるほうが、空気を読む人の速さが出る。
- 9で椅子を戻す行を残す：佐伯の前で合わせる一拍と打ち消し合う（第25周の指摘そのもの）。立つだけにして、椅子は空のまま横に残した。
- 9でミオが予定表を開かない行をト書きに書く（「ミオは、予定表を開いていない」）：言い終わる前に答える行為で足りる。説明のト書きになるので外した。
- 10で「……知ってたの」の頭に「……」を足す：台詞頭の「……」の数（1〜13で9）を動かす。「うん。」のほうが読みを一つに決める。
- 10bの3:00を注文する瞬間（2:4x、会社の机で『注文する』を押す）にする：時刻の切り替えが一つ増え、約+0.15分。手の画面の一行で足りる。
- 10bで知らない女の配達員に台詞（「お待たせしました」など）：持ち時間は増えるが、ミオの一歩に付き合わないことのほうが、他人の生活として強い。
