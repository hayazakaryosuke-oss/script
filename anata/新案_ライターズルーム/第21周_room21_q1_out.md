## 2　13の三つの拍と、気づきの一拍（72:00と13）

### 72:00（b採用。直しなし）
- 「何時」「火曜の、朝」「……正解」は残す。倉田が窓を見ずにミオの目を見る行、「まつげは、下りない」、つねられた所に触れる行も残す。**これが13の気づきの前段**になる：72:00で倉田は「閉じない目」を一度見て、まだ喜びとして受け取る。13で、閉じた目の写真と並べたときに初めて意味が変わる。
- 「だけ」を外した形（b）でよい。

### 13の判定
cの13は三つの拍に絞れていて、数字の列も減っている。直すのは**写真の拍の中身**と**伏せる時刻**の二つ。

**直しの範囲**：cの13の「倉田は、スマホを顔の前に上げる。」から「倉田の手が、ペンへ戻る。」まで（11行）を、次の12行に差し替える。

```
　倉田は、スマホを顔の前に上げる。目を見開く。錠が、開く。
　写真の一覧。升目が、全部、自分の片目。親指で、遡る。目。目。目。
　目の升目が尽きた先に、一つだけ、黄色。
　押す。黄色い光の中の、ミオの寝顔。口が、少し開いている。
　隣で、ミオは予定表を見ている。窓の白が、横顔に当たっている。
　倉田は、画面の寝顔を見る。横顔を見る。
　ミオが、まばたきをする。まぶたが下りて、すぐ上がる。
　倉田は、スマホを伏せて、署名の欄の横に置く。
　倉田の右手が、上がる。親指と人差し指が、少し開いている。指のあいだに、ミオの目が入る。
　指が、ゆっくり閉じる。ミオの目は、指の向こうで、開いている。
　ミオは、気づかない。
　倉田の手が、ペンへ戻る。
```
そして、cの縦の棒の拍の「倉田は、写真を伏せる。」（一眠りから覚めた直後）を**削る**。cの末尾「その横に、伏せたスマホ。」はそのまま生きる。

理由：
- **黄色の一枚が先にあるので、指の形の意味が決まる**。cの形（開けられた目の写真→指）だけだと、指は「11・12でまぶたを開けた形」の反復に読まれ、「開ける」のか「閉じる」のかが紙の上で決まらない。寝顔を見た直後なら「閉じさせたい」以外に読めない。説明台詞は一つもない。
- **この指が、第三幕の中心の反転（ミオの「やらないで」を越えて眠らせる）の最初の一回になる**。13では閉じられない（彼女の目は指の向こうで開いている）＝欲だけが生まれて、まだ何もしない。36の「手が、口の前まで上がる。止まる。下りる。」と同じ「上がって、戻る手」の形の、前の一回（cの読みを残す）。
- **伏せる順**：写真を伏せるのは、指を上げる前・署名の前。ミオは予定表を見ていて、写真は一度も上を向いて机に置かれない。監査の中「ミオが写真を見たと読める」が根から消える。
- **暗くなりすぎない**：この一拍の前後に、明るいものを置いたまま。前＝「……ピース」「二年」（ミオの取り違えと倉田の訂正）、後＝伸びた棒を冗談と読んで笑うミオと、紙の端まで引かれる『オ』。気づきは台詞のない四行の中だけで、すぐ「ペンへ戻る」＝それでも書く。恋が勝つ形で拍を閉じる。
- 「ミオは、気づかない。」は一行の説明に近いが、ト書きの事実として要る（cの「指の向こうで、開いている」だけだと、ミオが見返しているとも読める）。削るなら「ミオの目は、指の向こうで、予定表を見ている。」に替える（説明を行為の向きに変える）。こちらを推す：
```
　指が、ゆっくり閉じる。ミオの目は、指の向こうで、予定表を見ている。
```
（これで「ミオは、気づかない。」の行は要らない。11行に戻る）

### 採らなかった案（判定2の候補）
- **q1の別案「ミオが振り向き、倉田の指を『起きてる？』と読んで、自分の指で自分のまぶたを押し開けて見せる」**：笑いとしては強い（倉田は閉じたい、ミオは開けて応える＝一本の映画が一つのやりとりに入る）。しかし同じ13の中で、縦の棒の拍に「倉田の眠りを、ミオが冗談と読んで応える」がもう一度ある。同じ形のズレが二分のうちに二回になる（創作ノート10の5：反復は相手・目的・代価を変える）。キー場面の「その場のズレ」は縦の棒の一つに絞る。→ 採らない。

## 3　ミオが一人で起きている時間（10の2:00、棒アイス）

### 判定：今のままだと半分は「待つ人」に読める。二行外して一行足せば、彼女自身の喜びになる。
aの節は良い（スマホを持たない／アイス／『あたり』／一人で笑う）。ただし次の二行が、場面を倉田の側へ引き戻す：
- 「坂の下の、精算機の明かり。誰も、上がってこない。」…8bで倉田が眠っていた場所を見て、「上がってこない」と書くと、**倉田を待っている**夜に読める。
- 「左右を見る。誰もいない。」…見せる相手を探している＝**誰か（倉田）と分けたい**喜びに読める。

直し：
「　かじる。坂の下の、精算機の明かり。誰も、上がってこない。」
→「　かじる。廊下の明かりに、虫が一匹、当たっては離れる。」
（他人の生活ではなく、誰のものでもない夜の時間。8bの場所を指さない）

「　ミオは、棒を廊下の明かりにかざす。左右を見る。誰もいない。
　ミオは、棒をくわえたまま、膝を抱えて、一人で笑う。」
→
```
　ミオは、棒を廊下の明かりにかざす。
　四つ目のドアを見る。中で、倉田が寝ている。
　ミオは、立たない。
　棒をくわえたまま、膝を抱えて、一人で笑う。
```
理由：**起こしに行かない**、が「自分のための喜び」を行為で決める一行。倉田に見せれば二人の喜びになる。見せないことを選ぶ。これが原点の「僕が寝てる間、彼女は何をしているんだろう」の、観客だけが先に持つ答えの一つになり、第二幕の疑心暗鬼の種が「浮気」ではなく「彼女には彼女の夜がある」に立つ（ミオを嫉妬の装置にしない）。
- 「倉田のサンダルで」は残す（関係の小さな行為。恋の外の時間を、恋の中の物を履いて過ごす）。
- 3:00の「アイスの棒をティッシュに包んで、鞄の内ポケットにしまう」は残す。『あたり』はもう一本と替えられる＝ミオが一人で持つ、次の夜の小さな予定。第二幕で使わなくてよい（日用品を伏線にしない、aの記録どおり）。
- **3:02の広告との因果**：この直しで、ミオが広告を押す理由に「二人の時間」だけでなく「この一人の時間」が入る。『あなたの一日は、28時間になる』の四時間は、彼女にとって半分は自分のもの。13でミオが帯を六時から十時まで引くとき、観客はその四時間に、二人と、2:00の外階段の両方を見る。台詞は足さない。

### 喜びの夜の赤信号（aの直し）：同じ種をもう一つ
aの「倉田は、ミオの顔を見ている。顔に残っていた笑いが、少しずつ、引いていく。」は、**誰の笑いが引くのか**が読みにくい（倉田の顔か、ミオの顔か）。ミオの笑いが引くなら、二人に小さな傷がつく（第一幕で割らない固定とぶつかる）。
→
```
　ミオは、まだ通りの奥を見ている。笑っている。
　倉田は、その横顔を見ている。
```
理由：倉田が失ったのは、**ミオが一人で持てた一瞬**。ミオは損をしていない（一人で見て、まだうれしい）。倉田だけが、自分の眠りのせいで彼女の「いま」の外にいたと知る＝課題の「倉田の怖さを早めに」が、ミオを傷つけずに立つ。そして「先に眠らなくなったのは、彼女のほう」の最初の画が、ここで一度だけ出る。
- ミオ「……全部、青だった」／倉田「いつ」／ミオ「いま」…**台詞の耳として良い**。「いつ」に「いま」で返す食い違いで笑いが一つ、意味が一つ。変えない。
- 次の「倉田が、見上げる。」→白い窓の「何人」「……八」は、この順で正しい（怖さ→眠らない人の窓、が因果で並ぶ）。

### 7の合わせ方（11の暗証番号）
第8版の「倉田が、自分のスマホを出す。ミオの人差し指を取って、数字を四つ、押させる。錠が、開く。」の後に、
```
　ミオは、開いた画面を見ない。すぐ消して、倉田の胸ポケットへ返す。
　押した人差し指を、もう片方の手で握る。
```
理由：重さは「見ない」「すぐ返す」「指を握る」の三つの行為で出る（bの芯）。bの「倉田が消して渡す→ミオが一人で四つ押す」は、41:30で番号を覚えていた筋のためだが、一度自分の指で押しているので足りる。二行で済む。握った指は、41:30でその指が番号を押すときに、観客の中で思い出される。

### 8の耳の直し（12の56:10、b）
```
倉田「……音、切って」
ミオ「切ってる」
倉田「鳴ってる」
```
（bの「……それ、音」は何の音か一拍迷う。「音、切って」なら、打つ音のことだとすぐ分かる。ミオのスマホは消音で、鳴っていない＝倉田の耳だけに聞こえている。72時間目近くの体の代価〔音が聞こえる〕が、言い争いの中に紛れて出る。「切ってる」「鳴ってる」は些細な訂正で、笑いが一つ残る）
- bの「ミオ「揺らさないで」」は残す。苛立ちは「揺らさないで」（ミオ）と「音、切って」（倉田）で一度ずつ、二人が一回ずつ。仲直りの言葉がなく、膝に置かれる左手で終わる形も残す。

### 二案の判定
**判定1　寝顔の写真を見つける場所：案X＝12の41:30（b）／案Y＝13（a＋cを直した形）**
- **Yを採る**。
- 理由1（監督の課題）：「13で倉田だけがそれに気づく一拍」。Xだと気づきが12で済み、13は繰り返しになる。
- 理由2（12の重さ）：41:30はすでに第一幕でいちばん長い拍（眠る→開ける→錠→撮る→受付の女→真壁→見つける）。ここに遡る五行を足すと、「開けられた自分の目」という一つの画が、黄色の寝顔に食われる。12は「見られていたのは自分」、13は「もう見られないのは彼女」と、一場に一つずつ。
- 理由3（画と光）：13の受付は白い窓の光の中。白の中に一枚だけ黄色、が凡例だけで言える場所は13しかない（12の41:30は夜の白い天井で、黄色が立たない）。
- Xから残すもの：bの「自分の目、自分の目、自分の目が、上へ流れていく」の画は、13の「目。目。目。」に移して使う（写真を遡る一行＝監査の小も、ここで閉じる）。

**判定2　13の気づきの一拍：案P＝cの指（閉じようとして閉じない。ミオは気づかない）／案Q＝ミオが振り向いて、自分の指で自分の目を開けて見せる（q1の別案）**
- **Pを採る**（黄色の一枚を前に置き、ミオの目は「予定表を見ている」に替えた形）。
- 理由：Qは笑いが強いが、縦の棒の拍の「倉田の眠りを、ミオが冗談と読んで応える」と同じ形のズレが続く。キー場面のズレは一つ（縦の棒）に絞り、気づきは倉田一人の、台詞のない四行に置く。Pの手は第三幕の中心の反転と36の手（上がって、戻る）の前の一回になり、「もう一度あの寝顔を見たい」が13の時点で紙に残る。
