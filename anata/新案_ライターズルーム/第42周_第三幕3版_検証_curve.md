# 注意曲線（通し） 第三幕 42=5 43=4 44=3 45=3 46=4 47=3 48=4 結末=5（平均約3.9）。第一幕平均4.3、第二幕平均3.8
- 42：「やらないで」「決めるの、わたし」を「あなたは、だんだん」で押し切り、あくびで眠らせる。一晩の寝顔、眉のしわを伸ばすと戻る、握った手が開かない。
- 43：「……真壁さんとも、寝てたじゃん」で空気が止まる。記録の読み上げがこの映画でいちばん「説明」に近く長い。「首。横に、一回」が初見で一拍迷う。
- 44：状態の確かめ。45：「削除」の意味が割れる（眠らされたことの拒否か、連続記録を守ったのか）。
- 46：ブラインドを一枚ずつ、最後のすきまの顔、自分で耳をふさぐ、録音した自分の声で眠る＝ミオが自分の力で眠る場面として届いた。倉田がガードレールで眠り青の並びを誰も見ていない。
- 47：8秒は既知で山にならない、¥780を取るのは冷たく効くが二つがつながらない。「わたしの案です」は良い台詞。
- 48：コードを抜く・布団を粗大ごみ・隣の『小松』の布団で予感。処理券の名前はやや記号的。
- 結末：全員が眠る中で一人起きている倉田の画は強い。ミオは先にテレビを抜き、自分の数字が『0』になり「反応なし」と打つ。動機の読みが三つに割れる（ミオを放送で眠らせたい／青の並びを見せたい／ただ壊れていく）。「……あなたは」が誰に向けた言葉か分からない＝余韻か曖昧か紙一重。
