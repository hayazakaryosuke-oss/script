# ブレイントラスト v47　bt_lab（サンダンス脚本ラボの長年のアドバイザー）

## 1. 点数
**8.1**　息に合わせて頭が「上がる・下がる」という身体の動き一つに、恋の状態を全部預けている。この設計は80分の小品の背骨として強い。ただ第二幕で倉田の欲が紙から消え、真壁の線が決まらず、最後の行為の宛先もぼやける。そのため、一本の線が中盤で二本に割れている。

## 2. 効いている所
- **息の上下が、そのまま関係になっている。** 3「倉田の寝息で、ミオの頭が、上がる。下がる。」→13「上がらない。下がらない。」→19 真壁の胸で「また、ゆっくり運ばれはじめる」。台詞なしで、始まり・ひび・裏切りに見えるものを同じ画で語る。19で倉田がミオを自分の胸へ連れてくるが、速い息では運べないと分かる。この作品でいちばん残酷で正確なターン。
- **22の記録の読み上げ。** 「これは、わたし」「耳栓、二つとも外した」「顔、見たかったから」「これで、よかったのに」。ミオは、自分で選んで眠った過去を明かす。それで21の「倉田は、待たない」が取り返しのつかない行為になる。3の「寝たら、消す」が判決として戻ってくる。告白を説明でさせず、記録を読むという実務でさせている。
- **願いがいちばんひどい形で叶う。** 4の「全部、青だった。奥まで」「赤ですけど」が、25で誰もいない青の並びと「……あと、タクシー」になって叶う。写真は既読にならない。ミオは「反応なし」と打つ。仕事の報告の一語が、彼への返事にも読める。御霊前の女は始発に乗り遅れ、力が他人の生活を実際に壊す。

## 3. 最大の問題
**① 第二幕（9〜16）で、倉田の欲が紙から消える**
- どこで：9の署名の後。11「ノブに手をかける。回さない。」、12「残りのあくびを、殺す」、15「天井を見たまま」、16「答えない」。
- 観客の期待：一行の約束は「彼は力を隠す／彼女は講座を隠す」。二つの秘密がぶつかりかけ、隠すことに代価がつく場面を待つ。
- 紙での行動：ミオの秘密は9（全体の約三分の一）で倉田にばれる。倉田は講座に入り、それで終わる。以後の倉田は、見て、引いて、我慢するだけ。力を隠すために何かを失う選択は、一度もない。動いているのはミオ（夜間電話、真壁、16の気づき）。
- ズレ・なぜ問題か：中盤だけ主人公がミオに替わり、倉田は見ている人になる。21で倉田は「待たない」を選ぶ。そこまでに要るのは「彼女を眠らせたい／自分が運ぶ側でいたい」という欲の積み上げだが、紙では13の一場面しかない。このままだと21は人物から出た行為ではなく、急に来た暴力に見える。

**② 真壁の線を、紙が決めていない**
- どこで：10「ミオの顔で、目が止まる」、11「右の耳だけが、赤い」、12 バンドの手渡しと札の『真壁／沢井』、19「真壁の手が招く」。
- 観客の期待：第二幕のエンジンは「ミオが別の男の息で眠る」こと。観客はまず「これは浮気か」を知りたがる。
- 紙での行動：真壁には欲がない。14で、ミオが右の手首で真壁の412日を守っているらしいことはかすかに分かる。しかし真壁が何を望み、ミオに何を頼んだのかは、一度も行為として書かれていない。
- ズレ・なぜ問題か：22の「真壁さんとも、寝てたじゃん」は、倉田の見当違いのつもりで置かれているはずだ。しかし観客も同じ疑いを抱えたままなので、袖を上げるミオの反撃が答えとして読み切れない。三角関係にするのか、眠りの取引にするのか、一つの行為で紙に決めてほしい。

**③ 25のあくびの宛先が書かれていない**
- どこで：24「倉田の目は、『4:30』から動かない」→25「ミオ：起きてる」の写真で親指が止まる→「口の前の手を、膝へ下ろす」→レンズの前へ。
- 観客の期待：24の「家で」から、倉田が彼女の朝枠に何かをすることは分かる。
- 紙での行動：手を下ろす所までは、倉田がはっきり選んでいる。しかし狙いが三つのどれなのかは書かれていない。彼女を眠らせることか、彼女の仕事を止めることか、街ごと眠らせて一人になることか。
- ズレ・なぜ問題か：クライマックスの行為は、主人公がいちばんはっきり意図した選択であるべきだ。宛先がないと、結果（反応なし・始発・既読なし）は強いのに、選択ではなく事件に見える。21の「相手の意思を飛ばす」を広げた行為だと読めれば、結末の重さは倍になる。

## 4. 速すぎて分からなくなった所・飛んだ所
- 11：二時の電話と赤い右耳。真壁の用件が12まで分からない。
- 14：「金曜は、寝てて」。倉田を外して休ませたいのか、切り離したいのか、どちらにも読める。15で倉田が起きていると決める根拠は、この一行の読み方に懸かっている。
- 規則が二本ある：10の「※横になって三十分以上」と、14の『睡眠中』表示。20で座って眠った六人に赤線が引かれる理由を、読み手が自分で組み立てることになる。
- 22「胸が、ふくらまない」。体重をかけるのが確かめなのか、一瞬の加害なのか読めない。
- 24：倉田が老配達員の取り逃した仕事を受ける。落ちていく行為なのか、生活へ戻る行為なのか、25とつながらない。
- 結末の「目が、一つ、開いている」と「……あなたは」。誰に向けたのか、繰り返すのか、自分にかけるのか、開きすぎている。

## 5. 観客が持ち帰るもの
- 一行：好きな人がいつ眠るかを自分で決めた男が、街じゅうを眠らせ、望んでいた「青の並び」を一人で撮り、それが誰にも読まれない。
- 狙いとの一致：おおむね合っている。既読なし、「反応なし」、母の帯に触れない親指、乗り遅れた弔問の女。どれも救いや許しを置かせない。「あと、タクシー」で、願いはいちばんひどい形で叶っている。ただし③の宛先が空いているので、観客はこれを「彼の選択の帰結」ではなく「力の暴走」と受け取りかねない。暴走と読まれると同情が残り、狙いより甘くなる。最後の「……あなたは」も同じだ。また誰かを眠らせる兆しとも、自分を眠らせたい祈りとも読める。祈りと読まれれば、苦さが救いの側へ傾く。
