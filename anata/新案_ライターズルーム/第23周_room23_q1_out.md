## 要点（5行）
1. 試しで恋と笑いとして立っているのは **10（口上を混ぜる→寝たふりといびきで笑い返す→「合わせない」）**。ここは三つの原稿の中でいちばん良い。**8bの電球は「布団を断られた直後に、裏から暗くする」順なので、第三幕の罪（「やらないで」を越える）の小さな写しに読める**。順を逆にする（こっそり→見つかる→表から頼む→断られる→引く→ミオが一本足す）。6は紙の上では「眠りを延ばす」で、試しには読めない。数えずに、試しは8b・10の二度にする（課題の「二〜三度」に入る）。
2. 12（b）の71:59は、説明なしで読める。秒の数字が迷いの長さを測り、髪を耳にかけた指がそのまま耳たぶをつまむので、「見る」と「起こす」が一つの手の中でぶつかる。**第一幕の葛藤の頂点はここ**。13（c）の「撮らない」は行為としては読めるが、理由が「偽物だから撮らない」とも読める。中盤は、手を頭に置く・待つ・まぶたの下で目が動く・笑わない、と「起きないこと」が四つ続く。四人が読めなかった「閉じかけて、止まる」と同じ型に戻ってしまう。cの入り（倉田が画面のミオの顔を広げる→ミオが気づいて差し出す）に、終わりは「押さない→12と同じ指で耳たぶをつまむ→ミオが吹き出す→見上げる目を見てからペンを取る」を組み合わせた案を出す。
3. 台詞の型はおおむね崩れた（「いつ」「いま」「正解」は消えた。台詞頭の「……」は1〜13で大きく減った）。倉田の決まりを一つ足す：**倉田は、ごまかす時・嘘の時だけ丁寧語になる**（「切れましたね」「赤ですけど」「いびきが、雑です」「起きてます。ずっと」）。**本当のことは常体で言う**（「寝てただけ」「あれは、本物」）。この決まりから外れている行を直す。
4. 原稿どうしの食い違いは主に六つある。肩に頭を落とす形が6・8b・12・13の四回に重なること、13の寝たふりの形、13で署名の途中に一瞬眠る拍、72:00を水にするか音にするか、11と10bの『オフラインにする』の重なり、11〜13が尺の予算を+約1.4分超えていること。判定と直し方は4節に書いた。

## 2　12のせめぎあいと13の「撮らない」：説明なしで読めるか／葛藤の頂点として強いか

### 12（原稿b 12-7）：読める。頂点として強い。採る
- 6の形（肩・唇につく髪・映った寝顔）で始まり、「首を戻さない」で分かれる。倉田はガラスの寝顔では足りず、自分の指で髪をかけて本物を見る。同じ指が耳たぶをつまむ。**迷いが台詞ではなく、指の動きの続きと、秒の数字（52→56→58）で測られている**。起こすのが「最後の一秒」なので、取れるだけの秒を取った、という欲の大きさまで読める。
- 髪を耳にかけるのは、10でミオが自分でした差し出しの身支度。それを倉田の手でする、いちばん小さな「取る」になる。恋人どうしのやさしい手つきの範囲に収まっていて、支配には読めない。眠りも写真も取らずに、起こして終わる。bの監督判断1は**本案（指で髪をかける）**を推す。
- 直し一つ。
この行
```
　本物の寝顔が、近い。
```
→
```
　目の前に、寝顔。唇のあいだが、開いている。
```
（「本物の」は書き手の形容詞。5の決まり（寝てる人は、開く）で、本当に眠っていると観客に判らせる。）

### 72:00（原稿b 12-8）：音（始発の継ぎ目）を採る
- 「十一」「十」「十一両」「最後のは、二回鳴った」。ミオは単位をつけて押し切り、倉田は数え方のほうを直す。二人の言葉の型の違いが、そのまま喜びの笑いになる。「何時／火曜の、朝／正解」の答え合わせより、ずっと良い。
- 弱いところ：8b・36で「遠くで、始発が高架を渡っていく」が普通に聞こえるので、12で聞こえることだけでは「二人にしか起きない」にならない。56:10の「切ってる」「鳴ってる」（倉田にだけ聞こえる音）が下ごしらえになっている、という読みは合っている。そのうえで、ガラスの部屋は外の音が上がってこない、を一度だけ置く。
  - 足す一行（00:00の終わり、または08:41）：「　ガラスの下の大通りを、バイクが一台、走っていく。音は、上がってこない。」（+25字ほど）
- 揃いのTシャツの二人が「顔を上げない」も効いている（同じ72時間でも、二人にしか起きない）。

### 13（原稿c）：撮らない行為は読める。ただし二つ問題がある
1. 「撮らない」理由が二通りに読める。cの設計では、口が閉じている（5の決まり）から寝たふりだと判る→押さない。だと、「偽物は要らない、本物の寝顔が欲しい」とも読める（第三幕へ向かう欲の芽としては鋭い）。一方で、課題の「払う理由＝起きている彼女を選ぶ」はぼやける。
2. 中盤が「起きないこと」の連続になっている（シャッターは鳴らない／手を置いたまま動かない／ミオは待っている／受付の女が窓のほうを向く／まぶたの下で目が動く／笑わずに目を開ける）。四人が読めなかった「閉じかけて、止まる」と同じ型。さらに、転換点1が「うれしい出来事」（原点の芯3）であるべきところで、ミオが「笑わない」一拍が入り、二人のあいだに温度の低い瞬間ができる。

### 13の組み合わせ案（cの入り＋行為で終わる）
cの1〜7行目（ランプ〜「ミオも、指を二本、立てる。それから、財布の中をのぞく。」）と、「倉田は、ペンを置く。スマホを上げる。」〜「財布を、膝に置く。」はcのまま。そのあと（cの「ミオは、頭を、倉田の肩へ落とす。」から「それから、ペンを取る。」まで）を、次に替える。
```
　ミオは、申込書の横に、頬をのせる。目を、閉じる。口が、少し開く。
　画面いっぱいに、ランプの明かりの中の、ミオの顔。
　倉田の親指が、シャッターの上にある。
　押さない。
　倉田は、スマホを机に伏せる。指で、ミオの耳たぶを、つまむ。
　ミオの目が、開く。机に頬をのせたまま、倉田を見上げる。吹き出す。
　倉田は、その目を見ている。それから、ペンを取る。
```
そのあとはcのまま（署名の途中で一瞬眠る／『4:12』／一括）。ただし、次の一行は直す。
この行
```
　ミオが、左の欄の伸びた棒を、人差し指で上から下までなぞる。笑う。
```
→
```
　ミオが、左の欄の伸びた棒を、人差し指で上から下までなぞる。
```
（笑いは「吹き出す」に一回だけ。ミオの返事は、自分の『オ』の棒を紙の端まで引く行為で出す。）

- 読み：ミオは倉田の決まり（口が開く）どおりの寝顔を、自分から差し出す（10の寝たふりの二度目。今度は欲しがられていると知ったうえで、合わせてやる）。倉田は押さない（10のスイッチと同じ語。どちらも「取らない」）。12で寝顔を終わらせたのと同じ指（耳たぶ）で起こす。12は試験のため、13は理由がない。**理由のない「起きて」が、払う理由になる**。ミオは笑い、机の高さから見上げる。3の「床に近い高さで、目が合う」の反復で、出会いの目の高さに戻ってから署名する。
- 代価は下に残る：差し出された寝顔を断ったすぐあとに、倉田自身のまぶたが落ちて棒が伸びる（ミオは冗談と読む）。「もう寝顔は見られない」を、倉田の体のほうが先に知っている。
- 光：頬を机にのせるので、顔の半分にランプの橙が落ちる。寝たふりの顔が、凡例の「自分で眠った人の朝の色」をまとう。偽物の黄色の一枚で、10の黄色い写真は13で開かずに済む（cの判断どおり、第二幕へ送る）。cの「顔には当てない」から変わるので、画と光の担当の確認が要る。
- 字数：cの13（約2.3分）から約−0.15分。
- 葛藤の頂点の置き方：**12の71:59が頂点**（見る／起こす。秒が測る）→72:00が喜びの頂点（二人にしか聞こえない）→13は、選び終えたあとの軽い反復（差し出された寝顔を取らずに「起きて」と言い、署名する）。13にもう一度重い沈黙を積まないほうが、転換点1が原点どおり「うれしい」で切れる。

## 3　台詞の型（人物ごとの言葉づかい）
