# 第45周 盲検比較（長編の構成に強い脚本家の視点）

採点は「脚本として」。紙に書かれた構成・人物・場面の行為・画と音の設計だけを見る。演技・撮影・音楽・評判は入れない。基準作（9.5）とも、その脚本と比べる。骨組みとして、場面の選び方・並び・欲と代価の上がり方・80分で追えるかを見た。

## 1. 点数と勝敗
- **案X：8.4**
- **案Y：8.1**
- **案Xの弱い勝ち。** 背骨の因果と三幕の釣り合いではXが上。世界の手ざわり、他人が払う代価、結末の仕込みの経済ではYが上。

## 2. 決め手三つ
1. **「眠る胸」の線が、倉田の選択の結果として組まれている（X 4→12→16→20→22）。** 12「頭が、上がる。下がる」（二人とも知らない）。16で倉田が眠るのをやめると「頭は、上がらない。下がらない」。そのあと「三時、呼ばれもしないのに、ミオは自分で靴を履く」。20の真壁の胸は、倉田が自分で捨てたものの代わりとして立ち、22「4:00『1%』で倉田が眠る。その寝息で、ミオの頭が上がる」で輪が閉じる。Yは彼の本当に眠る胸を3で一度見せるだけで（10は寝たふりの胸）、17の扉が「失う」より「知る」に寄る。
2. **一場面に一段の状態変化と、三幕の釣り合い。** 0の物差し「誰が起き、誰が眠り、誰が誰の寝顔を見ているか」が27場面すべてにかかっている。三幕は22.8／32.6／22.8分。Yは22.6／39.8／18.0分で、15（5.8分）と17（6.2分）の重い場面が中盤の後ろに続き、反転の後の第三幕が細い。
3. **ミオに向かう力の使い方が、同意の外へ一段ずつ進む。** X 8のマスク（他人で試す）→14の罠（力を使わずに眠らせようとする）→18「ミオも、眠れるよ」→19の画面ごし→20の部屋→22の「やらないで」越え。どの段も恋の線の上で一段ずつ深くなる。冒頭と結末の対句も揃っている（1「……いたんですか」「いました」⇔27「……起きてたんですか」「起きてました」）。Yの結末「……寝ないんですか」「起きてました」は対句がずれる。

## 3. 勝った案（X）の弱点三つ
1. **ミオが知る場面が偶然に頼っている。** 17は、部屋に倉田とアベさんしかいない時に、ミオがたまたま給水機の前にいる。13も、講座のビルの向かいがミオの会社の通用口という地理の都合。発見と目撃という大事な二点が、人物の行為ではなく位置の偶然で起きている。
2. **他人が払う代価が薄い。** 31を切ったので、街が払う代価は年配の配達員一人（7・8・26）に細った。アベさんは17と20で落ちるが、何を失ったかが紙にない。真壁も第三幕で何も払わない。結末で「街を眠らせる」重さの手前に、他人の生活が削られる具体が足りない。
3. **第一幕と結末が重い。** 再会（2）と勝負（3）が分かれ、喜びの区間は約6分しかない。最初の嘘「……四時まで、です」を切ったので、23「……四時まで」が一人で立つ。結末は2,650字に九つの拍と二つの差しこみがあり、4:29の「コードを抜く」には前振りがない。

## 4. 負けた案（Y）から移すべきもの
- **Y2の統合**：再会と「目、閉じたら負け」を同じ夜・同じ店にする。X2とX3を一つにして約400字が浮く。
- **Y3の外階段の一拍**：浮いた字数でX4の頭に「……四時まで、です」（最初の嘘）とサドルの跡を戻し、X23で回収する。
- **Y11のアベさんの宅建の過去問と、白い升目九つ**：X13（倉田が部屋を逃げる時、指のあいだから半分もれる）に入れる。X20の明けに「……次、なかった」を置き、他人の代価を一つの顔に積む。
- **Y24（400字）の前夜**：コードを抜いて束ねる手と、アラーム『3:30』の伏せた電話。結末の差しこみの仕込みにする。
- **Y8の受付票**：肩で眠りかけたミオの画面の受付票を倉田が読み、「読んだと言わない」。追える理由を画で渡す。X10のミオの爪の跡と並べて置ける。
- **Y15の「肩が、下りる」**：記録を上へたどって、9/9の芝生が自分の体ではなかったと知る安堵。X17の発見の後に足すと、X23「これで、よかったのに」の苦さが深くなる。
- **Yの本文化の物差し③〜⑤**：あくびの形を場面ごとに変える、「上がる。下がる」の回数、8秒の回数。そのまま採る。

## 5. 80分で観客が迷いそうな所
- **手の甲の線**：X8「頬に三本が逆さに写る」「水飲み場で洗う」、X12「石けんで二度洗う」。観客は「洗ったから消えた」と読み、「眠ると消える」決まりと区別がつかない。消える画は「口が開く・寝息」の直後に一度だけにする。結末の〔手4＋点〕の「点」も紙の上では読めない。
- **講座の夜間電話**：X15の電話の女「何か読んでてもらえますか」で、「眠らない講座」がなぜ人を眠らせる電話を受けるのかが一行もない。ミオの三時の仕事が分からなくなる。
- **ミオの体の癖**：眠る人の胸でしか休めないことは台詞にしない決まり。そのため15の膝掛けや20の真壁の胸は、浮気と読まれうる。二重の意味を狙うなら、12と16で観客が癖を確実に覚えている必要がある。
- **結末の時刻**：二十分の決まりを外したので、4:58に起きだすことと5:18に女が起きることは、7の『6:33』→『6:53』（Yの書き方）のような時計の対で一度教えておかないと、偶然に見える。
