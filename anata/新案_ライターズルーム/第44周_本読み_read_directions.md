# 本読み 第44周　ト書きの読み手（チーフ助監督を兼ねる）
範囲は「本文（仮）」の1〜48と結末。ト書きは約51,800字（第一幕14,200／第二幕27,500／第三幕10,200）、台詞は約2,930字。

## 1. 言いにくいト書き（上位8）
1. 27「『阿部』の『4:21』が『4:22』に、『倉田 修』の『4:03』が…」　直前の『2:58』『睡眠中 3:54』と合わせて、h:mmの数字が五つ続く。時刻か眠った長さか、音では分からない。→「倉田 修の眠った時間が、四時間三分から四分になる」
2. 「『22:07:00』。日曜、午前三時七分。」の型が8回（18で5回、23・24・38）。数字を二つ続けると、どちらも耳に残らない。→ 時刻は柱だけに書く
3. 31「道の向こうで、倉田の顎が、上がる。……音は、こちらへ来ない」　視点がミオの側に移ったことを、耳は受け取れない。→「ミオの側から。」を足す
4. 38「吸う。吐く。吸う。二つ目で、息が、追い越す」　何の「二つ目」か分からない。→「三つ目の吸う息が、膝掛けより先に来る」
5. 1「男の手がそれに触れて、跳ねる」　跳ねるのが手かリュックか分からない。
6. 26「ミオの顔が、落ちる」　「落ちる」は62回あり、ほぼ眠りの合図。ここだけは落胆の意味なので、耳は「寝た」と取る。→「口の端が、下りる」
7. 19の申込書の刷り三行＋早見表＋金額＋『※』と、28の『水／木／金 0:00〜6:00 予約済み』　画面の字を一息に読みきれない。→ 読ませる字を一行に絞る
8. 結末「壁に背をあずけて、ずり下がる。手すりに、額をつける」　主語がないので、誰が倒れたか数えられない。

## 2. 動機の切れ目（上位5）
1. 27　ミオは倉田の『4:04』に触れて笑ってから、倉田を外す規則の『す』を打つ。倉田を守るためか、自分のためかが決められない。
2. 43　ミオが倉田の胸に体重をかける。起こすためか、息を確かめるためか、罰か。
3. 結末　倉田がレンズの前に出る理由。手がかりは20分前の47にある『朝枠 沢井案』と「家で」だけで、結末には一語も出てこない。
4. 37　真壁が『全額』と書き、その紙を折り、缶コーヒーを二本買う。何を知り、何を決めたのかが紙にない。
5. 17　ミオがカップを持った倉田の前を素通りする。「こちらを見ない」はカメラ側の言い方で、ミオが気づいていないのか、見ないと決めたのかが書かれていない。

## 3. 説明に聞こえるト書き（上位5）
1. 結末「店と、通りのあいだ。」　作り手の注釈。
2. 44と結末の「にじまない。」　撮れない否定で、規則の報告になっている。
3. 36「人の流れは、手前で、階段のほうへ曲がっていく」　通行人が眠らない言い訳。
4. 13「布団では開いていた目が、閉じている。」　皮肉を読み手に解説している。
5. 「声は、ガラスを通らない」の類が4回（3・17・23・結末）。

## 4. ト書きの声の一貫性
- 呼び方が揺れる。「年配の配達員」5回と「年配の男」12回。「作業着の男」（4・11・35）が同じ人か別人か書かれていない。配達バッグの呼び方も4通り。
- 「さん」付けはアベさんだけ（24回）。
- 時刻は12だけ「夜、七時十分」の形。
- 外から書く声の中に、内側の言葉が入る（「来ない」「迷いがない」「一拍。」）。カメラの位置を書いたのは20の一か所だけ。

## 5. 指定の確かめ
(a) 「見ている」79回（18・21で各6）。「Xを見る。Yを見る。Zを見る。」「目が、Xへ行く。Yへ行く」の三つ重ねが約12回。「上が」121回、そのうち「上がる。下がる。」13回（第二幕に11）、「ふくらむ。しぼむ。」6回。「眉のあいだが、ほどける。まぶたが、下りる。唇が、少し、離れる。」は21・25・38でまったく同じ。「指が○○の上で、浮く」12回。あくびの手順（喉→口→長い、あくび→膝→寝息）は10場面でほぼ同じ形。「にじんで、輪になる」6回で、結末では一頁に2回。8字以下の文が三分の一あり、笑いの場面と別れの場面が同じ拍で読まれる。
(b) 耳で追えるのは、手の甲の線の本数、『睡眠 0分』、白い丸、電池の％、「にじむ／にじまない」。追えないのは38（台詞なしで約1,580字、全編で最長）。時刻が消え、三つの胸のどれの上の「上がる。下がる」なのか迷う。31も視点が道の両側を行き来し、追える物が信号しかない。
(c) 紙の上の使い分けは正確だが、声に出すと全部同じ音になる。時刻に聞こえる「長さ」が四種類ある：『睡眠中 3:54』『6:06』『ビデオ通話 21:14』（40では『22:08』と並ぶ）、録画・持ち時間の『0:41』『9:12』『19:19』。41秒・8秒の引き算は、耳ではできない。38では『05:11:00』と録画の『03:11』が同じ瞬間を指す。20の「七時／五時です」はこのずれを笑いにしていて効いている。17の「四時三十八分」と結末の『4:38』は耳では同じ音だが、百分離れていて韻にはならない。→ 画面の数字には「画面に」「録画の」「通話の長さ」と前置きして読む。
(d) 今の見積もりは字数の比例（約480字で1分。比27.6：52.8：19.7）。台詞は約10分で、ほぼ画の時間に重なる。9場面を実際の間で数え直すと、今の見積もりに対して1.0〜1.6倍（3・4・10は1.5〜1.6倍、19・25・38は1.4〜1.5倍、44は1.0倍、47は1.4倍、結末は1.3倍）。
- 第一幕は長くなる：約38〜47分。笑いが反応の間に頼っている。
- 第二幕は長くなる：約72〜87分。31の信号二巡、38の息合わせ、8秒の止まりが実時間で流れる。
- 第三幕は少し長くなる：約26〜30分。画面の差しこみで締まる所はあるが、結末の眠りの波で伸びる。
- 合計は約136〜164分。次の本読みで、3・38・結末をストップウォッチで測ってほしい。

## 6. この脚本を現場で撮りたいか：8／10
画と音の段取りがほぼ紙の上で決まっていて、小道具が筋を運んでいる。
- いちばん撮りたい場面：38。光の帯がミオの頬に一本だけ残って、「かちり」と閉まる。
- いちばん困る場面：結末の眠りの波。生中継と時刻を揃えなければならないうえ、誰が倒れたのかを数えられない。
