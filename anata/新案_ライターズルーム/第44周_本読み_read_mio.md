# 本読み　沢井ミオ（主演）

（脚本として、紙の上だけで読んだ。言い換えは例）

## 1. 言いにくい台詞　上位8つ
1. 30「……お目を閉じておられます」。「お目を／おられ」で舌が止まる。途中の固まる芝居（目が開いたまま止まる）はいい。例：「……目を、休めて、おられます」。
2. 繰り返しの通し「この配信の、最初の一時間で、予算の三割を、」（25・27・33・40・45・46・47で十五回ほど）。読点が四〜六拍ごとにあって、毎回同じ速さでしか言えない。例：47の二度目だけ読点を外して「この配信の最初の一時間で予算の三割を使い切ります」と一息で通す。十五回目だけが違って聞こえる。
3. 43「九月九日。六時、三十分ごろ。芝生。負け？って聞いた。修、うなずいた」。句点が五つあって息が続かない。後ろ半分は3で扱う。
4. 43「首。横に、一回。それで、よかった」。5(b)で扱う。
5. 19「最後の」。何の「最後」か口が決められない（2の1）。
6. 2「次の人の、冷めます」。「人の、」の読点で切れて意味がほどける。例：「次の、冷めますよ」。
7. 47「木曜の朝枠。わたしが、見ます」。壁の予定表と同じ字を読み上げている。例：「野口」に指を置いて「これ。わたしが、見ます」。
8. 7「起きてるの、うちらだけ」。全編で一度だけの「うちら」が、ほかの台詞より若く聞こえる（4で扱う）。

## 2. 動機の切れ目　上位5つ
1. 19「最後の」。直前に「※」を指でたどり、『0分』を叩く。そのあと腕に頬をのせて寝顔を作る。「最後の（但し書き）」なのか「最後の（寝顔）」なのか、紙からは決められない。後者なら寝顔の線とつながる。例：「最後の、一枚」。
2. 22「平日も、いけます」で口の端が上がる。真壁の胸を知るのは27なので、この時点で何がうれしいのかが紙にない。睡眠外来を閉じたことからの逃げ、としか読めない。
3. 28「修。わたし、——」。倉田の浅くて速い胸を三度確かめたあとに何を言いかけるのかが空いている。そこへ真壁からの通知が来て「いけます」を選ぶ。言いかけた中身が決まらないと、選んだ重さが出ない（5(c)）。
4. 38で真壁の胸へ戻る所（5(d)）。
5. 47「わたしが、見ます」。仕事（案の日予算が半分になった、36）のためなのか、四時半（3「毎朝。四時半」）のためなのか。両方に読めるのはいい。ただ48でテレビの電源を抜くこととのつながりが細い。

## 3. 説明に聞こえる台詞　上位5つ
1. 43「負け？って聞いた。修、うなずいた」。その場にいた本人に、観客がもう見た11を話して聞かせている。例：記録の行だけを読み、ミオが自分で一回うなずいてみせる。
2. 43「決めたの、わたし」。主題をそのまま言っている。
3. 43「消して」「寝たら、消す」の二つ重ね。6のレシートを引くなら一行で足りる。例：「寝たら、消す」だけにして、甲を指でさす。
4. 47「わたしの案です」。7「わたしの」を受けているのはいい。ただ「わたしが、見ます」と並ぶと理由まで言ってしまう。どちらか一つでいい。
5. 43「顔、見たかったから」。34で見せた行為（耳栓を抜く）の理由を言葉にしている。ただ倉田にとっては初めて知ることで、残す価値がある。残すなら、ほかの「わたし」を減らして、ここだけが際立つようにする。

## 4. 声の一貫性
- 審判の声（「負け」「セーフ」「延長」「はずれ」「合わせない」「ペン」）は、3から43まで、ぶれずに通っている。いちばんの強み。
- 口ぐせ「いけます」（13・21・22・28・36、33の「いけません」）は、断れない人の声として一本通っている。47で「いけます」ではなく「見ます」と自分から名乗り出るのが、変化として効く。ここは触らないほうがいい。
- ぶれ：7「うちら」は一度きり。30・27の「起きております／おられます」は真壁の家の言葉づかいへの切り替えとして筋は通るが、「おられ」は行き過ぎ。42・43の「〜の、わたし」という倒置は、それまで一度も使われていない型で、急に作り手の声になる。
- 呼び方：「修」は14が初出。43「修、うなずいた」の三人称は、記録を読む声として成立している。

## 5. 指定の確かめ
**(a)** 声に出す「わたし」は8回。7「わたしの」、27「わたしで、よければ」、28「修。わたし、——」、42「決めるの、わたし」、43「決めたの、わたし」「これは、わたし」、47「わたしが、見ます」「わたしの案です」。
一・二幕で3回なのに対し、42〜43の二場に3回、しかも文の末尾に「わたし」を置く同じ型で集まっている。ここが作り手の声に聞こえる。
- 残す：42「決めるの、わたし」。目の前の行為（「眠れるよ」）を拒む台詞だから。
- 残す：「これは、わたし」。全部を倉田のせいにしない、という公平の行為だから。
- 残す：47の二つ。会社の言葉づかいで自然に聞こえ、7を受けている。
- 替える：43「決めたの、わたし」。例：「寝てた」（認めるだけで、言い訳をしない）、または黙って、後の「袖をひじまで上げる」をここへ前に出す。

**(b)** 初見の耳には、まず伝わらない。「横に」が受けるのは三行前の「うなずいた」と、約八十分前の11だが、あいだに二つの記録が挟まる。さらに「それで、よかった」が「そうしてくれればよかった（のに）」なのか「それでよかった（いまは許す）」なのか、口が決められない。直後の倉田の「うなずく」（縦）が皮肉として立つかどうかも、ここで決まる。例：ミオが自分の首を横に一回振ってみせて「これで、よかったのに」。言葉を半分、行為にする。

**(c)** 言える。三度とも違う中身で言える。ただし条件がある。14は中身が画面に出ている（『人数 2』）。42は43の記録の話と読める。28だけが空いている。しかも14と28は「修。○○、——」と同じ形で、耳には同じ一打に聞こえる。遮るものは、14が倉田の「寝よう」、28が自分の通知、42が倉田の催眠と三通りに違い、12（ミオは待つ）と42（倉田は待たない）の対もいい。例：28は名前を呼ばずに「わたし、——」から入る。あるいは言いかける直前に、キーリングの銀の鍵に指が行く、など中身の手がかりを一つ置く。

**(d)** 38では行為として渡されている。胸に手のひらを置く→一拍→赤い縁の目を見る→自分で頭を戻す→袖は離さない。ただ、彼女は耳栓をしていて、半分眠っている。だから「彼の胸では眠れない」という体の都合とも読めるし、「彼を休ませる」という選択とも読める。最初に真壁の胸を選んだ瞬間（27で手を引いてから38までのあいだ）は紙にない。俳優としては、27の終わり「頭は、どちらにも、動かない」から38までに、自分で一度傾く小さな一拍がほしい。二・三幕での自分からの選択（19の一括、27の「す」、32の鍵、39「いいです」、46のブラインド、47の名乗り出）は十分に渡されている。

## 6. 演じたいか　8／10
台詞は少ないが、どれも手と目で選ぶ人の台詞で、作り手の声になるのが43の数行だけだから。
- いちばん演じたい場面：27。知らない人に読み聞かせ、背中で真壁の寝息を聞きながら「す」を打ち直す。
- いちばん困る場面：43の流し。記録を読む三行と「首。横に、一回」で、何を言っているのかを自分で決めきれない。
