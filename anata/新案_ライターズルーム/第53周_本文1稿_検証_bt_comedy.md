# 第53周 ブレイントラスト：コメディ脚本家（笑いの設計・間・回収）

読んだもの：new_body.md のみ（初見・通読一回＋気になった所の読み返し）
採点は「脚本として」。紙に書かれていることだけを見ている。

## 1. 点
**8.6 / 10**

仕込みと回収の量と精度は高い。「何してた？」の言い直し、「窓に」、「花粉→ブタクサ→キンモクセイ」、「ワン、」から「……テン」まで、笑いの仕込みがそのまま痛みの回収に変わっていく。基準作の脚本と比べて足りないのは、細かい所で笑いの「間」がにごっている点（下のノート）。土台は強い。

## 2. グッド・ノート（大きい順）

### ノート1：「……」が多すぎて、ねらった間が埋もれる
- **どこで**：全編。台詞のおよそ半分が「……」で始まる（倉田は九十行ほどのうち四十行あまり）。
- **観客が期待すること**：倉田の笑いは「すぐ返す真顔の訂正」だと、序盤で覚える。「いました」「二本、残ってます」「開いてます」「赤ですけど」「わざと、です」。どれも「……」がなく、間をおかずに返している。
- **人物がしたこと**：中盤からは同じ型の訂正にも「……」がつく。「……ブタクサ、です」「……キンモクセイ、です」「……受講生の方、です」「……配達、あるんで」。間をとってほしい台詞（「……窓にですけど」「……テン」）も、ふつうの返事も、同じ記号になっている。
- **そのズレ**：すぐ返すから笑える人が、紙の上ではいつも少し迷ってから話す人になっている。
- **なぜ問題か**：ねらって置いた「……」と、くせで付いた「……」の見分けがつかない。本読みでもテンポが一つに決まってしまい、いちばん効かせたい間（窓、テン）の重みが薄まる。
- （直すなら一行：「……」を残すのは、ためらいそのものが意味になる行だけにする。）

### ノート2：第3場「三百円も」の数が合わない
- **どこで**：第3場。倉田が会長に百円玉を一枚渡す→会長「百円」→もう一枚→ミオ「三百円も」。
- **観客が期待すること**：小銭の笑いでは、観客は枚数を数えている。ここまでは二枚、二百円。
- **人物がしたこと**：ミオが「三百円」と言う。
- **そのズレ**：ミオが大げさに言っているのか、書きまちがいなのか、紙からは分からない。ミオが数を盛る人だという仕込みも、ほかに見当たらない。
- **なぜ問題か**：「会長が手数料を自分の乾燥機に入れる」というオチの直前で、読み手が数え直して止まる。告白と同じ場面の小さな笑いなので、つまずきが目立つ。

### ノート3：第12場「テン、聞いてないんで」の理屈がひっかかる
- **どこで**：第12場。目を閉じた会長が「……ナイン。テン」まで数え、二つ目のあくびで倒れる。その後、ポスターの『0』を直そうとする会長に、倉田「……テン、聞いてないんで」。
- **観客が期待すること**：直前の場面で「テン」は実際に口に出ている。だから観客は「いや、言ってたよ」と思う。
- **人物がしたこと**：倉田は「テンは聞いていない」と断る。
- **そのズレ**：言いたいのは「倒れた相手の上で数えるテン（第7場の『ワン、』で止まったもの）がまだない」ということ。でも、すぐ前に会長が自分で数えた「テン」があるので、字のとおりに読むと倉田の言葉がまちがって聞こえる。
- **なぜ問題か**：この一行は、第23場で正の字を自分で足すところ、第25場で真壁の上で「……テン」と数え、拳が上がって止まるところへ続く背骨になっている。入口でつまずくと、第25場の「テン」が「やっと数えた」と効くまでに時間がかかる。

### ノート4：第25場から第26場へ走る理由が、観客の計算にまかされている
- **どこで**：第25場の終わり。「紙コップの『木』から、壁の『金』へ行く。『3:41』へ行く。倉田は、走る。」
- **観客が期待すること**：退会届で「ミオはここにいない」と分かった。では、どこにいるのか。倉田がどこへ、何に間に合おうとして走るのかを知りたい。
- **人物がしたこと**：曜日のズレを見て走り出す。
- **そのズレ**：『木　夜　ここ』は、紙の上では第2場で一度だけの約束。毎週の決まりとしては書かれていない。また「木曜の夜は夜明けまで」「四時半の天気で終わり」という締め切りも、走る倉田の側では示されていない。
- **なぜ問題か**：青信号が奥まで続く絵（第5場の反転）は強い。でも観客が締め切りを知らないので、追いかけではなく移動に見える。着いてから天気が四時半に替わる回収も、「間に合った／間に合わない」の笑いや痛みにまでならない。

### ノート5：最後の一瞬、倉田が何を選びかけているのかが二つに割れる
- **どこで**：第26場のラスト。アベさんのふつうのあくび→倉田の喉が上がる→「頬を叩きかけた手が、口の前で止まる」→「顎が、開きかける」→黒。
- **観客が期待すること**：最後に、口をどうするかで倉田の答えを見たい。覆う（人を守る）か、出す（眠らせる）か、叩く（自分は起きている）か。
- **人物がしたこと**：叩くのも、覆うのも、どちらも途中で止める。
- **そのズレ**：止まった手は「やっと自分も眠れる（一緒に眠る）」とも、「向かいのアベさんを第18場と同じやり方で眠らせかけている」とも読める。脚本の仕込みが、両方を同じくらい強く支えている。
- **なぜ問題か**：「倉田さんは」「……起きてます」の直後にあくびが来るのは、笑いの形として完ぺき（言ったそばから眠くなる）。けれど、その意味が「回復」と「同じあやまちのくり返し」に割れたまま終わる。観客が最後に持ち帰る気持ちが、笑いでも痛みでもなく「どっち？」になりやすい。開いた終わり方を選ぶこと自体は問題ではない。気になるのは、どちらとも決めきれない割れ方だという点。

## 3. いちばん効いた所 三つ

1. **第7場**
   「選手の膝が折れる。顔から、キャンバスへ落ちる。／会長の口が、反射で開く。／会長「ワン、」／会長の顎が、トップロープに落ちる。」
   →「年だな」「……俺、ダウンしました？」「……してない、です」
   ここで能力の正体が一度に分かる。数えはじめた審判がまず倒れる。この「ワン、」が、第12場の「テン、聞いてない」、第25場の「……テン」まで続く。

2. **第3場→第20場**
   ミオ（窓へ）「付き合ってもらえませんか」／倉田（窓へ）「はい」／倉田（会長へ）「……窓にですけど」／会長「百円」
   → 野口「付き合うって、話したんですか」／倉田「……窓に、ですけど」／野口「……窓に」
   同じ言い訳が、相手と目的を変えて、笑いから痛みに変わる。野口の「……窓に」で、他人の目から二人の関係の細さが見える。

3. **第26場**
   倉田（小声で）「……彼女が寝てる間、何してるんですか」／アベさん「……寝てます」／アベさん「倉田さんは」／倉田「……起きてます」
   第5場から続いてきた「何してた？」の最後の言い直し。初めて、恋敵に向けて聞く。答えが「寝てます」なので、笑えて、負けがはっきりする。

（次点：第13場「蓋が外れる。何も出ない」と「……今の、なしで」。第25場「講師に、なりませんか。あなたなら」「……配達、あるんで」。）

## 4. 一行で勧めるなら
眠れない男のあくびは人を眠らせ、眠れなかった女は別の男の袖をつまんで眠る。笑っているうちに「誰が誰の眠りを取ったのか」の話になっていく、深夜の恋愛喜劇。
