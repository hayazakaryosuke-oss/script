# 第54周 ブレイントラスト　配給会社の宣伝担当（初見の通読）

読んだもの：new_body.md のみ。採点は「脚本として」（紙に書かれていることだけ）。

## 1. 点

**8.3 / 10**

いちばん大事な一行（「あくびを見た人が眠る元ボクサー」）が、ジム・ガラスの部屋・外廊下・事務室で、画だけで何度も立っている。予告編に切れる画は、ここ数年読んだ脚本の中でも多い。「窓にですけど」「起きている者です」「目、閉じたら負け」と、口コミで真似される言葉もそろっている。
減点は、終わりの一画と、そこへ走る理由が、紙の上でまだ一つに決まっていないこと。それから講座のルールの小さな食い違い。基準作の脚本は、最後の一画で「何が起きたか」は迷わせず、「どう受け取るか」だけを観客に渡している。そこにまだ届いていない。

## 2. グッド・ノート

### ノート1（いちばん大きい）　最後の一画が「再発」にも「解放」にも読める
- **どこで**：26場の終わり。「頬を叩きかけた手が、口の前で止まる。甲に、短い線が並んでいる。指が、震えている。／顎が、開きかける。／倉田の顔。／黒。」
- **観客が期待すること**：その少し前に、倉田は「あなたは、」を自分で折って口をふさいだ。観客は、この人があくびと最後にどう付き合うのかを、最後の一画で見せてもらえると思っている。
- **人物がしたこと**：止めない。叩かない。ふさがない。顎が開きかけたところで切れる。
- **そのズレ**：これが「誰も見ていないから、やっと自分のためにあくびしていい」という意味なら、条件は12場の会長の「見えてりゃ、効くんだな」だけにある。14場ぶん前のことだ。この場面ではアベさんもミオも目を閉じているが、紙はそこへ読み手の目を向けていない。しかも直前の「線が並んでいる」「指が、震えている」は、13場・24場の「武器が出る前」と同じ並べ方になっている。初めて読む人には、また眠らせてしまう前ぶれに見える。
- **なぜ問題か**：見終わった人の口コミが「どういう意味だった？」ではなく「結局どうなった？」で割れる。宣伝としては、最後の一画を一行の言葉にできない。予告の締めも作れない。
- （直すなら一行）：開きかける前に、「誰の目も開いていない」ことを、倉田が見て確かめる画を一つだけ置く。

### ノート2　「木　夜　ここ」がなぜ「今、あそこ」になるのか
- **どこで**：25場。「倉田の目が、紙コップの『木』から、壁の『金』へ行く。『3:41』へ行く。／倉田は、走る。」
- **観客が期待すること**：クライマックスの最後の一押しは、ミオが残した何かを倉田が読み解いて、彼女の居場所にたどり着くことだ。
- **人物がしたこと**：9月8日の古い誘いのコップと、曜日のずれだけで走る。
- **そのズレ**：「木曜の夜はあそこ」が二人の決まりとして続いていた画が、紙にない。木曜に会ったのは、たぶん9月10日の一回だけで、それも映っていない。退会届の「眠れるので」も、場所を指していない。だから倉田が店に着いてミオがいるのは、ミオがアベさんを誘った結果で、倉田の読みが当たったからではない。
- **なぜ問題か**：主人公の最後の行動が、たまたまに見える。「なんでそこだとわかったの」という口コミが出る。予告の「彼女は、あそこにいる」という一行が、紙の上では裏付けられない。23場の店の場面が何日の何時なのかもあいまいで、手がかりにならない。

### ノート3　講座のルールが、自分で教えたルールとずれる
- **どこで**：10場の貼り紙「※横になって三十分以上続いた眠りを、睡眠として計測します」。11場のアベさん「座ってたんで、セーフです」。13場では、倒れてすぐにバンドが「睡眠中」になる（3:50〜4:10で二十分）。15場では、パイプ椅子に座ったまま眠ったアベさんの行に、赤い線が引かれる。
- **観客が期待すること**：アベさんが自分の指で二度叩いて教えたルールが、そのまま効くこと。
- **人物がしたこと**：座って二十分眠ったアベさんが、本科を外れる。「……次、なかった」。
- **そのズレ**：注意深い読み手ほど「それ、セーフのはずでは」と止まる。
- **なぜ問題か**：13場から15場は、倉田のあくびが他人の生活を壊した代価（三年の分割、宅建）を見せる大事な所だ。ルールが食い違って見えると、その痛みが「設定のミス」に化けてしまう。（直すなら一行）13場の新しい貼り紙に、測り方が変わったことを一言入れる。

### ノート4　カップをアベさんに渡す意味が、二つに読める
- **どこで**：22場。「紙コップの横腹に、書く。…『木　夜　ここ』。／コップを、ベンチの、アベさんの手の横に置く。」26場では、ミオがアベさんの袖をつまんで眠っている。
- **観客が期待すること**：「木　夜　ここ」は、2場・3場・4場で二人だけの合図として育ってきた。観客は、これを倉田との合図として持っている。
- **人物がしたこと**：会うのが二回目の男に、同じ言葉を書いて渡す。
- **そのズレ**：「眠れる場所を教えた」のか、「相手を替えた」のか、紙の上では決まらない。アベさんとミオの間で、恋ではないとわかる行為が、膝掛けの一画しかない。
- **なぜ問題か**：ヒロインへの好き嫌いが、ここで割れる（「乗り換えた」）。26場で倉田が二つのコップ（親指のにじみと、二度なぞった『ここ』）を見比べる画が、どっちの痛みなのか、読み手が受け取れない。

### ノート5　12場でミオが「知った」あと、講座に残る理由が見えない
- **どこで**：12場の外廊下。「その行を、親指で押さえる。／ミオの肩が、下りる。長い、息。／ミオは、紙コップの氷を一つ、口に入れる。」「ただいま」。
- **観客が期待すること**：寝落ちが病気ではなく倉田のあくびだったとわかったのなら、二十九万八千円の講座から離れるか、少なくとも残る理由が見えること。
- **人物がしたこと**：氷を噛んで、講座に残る。夜間電話を続ける。14場ではバンドを外して、自分の席だけを守る。
- **そのズレ**：「知った」画はきれいだが、そのあとにミオが何を選んだのかが行為として出てこない。16場の「真壁？」に答えない沈黙が、初めての読み手には「後ろめたさ」に見える。
- **なぜ問題か**：中盤のすれ違いが、ミオの意思ではなく、情報が伏せられていることで動いているように見える。17場の電話（予算の話で人を眠らせる）が「ミオもまた、人を眠らせる側になった」という鏡になっているのに、その鏡に気づく前に読み手が置いていかれる。

## 3. いちばん効いた所三つ

1. **3場のコインランドリー**：「付き合ってもらえませんか」「はい」／「……窓にですけど」／会長「百円」。20場の野口「付き合うって、話したんですか」「……窓に、ですけど」で、笑いが痛みに変わって返ってくる。口コミで真似される台詞。
2. **7場のジム**：クリンチから「離れぎわ、倉田の口が、大きく開く」→選手が落ちる→会長「ワン、」で会長も落ちる。説明の台詞なしで、この映画が何の映画かが一発でわかる。予告編の頭はここで決まり。
3. **24場のガラスの部屋**：窓際の女「炊飯器、六時に、な——」と、床のスマホから「お母さん？　……もしもし」。眠らされる側の生活が、一行ずつ切れていく。派手な画のまま、主人公に代価を払わせている。予告編のいちばんの見せ場で、そのまま口コミのネタになる。

## 4. 一行で人に勧めるなら

「あくびを見せた相手を眠らせてしまう元ボクサーが、眠れない恋人だけは眠らせちゃいけなかった——『目、閉じたら負け』の、深夜三時のラブコメ。」
