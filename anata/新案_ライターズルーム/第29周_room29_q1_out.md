## 0　先に結論（三つの原稿をまたいで、いちばん効くこと）

1. **ミオが休む「しるし」を、体の一つに揃える＝「指先の震えが、やむ」。**原稿aの「肩が寝息に合わせて上がって下がる」は、ト書きが意味を言ってしまう（同調＝親密）。一度目から「愛」に読め、疑いが立たない。原稿cの「まぶたが下りる・上がる」は居眠りに読め、『0分』の決まりとぶつかる。震えは、ミオの体の段（18 袋の持ち手→21・22 マグの面→24 留め具→27 指先）でもう紙に積んであるので、説明なしで「休んだ」に変わる。しかも**起きている倉田の前では、やまない**（25・27）。35で、真壁の寝息で震えがやみ、戸口の倉田の開いた目を見るとまた震え、真壁の顔へ戻るとやむ。原因（倉田が眠らないこと）が、台詞なしで一つの画に入る。
2. **ミオの一語を、23（聞こえる）→27（「……まだ」）→35（聞こえる）にする。**23の囁きは原稿cどおり年配の男の耳で一度だけ聞こえる形がいちばん強い（「同じ台詞に新しい相手」）。原稿bの27「……今夜は、いない」は35の「いる」と対になりすぎて図式に見える。「……まだ」にすると、寝たふりの倉田には「（あいつは）まだ起きてる」＝浮気の合図に聞こえ、二度目に読めば「（あなたが眠るのを）まだ待っている」になる。
3. **真壁の呼び方を一つだけ変える＝ミオにだけ「沢井さん」、ほかは全員「様」。**最初に倉田の耳に入るのは19（ロビー。声が聞こえる場所）。体を出さずに、男の引力が耳で立つ（第28周「真壁に引力がない」への、台詞の耳からの答え）。

## 1　15（原稿aの本文）

### 1-1　真壁の442分
- どこを：「真壁「日本の睡眠は、一日、四百四十二分。調べた三十三か国で、いちばん短い。つまり皆さんは、もう、世界でいちばん上手に、起きている」／倉田の顎が、胸へ落ちる。跳ね上がる。」
- どう変える：
```
真壁「日本の睡眠は、一日、四百四十二分です。調べた三十三か国で、いちばん、短い」
　倉田の顎が、胸へ落ちる。跳ね上がる。
真壁「つまり皆さんは、もう、世界でいちばん上手に、起きていらっしゃいます」
　倉田の顎が、また、落ちる。
```
- なぜ：①台詞の型。真壁は「丁寧語の完結文」（第一幕 台詞の型）。「いちばん短い」「起きている」で終わると、真壁の口でなくなる。28・35で真壁がアベさんに「お目を休めておられます」と言う敬語の高さに、ここで合わせる。②笑い。「いちばん上手に起きている」の売り文句の下で、顎が落ちる。売り物と体のずれを、間（ま）だけで見せる。講義を二つに割るのは第1版の形に戻すだけで、字数は増えない。

### 1-2　『07:00:00』の読み違い（監査の重大④を、行為で）
- どこを：「アベさん「……何時ですか」／倉田（窓を見て）「……五時」／アベさんは、手首を見る。」
- どう変える：
```
　隣の山から、作業着の女が顔を出す。アベさん。ガラスの奥の赤い数字を見る。『07:00:04』。
アベさん「……七時」
倉田（窓を見て）「五時です」
アベさん「……二時間、得した」
　アベさんは、手首を見る。『睡眠 6時間41分』。膝掛けを、頭までかぶり直す。
```
- なぜ：①赤い数字が経過時間であることを、他人の読み違いと倉田の些細な訂正で一度だけ見せる（注を読まなくても紙で分かる）。②アベさんの最初の一句が、身勝手な言い換え（眠った二時間を「得した」）。20の「あと二時間、もったいない」、「三十六」と同じ人の口になる（眠りを金と時間で数える、弁当工場の夜勤の人）。③倉田は他人には丁寧語（「五時です」）。原稿aの「……五時」は台詞頭の「……」を一つ増やすだけなので外す。

### 1-3　ロビーの光（ミオが暖かい明かりを出て、白へ戻る）
- どこを：「暗いロビー。低いソファに、灰色の膝掛けの山が一つ。」「ミオは、隣のソファに倉田を寝かせる。膝掛けを、顎の下まで引く。その顔を、見ている。／ミオは、一人で、ガラスの扉の中へ戻る。」
- どう変える：
```
　暗いロビー。床置きのランプが一つ、低いソファの端に、橙の明かりを落としている。灰色の膝掛けの山が一つ。
　ミオは、ランプの明かりの中に、倉田を寝かせる。膝掛けを、顎の下まで引く。しゃがんで、その顔を、見ている。
　ミオは、立つ。ガラスの白の中へ、一人で戻る。
```
- なぜ：第一幕の凡例（ランプの橙は二人の側、白は講座の側）を、ミオの体の動きで一度だけ跨がせる。暖かい明かりの中に残るのは、眠る倉田の顔。ミオは自分で白へ戻る（割れ目はミオの選択、という課題を、光でも言う）。光源は画面の中のランプとガラスの部屋の天井だけ。「輪」の語は光の輪に取っておくので使わない。
- 一枚で残る画は原稿aのまま（「膝掛けの山が二つ。その向こう、白く透けたガラスの中で、一つだけ高い机に、ミオが、まっすぐに立っている」）。手前の山にランプの橙が乗るので、橙と白の二層になる。

### 1-4　放送の道具を一つに（音の設計）
- どこを：「隅のパイプ椅子で、受付の女が、壁の受話器を取る。天井から、女の声。「始めます」。」（原稿a）と、原稿bの34・35の「ワイヤレスのマイク」
- どう変える：原稿bの35を採るなら、15を「受付の女が、ワイヤレスのマイクを口に当てる。天井から、女の声。「始めます」。」に。原稿aの34・35（壁の受話器『全館』）を採るなら、そのまま。
- なぜ：同じ天井の声に道具が二つあると、35の「誰の手で、どこから鳴るか」がぼける。35で倉田が「眠った列のあいだを歩く」には、手に持てるマイクのほうが画になる（壁の受話器だと、倉田は壁に縛られて、扉まで別の動きが要る）。

### 1-5　15で、ほかに足さないもの
- ミオは一言も話さない（原稿aの決め）を守る。「まぶたに指を当てる。開けない。」は、第一幕11の「寝たら、開けて」の裏として、いちばん強い一行。残す。
- 「その顔を、見ている。」は一拍だけ（二重の画の一回目）。15でしるし（震え）は出さない。

## 2　16・20・21（ビート）　二重の画：一度目は疑い、二度目は愛に読めるか

### 総評（三つの原稿をまたいで）
- 二重の画が「一度目に疑い」に読めるには、その直前に**疑う材料**（真壁の電話・真壁の呼び出し・嘘に聞こえる一語）が要る。16（2:00の『真壁先生』）・20（真壁の呼び出し）・23（3:02の電話と囁き）は、どれも材料を持っている。良い。
- 壊しているのは、原稿aの「ミオの肩が、倉田の寝息に合わせて、上がって、下がる」。ト書きが「同調＝親密」を言ってしまい、一度目から愛に読める。**16・23から外し、しるしは「指先の震えが、やむ」に揃える**（0の1）。
- 見せる距離を、三回とも変える（反復は相手・目的・代価を変える）：**16＝近い（倉田の薄目）／20＝遠い（ガラス越しの小さな姿と、頬に残った跡）／23＝画面越し（録画。見ているのは他人）**。同じ近さで三回見せると図式になる。

### 2-1　16（原稿aと原稿cの合わせ）
- どこを（原稿a）：「ミオが戻る。倉田の顔の前に横になる。壁に当たった明かりの縁で、目を開けたまま、寝顔を見ている。ミオの肩が、倉田の寝息に合わせて、上がって、下がる。」「倉田の目が、ミオの手首へ。『睡眠 0分』。倉田は何も言わない。」
- どう変える：
```
　ミオが戻る。倉田の顔の前に、横になる。腕に頬をのせて、横向き。
＊
　四時十分。倉田の目が、薄く開く。
　鼻と鼻のあいだが、手のひら一枚。ミオの目が、開いている。倉田を見ている。
　倉田の目が、閉じる。
＊
　七時。東の窓の黄色い光が、倉田の側にだけ落ちている。ミオは、白い側で、もう服を着て座っている。
倉田「……寝た？」
ミオ「寝た」
　倉田の目が、ミオの手首へ行く。『睡眠 0分』。
　倉田は、膝掛けを、頭までかぶる。
```
- なぜ：①16は倉田の欲（寝たふりの頼み・子守唄）が前半にある場面。同じ場面でミオの休むしるしまで見せると、**鏡の両方が一つの場面に並ぶ**（倉田は寝顔を見られない／ミオは寝顔の横で休める）。16ではミオの側を「薄目の前の、開いた目」だけにする（一度目は不気味な確かめ、二度目は休み）。しるしは出さない。②「何も言わない」は行為でない。15でアベさんがした「頭までかぶる」を倉田がする＝見なかったことにする行為（笑いで、痛い）。③「寝た」は原稿aの芯。ミオの型（決める時は一語）に合う。残す。

### 2-2　20（原稿aを短く。跡と遠景で）
- どこを（原稿a）：「2:10……ミオが出てくる。ソファの脇の床に座る。倉田の顔の高さ。ソファの縁に置いたミオの手が震えている。倉田の寝息。手の震えが、やむ。」「真壁「沢井様」」「2:31 倉田が目を覚ます。膝掛けが、顎の下まで引かれている。」
- どう変える（ビートの形）：
```
　ガラスの中から。暗いロビーの、膝掛けの山の脇の床に、小さな人影が一つ、座っている。紙コップを、山の中の頬へ当てている。
　ガラスの扉が開く。真壁が、扉を押さえている。人影が、立つ。
＊
　二時三十一分。倉田が、膝掛けの下で目を開ける。右の頬に、丸い水の跡。手の甲で、拭く。
　ローテーブルに、水の残った紙コップ。
（透けたガラスの中。真壁がカーディガンを脱いで、ミオの肩に掛け、袖を手首のところで二度折る。ミオが紙コップの底を真壁の頬に当てる。口が「何時」。真壁は時計を見ずに、口だけ動かす）
　倉田は、紙コップを取る。底を、自分の頬の、丸い跡の上に当てる。
```
- なぜ：①20の二重の画は「遠景」と「跡」で。一度目は「彼女は、俺が寝ているのを紙コップで確かめてから、真壁のところへ行った」（疑い）。24で「何時」が眠りの確かめだと分かると、二度目は「休み時間を、俺の寝顔の横で使っていた」になる。震えのしるしは20では出さない（近さがないと見えない。三回目を23に取っておく）。②倉田が自分の頬に当てる紙コップが、**彼女が当てた同じ所**に重なる（倉田は知らない。観客も一度目は知らない）。嫉妬のまねが、知らずに彼女の手の跡をなぞる。笑いで、痛い。③真壁の引力は原稿aのB（カーディガンと袖を二度折る手）を推す。原稿cのA（膝が抜けたミオの閉じた目を、真壁が二秒近くで見る）は強いが、「倉田がいちばん欲しいもの（彼女の閉じた目）」を真壁に渡す画で、20の跡（ミオの側）と同じ場面に入ると、二度目に読んだ時に鏡の両側が一つの場面に揃う。袖を折る手は寝顔に触れずに体温だけを渡し、22の「袖が、二度折ってある」で倉田と観客が同じ疑いを持てる（第28周「前半の不倫？を観客も一度は疑えるように」）。
- 外すもの（原稿a）：「2:40 ガラスの中で、ミオと真壁が事務室の扉へ入っていく。ミオの手に、牛乳の小さなボトルが二本」（20の行が多すぎる。牛乳は18と24で足りる）。

### 2-3　19・20　真壁の呼び方（台詞の耳）
- どこを（原稿a 19）：「天井から受付の女の声「再開します」。ミオは立ち、ガラスの中へ。」／（原稿a 20）「真壁「沢井様」」
- どう変える：
```
（19の終わり）
真壁「沢井さん」
　ミオは、立つ。ガラスの中へ戻る。
　倉田の手は、鳴らした指の形のまま、宙にある。
```
20の「沢井様」は削る（扉を押さえるだけ。声はガラス越しで聞こえない）。以後、真壁はミオにだけ「沢井さん」、ほかは「阿部様」「倉田様」（28・34・35の原稿bはすでにこの形）。
- なぜ：真壁の型（丁寧語の完結文・問いを言わない）の中で、呼び方の一段だけが崩れる。客から雇った人へ、の変化が、倉田と観客には「近い」に聞こえる。体を出さない引力を、耳で一つ。19の真壁「あの夜の方も、眠っていただけ、でしたね」の直後に置くと、二つの台詞で十年の秘密と呼び方が同時に倉田の耳に入る。

### 2-4　21（原稿aのアイマスク）
- どこを：「1:40 ミオは靴を履く。ドアの前で振り向く。ミオ「寝てて」（10bの『寝てて』）。」
- どう変える：残す。ただし振り向かない形に。「ミオは、靴を履く。ドアを開けたまま、背中で。ミオ「寝てて」」
- なぜ：振り向いて言うと「頼み」が顔に出て、二度目の意味（あなたが眠れば、ここで休めた）が一度目から透ける。背中で言えば、一度目は「早く寝て＝見られたくない」に読める。第一幕10bの文字『寝てて』を、声で、背中で、相手のいる所で言う（相手・代価を変えた反復）。

## 3　23（原稿cの本文）

### 3-1　「充電」（倉田の嘘の型）
- どこを：「ミオ「充電？」／倉田「充電」」
- どう変える：
```
ミオ「充電？」
倉田「充電、です」
　ミオの目が、本棚へ行く。膝のパソコンへ、戻る。
ミオ「うん」
```
- なぜ：第一幕の台詞の型「倉田は、ミオに対しては、ごまかす・嘘の時だけ丁寧語」（監督の判断14）。ここで一度だけ使うと、ミオは嘘を聞き分けて、8bの「……四時まで」と同じ「うん」で受け流す（関係の型：嘘を知って受け取る）。一度目は「ミオは録画に気づいたかもしれない」という疑いが一つ増え（3:02で光を手でふさぐのが、カメラから隠す手にも読める）、二度目は「起こさない手」に戻る。

### 3-2　3:02の光（録画に映るための光源と、二重の読み）
- どこを：「画面の隅に、『3:02』。眠る倉田の枕もとで、ミオのスマホが光る。ミオは、その光を、手のひらでふさぐ。片耳に、イヤホンを入れる。」
- どう変える：
```
　画面の隅に、『3:02』。眠る倉田の枕もとで、ミオのスマホが光る。ミオは、その光を、手のひらでふさぐ。
　膝のパソコンの蓋を、指一本分まで下ろす。細くなった白が、倉田の顔の上に、一本だけ残る。
　片耳に、イヤホンを入れる。
```
- なぜ：①実務：午前三時の暗い部屋で本棚のスマホが撮れるのは、画面の中の光源があるときだけ。ミオが手でふさげば、録画は黒になる。パソコンの細い白を一本残す（光源は画面の中だけ、の凡例どおり）。②二重の読み：一度目は「眠っているのを確かめるために顔を照らす」、二度目は「起こさずに、顔だけは見ていたい」。第一幕10で倉田がスタンドの首を曲げてミオの顔にだけ明かりを落とした手の、逆の目的（倉田は眠らせるために照らした。ミオは起こさないために細くする）。一時間あとの第二幕で、片方ずつ出る反復なので図式にならない。

### 3-3　年配の男のやりとり（残す。一か所だけ削る）
- どこを：「男「……いま、隣で、寝てる人がいる」／男は、噛む。／男「二回、言った」／倉田「誰に」／男「うちのも、言う。電話で。俺が寝てると」／倉田「誰にですか」／男「知らない。寝てるから」」
- どう変える：残す。原稿cでいちばん効く行。「知らない。寝てるから」は、原点の「僕が寝てる間、彼女は何をしているんだろう」を、それで平気な他人が先に言ってしまう一句（他人の生活が、主人公と違う答えを持つ）。倉田の「誰に」→「誰にですか」は他人への丁寧語の言い直し（些細な訂正）で、型に合う。
- 一つだけ：一文の語を35と完全に揃える＝「いま、隣で、寝てる人が、いる」（読点を一つ足す。原稿bの35と同じ）。ミオの口では二度目も同じ読点で。
- 原稿bの申し送り（23では言葉を聞かせない）とは食い違う。ここは原稿cを推す：35で倉田がこの一文を聞いた時、**ベンチで他人の口から聞いた同じ一文**として倉田にも観客にも同時に戻ってくる（「同じ台詞に新しい相手」）。言葉を35まで伏せると、35の一語は新しい情報になるが、倉田の「自分の横で言われていた」が紙に立たない。

### 3-4　しるしを録画の中に（倉田は見のがし、他人が見る）
