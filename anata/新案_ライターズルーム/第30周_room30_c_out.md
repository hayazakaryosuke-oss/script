## 0　決め：ミオの「数秒の眠り」の体（第2版の「指先の震えが、やむ」を、これに置き換える）

### 体の印（ト書きの語をそろえる）
| | 何が起きる（この順） | 語 |
|---|---|---|
| **落ちる** | 眠る人の寝息に、ミオの息が一つ遅れて重なる → 眉のあいだが、ほどける → まぶたが、下りる → 唇が、少し離れる | 「ほどける」「下りる」「離れる」 |
| **戻る** | 顎が、小さく跳ねる → 目が開く → 唇が閉じる | 「跳ねる」 |
| **また落ちる** | 寝息が続いていれば、一つ、二つで、また下りる | 「また」 |

- **唇が離れる**のは、第一幕5で倉田自身が立てた決まり「寝てる人は、開く」の再使用。観客は、ミオの唇が離れた時、それが寝たふりではなく本物の眠りだと、第一幕の決まりで一度目に読める。
- **秒は寝息で数える**（ト書き「寝息、一つ。二つ。」）。眠っている大人の息は一分に十二〜十五回ほど＝一つ四〜五秒。休む一回＝寝息二つ〜三つ（約8〜12秒）。スイッチにしない：落ちる→戻る→落ちるを繰り返す。
- **二つの種類を分ける**（同じ体、違う場所）
  - **休む数秒**：眠る人の寝息のそば。眉がほどけ、何度も落ちて戻る。何も失わない。
  - **落ちる数秒**：寝息のない所（仕事・人前・階段）。眉はほどけない。一回だけで、戻る時に何かを失う（語・段・受話器・数秒の記憶）。これが**体の時計**になる（下の2）。
- **バンドが数えない理由（紙に書かない。美術と取材の決め）**：講座のバンドは三十秒の区切りで眠りを判定する作り（市販の機器も、三十秒ごとの区切りで睡眠を判定するのが一般的。確信度：中）。十秒前後の眠りは、区切りの中に消える。だからミオは一晩に何百回落ちても『睡眠 0分』。「機械が体をごまかす」は、この数字のずれだけで見せる。説明台詞はなし。
- **一晩で足りる量か（専門医の指摘へ）**：倉田の横で落ちる夜（16〜23）は、数百回×十秒前後＝合わせて三十分〜一時間ほどの、細切れの浅い眠り。生きていける最低の線を、倉田の寝息が支えていた。25でそれがなくなると、寝息のない所で勝手に落ちる数秒が増え、長くなる（時計）。
- **耳の決め（誰の寝息を入れるか＝ミオの選択）**：24は受話器と片耳のイヤホンで両耳をふさぐ（真壁の寝息を入れない）／33は両耳にイヤホン（倉田のあくびも寝息も入れない）／35は下の耳だけ電話のイヤホン、上の耳を空ける（真壁の寝息を入れる）。耳を開けるか閉じるかで、ミオが誰の寝息を選んでいるかを行為で見せる。
- 第二幕の「止まる」不使用は守る（「息を、止める」も使わず、「吸ったまま、吐かない」）。第三幕の「初めて眠れる」＝初めて長く眠れる（口が開いたまま、寝息が何百も続く。バンドが初めて動く）。

### 3　ミオが真壁の秘密を倉田より優先する理由（行為で一つ）
- **行為**：24、真壁が眠って口が開いていく。ミオの人差し指が、その顎を押し上げて口を閉じる。目は真壁ではなく、扉の隙間のガラスの白（倉田とガラスの部屋の側）を見ている。第一幕12の41:30で、眠った倉田を照合から隠したのと同じ指。
- **読まれ方**：ミオは「眠っている人を、見張る目から隠す人」で、それは倉田のためにもしてきたこと。倉田は逆に、覆いをめくる人（21でアイマスクの縁を指で上げた。23で本棚のスマホが録画しているのをミオは見たうえで「うん」と言った）。眠る人の秘密を、覆いをめくる人には渡さない。真壁の秘密を守ることは、41:30で倉田の秘密を守った手を守ることでもある（倉田に話せば、ミオは「眠る人のことを話す人」になる）。
- 「言えば済む」への紙の上の答えはもう一つある：倉田は一度もミオに「何をしてるの」と聞かない（23では年配の男に「誰に」「誰にですか」と聞き、27ではスマホを開ける）。ミオは聞かれれば答える人（電話の女の問いには、毎晩、本当のことを答える：27「……まだ」、35「……いま、隣で、寝てる人が、いる」）。台詞では言わない。

### 4　24で名簿の『倉田 修』を見たあとの選択（何もしない、を選択として）

### 推しの場所：16の4:10（第2版の「倉田の薄目の前に、開いたままのミオの目」を差し替える）
