# 第58周 ブレイントラスト　恋愛ドラマの脚本家（40代・女性）の通読メモ

見たところ：ミオという人物、女性が自分で決めているか、別れの書き方。
採点は「脚本として」。紙に書かれていることだけを見た。

## 1. 点

**8.6 / 10**

ミオは、ほぼ全部の分かれ道を自分で選んでいる。先に告白する（3）、ゲームを決める（4）、延長する（5）、ひとりで申し込む（8）、線を消す（14）、「やらないで」と言う（18）、鍵を置いて出ていく（19）、真壁に返す（22）、最後に自分で目を閉じる（26）。女の人が「話を動かすための道具」になっていない。別れの場面（19）は、今まで読んだ恋愛ものの別れの中でもかなり上のほう。
点を下げたのは、三幕（24〜25）で話の中心がミオから男どうしの勝ち負けに移ること。それと、ミオがなぜそうしたのか分からないまま進む所が二つあること。

## 2. グッド・ノート（五つ）

### ノート1（いちばん大きい）　24〜25　「違う」三回と、真壁へのテンカウント
- **どこで**：24、ガラスの部屋。「倉田は、バンテージの指で、髪を分ける。肩を持って、顔を横に向ける。知らない女の寝顔。倉田「違う」」が三回続き、「横を向いた三つの寝顔が、そろって、倉田のほうを向いている」。そのあと「かかとが、床から小さく浮く。跳ねる」。25では、眠った真壁の横で「ワン……テン」と数え、拳が上がる。
- **観客が期待すること**：18〜19で、観客はミオの「やらないで」の側に立った。だから三幕では、倉田がその言葉に向き合う姿を見たい。眠らせる力を、使わずにいられるかどうか。
- **人物がしたこと**：倉田は、ミオがいない所で、警備員と十人と真壁を、本人の許しなしに眠らせる。眠っている女の髪を分けて、顔の向きを変える。これは18でミオにしたこと（眠った体を勝手に動かす）と同じ行為だ。それなのに、三つの寝顔がそろってこちらを向く絵が、笑いのオチになっている。かかとが跳ねるのも、テンカウントも、試合に勝った気持ちよさとして書かれている。
- **そのズレ**：別れの理由になった行為を、観客は三幕で「気持ちのいい見せ場」として受け取ることになる。歯止めは「お母さん？」でかかとが止まる所と、拳が止まる所の二つ。どちらも小さい。26で倉田がこらえるのは「あなたは、」の指一本だけで、二場面ぶんの力の使い方とつり合わない。
- **なぜ問題か**：この映画の別れは「眠りを相手が許したかどうか」で起きている。三幕がそれを見せ場に変えると、ミオの「やらないで」は男が強くなるための一段に下がってしまう。しかも一番の山場は男どうし（倉田と真壁）の勝負で、真壁はそもそも恋の相手ではない。女の観客は、24の「髪を分ける」で倉田から気持ちが離れる。そこが笑いで流されると、脚本も一緒になって気づいていないように読める。
- （直すなら一行：眠った女の顔を動かす所だけは笑いにせず、倉田自身がそれを18と同じだと分かる一拍を入れる。）

### ノート2　15〜17　ミオはなぜ講座に残るのか／「真壁？」への沈黙
- **どこで**：12でミオは、自分の寝落ちが倉田のあくびのせいだったと知る（「その行を、親指で押さえる。ミオの肩が、下りる」「ただいま」）。それでも15では緑の音で講座に入り、17と22でも夜間電話の当番を続ける。16では倉田の「……真壁？」に「ミオは、答えない。倉田に背を向ける」。
- **観客が期待すること**：「ただいま」で、ミオは病気ではなかったと分かり、倉田のもとへ帰ってきた。観客は、講座はもう要らないと思う。続けるなら、その理由（払った298,000円、真壁に頼まれた当番、あの部屋でなら眠れる、など）を一度は見たい。
- **人物がしたこと**：理由を見せないまま、ミオは倉田を外された講座に一人で通い続ける。疑われた所では黙る。
- **そのズレ**：倉田の疑いも、18で倉田がしたことも、19の別れも、全部「ミオがまだ真壁の所にいる」という一点に乗っている。その一点が、ミオの選択としては書かれていない。17を読めば「眠っている人のそばだと眠れる」のだと後から分かるが、16の時点では、観客は「何か隠している」とも「信じてもらえず傷ついた」とも読めてしまう。
- **なぜ問題か**：ほかの場面では、ミオの行動にはいつもはっきりした理由がある。ここだけ、筋を進めるために彼女がその場所に置かれているように見える。恋愛ものでいちばん嫌われる「言えば済む誤解」に近づいてしまう。

### ノート3　8→20→21　「沢井案」と、ミオの仕事が消える
- **どこで**：5「沢井案」「わたしの」。8で朝会中に寝落ちして『日予算』に0が並び、自分で消す。そのあとは、10「有休」、20 野口「沢井さん、休んでます」、21「閉じた会社のパソコン」だけ。22の「四つに折った紙」は、真壁も倉田も開かない。
- **観客が期待すること**：「わたしの」と言わせたからには、沢井案がどうなったか、ミオがそれを手放したのか守ったのかを一度は見たい。0が並んだ失敗の結果も。
- **人物がしたこと**：ミオは仕事を、画面に映らない所で手放している。17で広告の文を眠り薬がわりに読み聞かせるのは見事な使い方だが、本人にとって仕事が何だったのかは、もう描かれない。
- **そのズレ**：一幕のミオは「仕事を持った人」として立っていた。三幕のミオは「誰の隣で眠るか」（倉田／真壁の部屋／アベさん）だけで語られる。いちばん大きな自分のための決断（22で返した紙）は、中身が二度とも閉じられたまま。
- **なぜ問題か**：別れたあとの女の人が、次の男の隣に移るだけに見えてしまう危険がある。紙を開かない二人の男の慎みは良い。ただ、その代わりに、ミオ自身の口か行為で「自分のために何を選んだか」が一つ見えないと、彼女の意思は恋の相手の側からしか読めない。

### ノート4　23　空いた席と「既読」
- **どこで**：23の軽食店。「煙の日と同じ席に、ミオ。向かいの席は、空いている」。修とのトークをいちばん下まで送り、何も打たずに伏せる。「ミオは、向かいの空いた席を見ている」。同じ時間に、倉田の画面には『既読』がつく。
- **観客が期待すること**：ついさっき倉田の『起きてる？』を全部読んだのだから、観客は「ミオは倉田を待っている」と受け取る。
- **人物がしたこと**：ミオが待っていたのは、22でコップを置いたアベさんだ（26で、その「向かいの席」にアベさんが座っている）。倉田の席は、通路をはさんだ向こう側。
- **そのズレ**：どちらの席を見ているのかが紙の上で分けられていない。そのため『既読』が「来て」という合図なのか、「読んだけど返さない」なのかが決まらない。
- **なぜ問題か**：26の意味がここで変わる。倉田は呼ばれて来たのか、呼ばれていないのに来たのか。ミオの意思を最後まで守る脚本なら、この夜の彼女の気持ちは観客にだけは読めてほしい。今は読み手のくせで、どちらにも転ぶ。

### ノート5　22　アベさんへの『木　夜　ここ』
- **どこで**：22。「紙コップの横腹に、書く。ペン先が、刷った三日月の上ですべる。もう一度、なぞる。『木　夜　ここ』。コップを、ベンチの、二人のあいだの座面に置く」。26で、その二度なぞった『ここ』がアベさんの肘の横にある。
- **観客が期待すること**：この三語は、2でミオが倉田を初めて誘った言葉。観客は、倉田あてだと思って見る。
- **人物がしたこと**：同じ言葉を、同じ書き方で、アベさんに渡す。
- **そのズレ**：26で二つのコップが並ぶ絵は強い。ただ、まったく同じ言葉なので、恋愛ものの観客は「アベさんが次の恋人」と読む。脚本が見せているのは、たぶん恋人ではなく「一緒に眠れる人」だろう。そうだとすると、言葉が同じすぎて、別の意味のほうへ引っぱられる。
- **なぜ問題か**：一つは、2の最初の誘いが「誰にでも使う決まり文句」に見えて、さかのぼって軽くなること。もう一つは、ラストが「優しい別の男に移った女」という古い型に寄ってしまうこと。袖をつまむ指（10・18・26とつながる）はとても良いので、そちらに意味を任せたほうが、ミオの選んだものの形が正確に伝わる。

## 3. いちばん効いた所三つ

1. **19　別れ**
   「ミオ「やらないでって、言った」／倉田「聞こえてた」／ミオ「聞こえてたのに？」／倉田「寝れたじゃん」」から、「ミオ「これで、よかったのに」」。そして「倉田の鍵を、爪で輪から外す。指が、一度すべる。もう一度。外れる」。
   責める言葉は一つもないのに、何が壊れたのかが全部わかる。「寝れたじゃん」は、男が言いそうな最悪の一言として正確。鍵が一度すべるので、ミオがまだ好きなまま出ていくことも伝わる。

2. **12　外廊下の「ただいま」**
   「ミオは、スマホを出す。『寝落ちの記録』。いちばん上の行。『9/17　0:05　修の部屋』。その行を、親指で押さえる。ミオの肩が、下りる。長い、息」→「ミオ（小さく）「ただいま」」。
   病気かもしれないと一人でおびえていた女の人が、真相に気づく瞬間を、説明なしで「肩が下りる」だけで書いている。怒りではなく安心が先に来るのが、ミオという人の優しさで、正しい。

3. **26　自分で閉じる目**
   「目が、倉田の顔から、口をふさいだ手へ下りる。笑わない。ミオは、自分でまぶたを下ろす。ミオ（小さく）「……負け」 袖をつまんだ指は、離れない」。そのあとの「倉田（小声で）「彼女が寝てる間、何してるんですか」／アベさん「寝てます」」。
   倉田がこらえたことを、ミオは見て、受け取る。でも戻らない。眠るのは、彼の力ではなく彼女の意思。帰ってきた男が、女の決めたことを消さずに終わる。「負け」が4・21・26で、相手も意味も変わって三回使われるのも見事。

## 4. 一行で勧めるなら

あくびで人を眠らせてしまう男と、彼の胸の上でやっと眠れた女が、「わたしが寝てる間、何してたの」の一言で別れる。笑えるのに、最後まで女の人の「やらないで」が消されない恋愛映画の脚本。
