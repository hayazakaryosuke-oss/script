# 盲検比較　稿X／稿Y（脚本としての採点）

## 1. 点数と勝敗
- 稿X：8.4
- 稿Y：8.2
- **稿Xの弱い勝ち。** 両稿は九割同じ本文。差は、恋の始まり・ミオの仕事・真壁の扱い（Xが上）と、中盤の倉田の行為・結末前夜の準備（Yが上）の差し引きで決まった。

## 2. 場面ごとの勝ち負け（差のある所だけ）
- **X勝ち／恋の始まり（X§3 コインランドリー）**：「付き合ってもらえませんか」を窓に言い、「……窓にですけど」「百円」「三百円も」で笑いに落とす。告白が生活の用事（乾燥機の百円）の中で起き、野球帽の配達員が自分の濡れた洗濯物を持つ他人として登場する。Yはこの場面がなく、恋に落ちる場面が外階段の一杯に縮んでいる。
- **X勝ち／朝会（X§8前半）**：立ったまま眠り「0、0、0、0、0」が増える。それを自分で消し、手首に「10:02」と書く。ミオの代価が行為で見える。Yには場面がないので、記録の三行目「朝会」と終盤の「これは、わたし」が紙の上で裏づけられない。
- **X勝ち／真壁（X§14・§20）**：名簿の「真壁　連続0分　412日目」と、倒れきった背もたれ。これで、バンドをミオに預ける意味（眠る自分の記録を他人に起きて守らせる）が一つに決まる。結びの「白い跡の上に巻く」も行為で効く。Yの「目標30／実績11」は売上の圧で、人より事業に寄っている。
- **X勝ち／結末の代価（X§25）**：女の紙袋に「御霊前」と新幹線の切符。起きて「5:18」と「持ち手の切符」を見て走る。叶い方の「ひどさ」が他人の生活に具体的にかかる。Yは「手土産」で軽い。
- **Y勝ち／携帯を枕の下に（Y§13）**：倉田がミオの携帯を自分の頭の下に隠し、真壁の電話を押さえこむ。ミオは目を開けたまま抜き取り、「寝てて」と言って出る。中心の越境の前に、倉田の支配が一段上がる。ミオの選択も一つの行為になる。Xの§13（耳栓とアイマスク）は静かで、段差が弱い。
- **Y勝ち／前夜（Y§26）**：ミオがテレビのコードを抜いて束ね、「3:30」に目覚ましをかけて寝る。倉田は布団を二つに折り、配達を「オンライン」にする。二人の選択が行為で並ぶ。Xは結果（「抜いたコードが束ねてある」）しか見せない。
- **Y勝ち／ミオの言葉**：Y§4「……沢井案」「わたしの」、§25「以上です」。仕事を自分の名で引き受けて言い切る。Xは言い直しの一行で済ませている。
- **Y勝ち／手洗い（Y§10）**：保冷剤で欠伸を飲む場面が、三本目の線を引く行為になっている。Xは§10で「二本」、§11で「三本」と数が飛ぶ（連続性の穴）。

## 3. 勝った稿（X）の残る弱点
1. **結末の欲しいものが一つに決まらない。** 倉田がレンズに出る直前の引き金は記者の「雲が少なく」。そこまでに置かれているのは、既読のない「起きてる？」・写真・四本目の線。読み筋が三つ残る。「ミオに見られたい」（ただし彼はミオがテレビを抜いたと知らない）。「街を眠らせて青を撮り直したい」。「沢井案の朝枠を潰したい」。朝枠が天気の前後だと倉田が知る段取りも紙にない。
2. **手首の時刻の列の意味が揺れる。** 寝落ちの時刻なのか、起きていた証なのかが決まらない。§8の床で起きたまま一つ足す所と、§25の「4:36」が同じ規則で読めない。
3. **ミオの選択が、中心の手前で言葉にならない。** 講座の「1」、事務室の「す」、鍵を置く、はどれも無言の行為。「決めるの、わたし」までに自分の意思を口に出す場面が一つもない。真壁も、紙の上では画面の一行（412日目）でしか語られていない。

## 4. 負けた稿（Y）から移すもの
- **Y§13の「携帯を枕の下」と「寝てて」。** Xの§13の前か後ろに置き、越境の前段を作る。
- **Y§26の前夜。** とくにミオがテレビのコードを抜き、目覚ましを置いて寝る行為。これで結末の「反応なし」と、目を覚ましている理由が一本につながる。
- **Y§4の「……沢井案」「わたしの」と、Y§25の「以上です」。**
- **Y§10の手洗いの欠伸殺しで、三本目を引かせる場面。** 数の穴も埋まる。
- **Y§27の「五時十二分」の時刻の見出し。** 女の頼んだ時刻に倉田が伏せることを、時刻だけで刺す。
- 移さないもの：「朝枠（新宿駅前の天気の前後）」の書き足し。画面の字に頼る量が増える。結末の動機は、ほかの行為で決める。
