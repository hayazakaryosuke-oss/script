# 本読み 第44周：倉田 修（主演）
担当の台詞は106行・774字（読点込み）。紙に書かれていることだけで読んだ。

## 1. 言いにくい台詞 上位8
1. **42「あなたは、だんだん、眠くなる」**：ト書きは「待たない」で、ミオの「あのね、修」にかぶせる行なのに、読点三つで3のテレビの調子に戻ってしまう。例：（かぶせて）「あなたはだんだん眠くなる」。
2. **3「あそこで、天気が始まるまで」**：「天気が始まる」が口に乗らない。例「あそこで、天気やるまで」。
3. **12「ミオ。俺の、——」**：「の」で切ると、続く名詞を決めないと切れない。例「ミオ。俺さ、——」。
4. **37「……僕の」**：断片で意味が立たない。一人称もここだけ「僕」。例「……じゃあ、僕のだけ」。
5. **8「まっすぐに、してます」**：読点で止まり、「に」が書き言葉。例「まっすぐ、引いてます」。
6. **17「当日の参加は」**：初対面の相手には切れすぎ。例「当日って、入れます？」。
7. **6「今夜から、寝ないでいよう」**：少し硬い。例「寝ないでおこう」。
8. **31「眠いですか」**：唐突。ただ、30「次は、聞いてください」への返しだと紙から分かるので、言い方で足りる。

## 2. 動機の切れ目 上位5
1. **結末4:37 レンズへのあくび**：ミオが見る4:30の枠だということは、47と3から分かる。だが「ミオを眠らせたい／世界を眠らせて〈うちらだけ〉にしたい／見つけてほしい」のどれなのかが決まらない。どれを取るかで、続く『起きてる？』の意味が逆になる。
2. **結末5:12**：約束の時刻に、倉田は起こさずに伏せる。36の「※約20分後」を倉田が覚えているなら、4:58のあくびは約束を自分で潰す行為になる。覚えていないなら、ただの失敗。紙はどちらとも決めていない。
3. **47 寝ている男の¥780を取る**：理由がないので「悪くなった」しか演じられない。しかも十時半には広場に戻っている。
4. **46火曜「口が、開きかけている」**：あくびの手前なのか、呼びかけなのか。何をしに来たのかが決まらない。
5. **48 布団を出す**：「もう寝ない」なのか「二人の布団は要らない」なのか。一行あれば、体が一本になる。

## 3. 説明に聞こえる台詞 上位5
1. **結末 黒「……あなたは」**：言う相手がいない。1の題名の声と対になる額縁で、作り手の声に聞こえる。
2. **結末「起きてました」**：店員の問いが、1と合わせるために置かれていて、店員に聞く理由がない。そのため返しが決め台詞になる。
3. **6「寝るの、もったいない」**：作品の一行（ログライン）がほぼそのまま出ている。動機はあるので、言い方で救える。
4. **20「五時です」**：経過時間と時刻のずれを説明する行。アベさんの笑いが救っている。
5. **42「眠れるよ」**：32の繰り返しで、相手・目的・代価が変わっていない。ミオの主題の行を引き出すための受けになっている。

## 4. 声の一貫性
- **一人称**：12は「俺」、37は「僕」、15のトークは「おれ」。台詞が少ないぶん目立つ。
- **「、です」でかわす癖**：5・12・16・17・18・35の六回。一貫していて、俳優には宝。
- **「じゃん」**：43の二回だけ。責める場面で初めて出る語尾として効く。意図かどうか確認したい。
- **ぶれのない所**：呼び方は「ミオ」「真壁さん」。「すいません」と、二人の遊びは「寝る」・力は「眠れる」の使い分けも、ぶれていない。

## 5. 指定の確かめ
**(a)** 口から出る。7で倉田自身が言った、ミオへの些細な訂正なので、本人の口ぐせ。前半を言う人がいないところで、頭の中のミオに返す。それ自体が芝居になり、直後の「親指は、遅れない」→送信の行為が台詞を受けて流す。危険は二つ。①結末は呼び返しが多く、その一つとして並ぶと決め台詞になる。②2-1が決まらないと、満足とも孤独とも読める。例：台詞の前に「目が、横（7でミオがいた側）へ行く」の一行があれば、反射になる。

**(b)** 42の本文に「三つ数えると」はない。42の口上は「あなたは、だんだん、眠くなる」で、「三つ数えると」は11と結末4:58にある。両方を見た。
- **42**：紙はすでに防いでいる。口上のあとも「ミオの目は、開いている」。ミオの拳が上がるのは喉が上がった時。「手は、上がらない」ともある。残る危険は「声を作って」読むことで、地声でかぶせれば防げる。**言い方で防げる。**（声を作らずに）の一語があれば、さらによい。
- **4:58**：**紙で防ぐべき。**「いち、に」→「口が、開く」の並びだと、数えたことが効いたように見え、「さん」を言わない切り方も仕掛けに見える。行の前に「喉が、上がってくる」を一つ置けば、俳優は喉に追われて急いで数える芝居になり、原因があくびだと見える。

**(c)**
- **43「……真壁さんとも、寝てたじゃん」**：言える。「それで？」で言い分が尽き、38で見たことを持ち出す。「目が、横へそれる」から、本人も卑しいと分かっている。2「一緒に寝ただけ」の裏返しで、身勝手な言い換えとして効く。強く言うのは「とも」。
- **4:58の行**：今の紙では、まだ動機ごとは言えない。読み方は三つある。①起こそうとして体に負けた。②起きだす世界を止めた。③女の代わりに「まだ寝てていい」と決めた（42の再演）。「膝に手を置いたまま」だけでは①と③のあいだで止まる。目がどこを見るかが一つあれば決まる。女のスマホの『始発　5:12』なら①、頭を上げる司会なら②。

**(d)** 全体として足りている。喉・手で口・保冷剤・甲の線という体の語彙が揃っていて、28・34・38・41・48は台詞なしで主演が立つ。足りないのは次の三か所。
- **結末4:05〜4:36**：「見る」だけが三つ続く。5:12に向けた行為がないので、起こさないことが演じられない。例：電池は2%、席の下にUSB口、ケーブルは1でミオに渡ったまま。
- **46火曜の歩道**：何をしているのかがない。
- **「まばたきを、しない」**：六回以上続く。47で意味が冷たく変わるので、そこだけ別の行為にすると、落差が立つ。

## 6. 演じたいか：8／10
台詞を捨てて、体で恋と罪を運ぶ役。減点は、結末の欲が一本につながらないこと。
- **いちばん演じたい**：38。真壁の胸の上下に息を合わせて、二つ目で追い越す。
- **いちばん困る**：結末4:37〜5:12。三つの行為を一つの欲でつなげない。
