# 脚本創作ノート
## 三作品の全文研究と『あなたはだんだん眠くなる』東京篇
早坂亮輔の創作・改稿のための参照資料

2026年9月30日

## 要旨
三作から引き継ぐのは、短い台詞や長い沈黙という外形より、同じ出来事を別々に受け取る人物を、生活の時間の中で衝突させる設計である。『あなたはだんだん眠くなる』では、倉田にできることが増えるほど、ミオの言葉を聞くことが難しくなる。この進行を、能力の規則だけでなく、仕事、食事、移動、金銭、帰る場所で支える。

このノートは三作の掲載脚本を対象とした読解・創作上の仮説であり、作家本人による技法解説ではない。作者・監督の他作品全般へ、そのまま一般化しない。作品の台詞、場面、象徴を移植せず、何がどの順番で変化しているかを別の人物・行動へ置き換える。

脚本本文は計89ページ。三作とも冒頭から結末まで全文を通読した。スキャンの文字層には誤認識と読順の乱れがあるため、抽出した全文を順に読み、重要な場面・結末・引用箇所・乱れた読順を誌面画像で照合した。これは一字ずつの翻刻・校訂版を作ったという意味ではない。誌面の広告・別作品は研究対象に含めていない。

『ドライブ・マイ・カー』の脚本・監督ノート／脚本家ノート（同号34–35頁）も確認した。濱口のノートは当初の釜山から広島への変更と土地の条件を記し、大江のノートは一つの台詞の修正が前の場面や人物へ波及することを記す。本ノートの具体的な分析は、まず掲載脚本そのものを根拠とする。

本ノートの「第○場」「○頁」は掲載脚本の場面番号と誌面の頁。完成映画のカット割り、上映時間、俳優の実演とは区別する。東京篇への適用箇所だけは第三改訂稿の場面番号を用いる。

## 2　『きみの鳥はうたえる』――自由であるという自己像の代価
中心には、三人でいる喜びと、その関係を定義しないことで守ろうとする「僕」がいる。恋愛の勝者を選ぶだけの三角関係ではない。誰かを束縛しないという態度が、欲しいものを言わず、相手に決定の負担を渡す態度にもなる。しかも三人の楽しさまで偽物になるわけではない。

### 全編のビートと受け渡し

| 場面 | 起こること | 構造上の働き |
|---|---|---|
| 1–9 | ピアスを巡る島田と佐知子の不一致。映画館の「僕」と静雄。街で佐知子が「僕」の肘に触れる。 | 最初から佐知子には主人公の知らない関係がある。短い接触に「僕」が意味を与えて待つ。 |
| 10–18 | 静雄と母。約束の夜に眠ってしまう「僕」。翌日の職場と昼食。 | 不誠実さを事件だけで裁かず、それでも会いたくなる振る舞いと並べる。静雄にも母との生活がある。 |
| 19–25 | 職場のメッセージ、セックス、静雄の帰宅、三人の食事。 | 二人の親密さが、同じ部屋に帰ってくる第三者の存在で変わる。身体と狭さが会話を中断する。 |
| 26–33 | 買い物、帰宅、借金の受け渡し、静雄の家事、三人の遊び。 | 金、服、花、部屋が三人をつなぐ。「僕」の幸福の解釈と、観客に見える距離を並行させる。 |
| 34–39 | 佐知子と同僚。クラブ。性行為の後の会話。静雄の外出先。 | 主人公の見ていない時間を渡す。居心地のよさを作っているのは誰か、という問いが生まれる。 |
| 40–48 | 万引きへの対応、島田との関係、退職、店の利益の話、森口への暴力。 | 他人の楽しみを邪魔しないという「僕」の態度が、労働と暴力の場で矛盾を露出する。 |
| 49–58 | 求職、佐知子と静雄の散歩とカラオケ、三人の朝食。 | 二人が近づく時間を「僕」の推測だけに任せない。和やかな朝食と関係の変化が同居する。 |
| 59–68 | 閉店後の書店。二人のキャンプ。「僕」への報復。静雄の母の訪問と帰還。 | 「自由」の言葉では引き受けられない痛みと、本人に見えない他者の事情が増える。 |
| 69–72 | 母の発病を知っても三人で遊び、夜が明け、静雄を見送る。 | 楽しさは単なる現実逃避として処理されない。終わりたくない時間を身体の疲れと街の朝が終わらせる。 |
| 73–75 | 交際の告知。母の病室にいる静雄。別れ際の「僕」が引き返して告白。 | 正直になることはできる。しかし相手が応じるとは限らない。既に進んだ他人の時間は巻き戻せない。 |

### 精読A　台詞と行動の間に第三者が入る
第23–31場（21–24頁）。二人きりの場面でも、部屋の持ち主のもう一人が虫の扱い、帰宅、借りる服、生活費を通じて入ってくる。人物紹介のために静雄の性格を説明するのではなく、二人の行為の条件を静雄が変える。

さらに、佐知子から「僕」に渡った金の一部が静雄へ渡る。「僕」は金の来歴を別のものとして話す。この小さな嘘には、友人を助けること、借り手である自分を見せないこと、三人の均衡を保つことが重なる。善意か虚栄か、一方だけでは説明できない行動になる。

応用する問いは「主人公が受け取ったものを、誰に、何と説明して渡すか」。東京篇の紹介料、出演料、返す鍵も、意味を説明する小道具ではなく、渡す場面で人物間の力関係を変えるものとして扱う。

### 精読B　会話の用件が途中で変わる
第40–48場（27–29頁）。万引き対応についての衝突が、職業上の責任、店長への反発、佐知子への感情へ移る。店長との会話も、店の経営を巡る叱責だけでは終わらない。「僕」が相手を軽く見積もっていたことが露出し、続く森口との会話で暴力が起きる。

ここで重要なのは、人物が一つの場面に一つの感情しか持たないわけではないこと。職場の正論を言う人物にも卑小さがあり、不真面目な人物にも友人を守りたい気持ちがある。ただしそれは暴力を正当化しない。

東京篇の真壁との対決も、詐欺師を論破して終わる場面にはしない。契約の実務、倉田が失った眠り、真壁が人から求められる場所を手放せないことを、同じ机の上に置く。

### 精読C　最後の表情は「何でも読める」ではない
第73–75場（35–36頁）。「僕」は相手を解放するような言葉を言った後、自分の態度に耐えられず引き返す。掲載脚本の最後のト書きは長い。告白した側の後悔と高揚、受け取った側の喜び、怒り、応えられない悲しみを、同時に指定している。

したがって、この結末を単に「答えを見せない、余韻のある恋愛」と学ぶと浅くなる。観客への説明を減らすことと、作者が人物の感情を決めないことは別である。俳優が相反する感情を演じられるほど、作者側は具体的に決めている。

東京篇ではミオの拒絶を明言させる。ミオの顔が安らぐことと、倉田を恋人として選ばないことは、どちらも成立する。倉田の行動で後者を消さない。

### この作品から移さないもの
酒、クラブ、三人暮らし、肘への接触、ピアスの仕掛けを移さない。場面が緩やかだからといって因果を薄めない。学ぶのは、一緒にいる時間を十分に経験させ、その同じ時間の代価を後から見せる順序である。

## 3　『寝ても覚めても』――似ている顔と、異なる生活
同じ顔という大きな虚構を、仕事の失敗、部屋の片付け、友人の口出し、運転の負担などが受け止める。朝子の選択は理解し切れなくても、選択によって誰の生活が傷ついたかは具体的に分かる。不可解さと生活の具体性が同時に置かれている。

### 全編のビートと受け渡し

| 場面 | 起こること | 構造上の働き |
|---|---|---|
| 1–5 | 写真展で麦と出会う。友人に紹介する。クラブ。 | 本人には恋の始まり、友人には危険の兆候。同じ行動の意味が一致しない。 |
| 6–12 | バイク、事故、共同の家事、麦の一晩の不在と帰還。半年後の失踪が語られる。 | 一度戻ることが、次も戻るという期待を作る。安心の場面が、後から喪失の起点になる。 |
| 13–22 | 東京で亮平と出会う。職場、写真展、カフェ。 | 似た顔を持つ人の職業、話し方、気遣いを、初めての人物として立ち上げる。 |
| 23–28 | 食事会で串橋がマヤを批判。朝子の反論。四人の交友。亮平の告白。 | 朝子の無口さが受動性だけではないと分かる。亮平には他人を関係へ戻す具体的な働きがある。 |
| 29–38 | 朝子が亮平を拒む。公演への訪問。震災下の移動。再会。 | 二人の時間を都市の出来事が変える。歩く方向と、人々の流れが欲望を可視化する。 |
| 39–48 | 五年後の朝食、仕事、東北との往復、運転疲れ、介抱。 | 省略された年月を、協働と摩擦で埋める。亮平は過去の男の代用品という説明に収まらなくなる。 |
| 49–53 | 春代との再会、麦の広告、友人への告白、求婚と亮平の既知の事実。 | 秘密を話す場面が、相手が既に知っていたという反応で反転する。理解されることの重さが増す。 |
| 54–56 | 麦へ別れを告げるような身振り。新居の内見。 | 未来への合意を具体化する。その直後の選択が壊すものを観客に先に渡す。 |
| 57–63 | 麦が来る。朝子が亮平のもとを去る。友人との電話。 | 欲望が選択として実行される。ロマンティックな逃走に、残された人の反応が入り続ける。 |
| 64–67 | 海沿いで別れ、平川に助けを求める。 | 欲望の向きがもう一度変わる。引き返すためにも、具体的な交通と金と他人への依存が要る。 |
| 68–73 | 亮平の転居。春代の反応。拒絶と猫探し。岡崎・栄子との再会。 | 帰還だけでは失った信用は戻らない。再会した他人も、昔の姿のままではない。 |
| 74 | 再度の訪問。家に入る。二人が川を見る。 | 同じ場所を共有しても評価は一致しない。関係の継続と、信頼の回復を同義にしない。 |

### 精読A　食事会は「意見の紹介」ではなく、関係を作る事件
第25場（60–62頁）。串橋は帰ろうとし、理由を問われ、批判を口にする。マヤは批判に怒りながら、その批判が本気かを確かめる。朝子は友人の努力が届いていることを自分の経験として語る。亮平は串橋がそのまま帰れば関係を修復できなくなると考え、出口で止める。

話者が変わるたびに、会話の目的が変わる。帰る、問いただす、傷をつける、守る、場に戻す。誰か一人の正しい演劇論を説明しているのではない。朝子が突然長く話すことも、その場で守りたい相手がいるから生じる。

応用では、全員を同じ省略調の台詞に揃えない。真壁は敬語と手続きを増やし、倉田は訂正と要求を増やし、ミオは具体的な用件を完了しようとする。台詞の長さは発言者のその場の目的から決める。

### 精読B　年月の省略は、生活の協働で支える
第39–48場（66–69頁）。五年後という表示だけで二人の関係を成立させない。料理の呼び方のずれ、仕事の成果、猫を預ける友人、東北への往復、運転する側の疲れ、帰宅してからの世話が続く。互いを必要とする具体と、負担の偏りが同じ区間にある。

東京篇では三年の空白を、秘密の一括説明で埋めない。ミオがもう飲まない缶コーヒー、二回変わった部屋、知らない友人、荷物の配達時間を出す。ただし、それらをすべて浮気の証拠に見せる音楽や演出は避ける。ミオの三年は実際に続いていた生活である。

### 精読C　友人は主人公の選択を別々に受け取る
第63、69、73–74場（77、79、81–82頁）。朝子が去ること、戻ることへの友人の反応は揃わない。本人の決意を賞賛するだけでも、全員で断罪するだけでもない。支えてくれた人の不快さ、期待、面倒、記憶がそれぞれ残る。

東京篇第41場のアベさんも、紹介料の返却を単純な正義の回復として受け取らないよう改めた。返金は受け取るが、来てよかった経験まで無かったことにはしない。善悪の整理と、その人が実際に経験したことを一致させ過ぎない。

### 精読D　帰還は原状回復にならない
第65–74場（78–82頁）。朝子の帰路は長い。財布、金、乗り物、助けてくれる人、拒む人、変わってしまった友人に、一つずつ接触する。最後の亮平の言葉は、彼女を家に入れた事実だけでは打ち消されない。窓から同じ川を見るが、二人の評価は違う。

東京篇の終わりにも「行為を取り消せない身体的な事実」を置く。ミオは眠っている。倉田は声を聞かずに済んでいる。しかし拒絶された事実は残る。以前と同じ布団屋に戻れても、以前と同じようには眠れない。

### この作品から移さないもの
二重の顔、震災、海への逃走、川の台詞などを使って似せない。ミオを麦のような帰還者に置き換えるだけでも足りない。再訪は仕事と個人的な希望から生じ、帰宅先は既に別にある、という本作固有の条件を守る。

## 4　『ドライブ・マイ・カー』――聞くことが身体の習慣を変える
家福は、音の物語を覚え、音の録音に合わせて台詞を言える。それでも音が話そうとしたことを聞けない。情報量と理解を切り離した設計である。音の秘密を解き切るより、家福が自分の避けたことを言葉にし、他者の前で演じ直せるかが変わっていく。

### 全編のビートと受け渡し

| 場面 | 起こること | 構造上の働き |
|---|---|---|
| 1–7 | 寝室の物語、翌朝の語り直し、舞台、高槻の紹介、録音。 | 親密さを内容だけでなく共同作業として示す。後に残る声と、応答の形式を作る。 |
| 8–17 | 予定変更、帰宅、目撃、帰宅しなかったふり、事故と検査。 | 見たことを知っている観客と、知らないふりをする主人公の間に差ができる。 |
| 18–25 | 娘の記憶、夫婦の親密さ、話の続き、話し合いの約束、帰宅の遅延、死、演技の中断。 | 聞かないことが行動として積み重なる。喪失は、未完の会話と未完の仕事を残す。 |
| 26–38 | 二年後の移動、滞在制作の実務、運転手への反発、試乗、受け入れ。 | 依頼・契約・習慣によって、他者と毎日同じ車にいる理由を作る。 |
| 39–45 | オーディション、配役、本読み、車内の待ち方を巡る会話。 | 役者と運転手の双方を、家福の思い通りには扱えない人として出す。 |
| 46–50 | 高槻との飲酒、音についての会話、撮影への反応、本読みへの異議。 | 家福が高槻を調べる一方で、自分の仕事上の態度も問い返される。 |
| 51–54 | ユンス・ユナの家での食事。運転への評価とみさきの過去。 | 人を助けるつもりの言動が相手から修正される。技能への感謝に、その技能の痛ましい来歴が加わる。 |
| 55–61 | 稽古の準備、高槻の事故、稽古のやり直し、みさきとの外出。 | 反復に少しずつ新しい注意が入る。移動先には語り手自身の生活と記憶がある。 |
| 62–68 | 屋外の稽古、高槻との会話、音の物語の続き、助手席への移動。 | 他者が自分の知らない言葉を持っている。聞く前と後で、車の中の位置と行為が変わる。 |
| 69–70 | 稽古中の逮捕。公演を中止するか、家福が出るか。 | 理解は感情の到達点だけでは済まない。仕事を引き受ける期限のある選択が生じる。 |
| 71–77 | 北への移動、休憩、みさきの家の跡地、互いの告白。 | 傷の同一化ではなく、異なる記憶を聞き、自分の回避も言葉にする。 |
| 78–81 | 公演、手話による応答、みさきの後の暮らし。 | 繰り返された言葉が異なる身体から届く。最後には主人公の外にも生活が続いている。 |

### 精読A　長い会話を支える実務
第30–36場（46–49頁）。宿までの距離、運転手を付ける理由、車へのこだわり、試乗の条件が交渉される。後に長い会話ができる車内は、親密になりそうだから作られた空間ではなく、互いの職業上の条件が生んだ空間である。

東京篇では、深夜に人が講座室にいる理由を作り直した。通常講座は夜八時から十時、金曜は任意の夜間交流会。終電後は始発を待つ人がいる。受付係のミオは夜間対応の賃金を得る。講座費や生活の都合がなければ、会話だけを巧くしても場所は成立しない。

### 精読B　発話の内容より、聞き手の仕事が変わる
第1–2、20–22、66、77場（37–38、43–44、63–65、69–71頁）。音の物語は、夫婦の共同作業であると同時に、家福の知らない場所にも続いている。高槻が続きの語り手になることで、家福が音の言葉を所有していないことが具体化する。

音の物語の解釈が一つに確定するわけではない。高槻の語りも、その後の逮捕も、一方が他方を取り消すように置かれていない。説得力のある言葉を言える人が、その通りに生きられるとは限らない。

東京篇の録画では、情報を集める行為自体が倉田を眠れなくする。ミオの口の動きを繰り返して見ても、三年間のすべては分からない。終盤で日常的な挨拶だった可能性が示されても、彼が費やした夜は返らない。

### 精読C　反復は「同じ台詞に新しい相手」が入ること
第7、22、25、34、38、50、62、78–80場など。戯曲の台詞は録音、稽古、公演で繰り返される。単に伏線を回収するだけでなく、声の主、聞く身体、言えるかどうか、相手へ返せるかどうかが変化する。

東京篇の口上は、①寝具を売る口実、②サクラとの合図、③アベさんへの気遣い、④舞台の成功、⑤失敗後の検証、⑥許可された実験、⑦他人の予定を止める命令、⑧拒絶を遮る言葉、⑨自分への願い、と用途を変える。文句そのものを複雑にする必要はない。

### 精読D　善意を相手が訂正できる
第53–54場（56–58頁）。ユナは特別に優しく扱われる前提を問い返す。みさきは運転を褒められて嬉しいと語るが、その技術の来歴は苦痛に関わる。丁寧に聞くことは、相手を無傷の存在として理想化することではない。

東京篇で加奈は実験の条件を決める。アベさんは眠る時刻と起こす手段を持つ。ミオは催眠を断り、仕事を辞め、紹介料の返却を自分で決める。倉田がそれを聞かなくなると、同じ能力が異なる行為になる。

### 精読E　感情の到達を、引き受ける仕事で確かめる
第69–80場（66–72頁）。高槻の逮捕を受け、公演をどうするかという問題が生じる。家福の変化は、告白したから完成するのではなく、自分が演じる場へ戻ることで可視化される。

東京篇も、能力が戻ったという内面の確信だけで終盤へ進めない。第31場で実際に戻り、第35場で講師契約に署名し、第36場でその場の人々に行使する。倉田が信じること、選ぶこと、他人に起こすことを三段階に分ける。

### この作品から移さないもの
録音された妻の物語、戯曲の引用、赤い車、旅の終点、抱擁の配置を写さない。また、短い台詞と沈黙だけがこの脚本の特徴だとしない。長い独白も、相手がその場で聞かざるを得ない関係と、後の行動の変化を伴っている。

## 5　三作を混ぜずに、早坂の脚本へ使う

| 設計上の問い | 三作からの学び | 早坂作品での使い方 |
|---|---|---|
| なぜ今、この人と同席するのか | 共同生活、職場、制作の契約が会話の場所を作る。 | 場所を象徴から選ぶ前に、仕事と用事を決める。 |
| 何を言えずにいるのか | 言わないことには関係を保つ実利がある。 | 言えない欲望を、値段、時間、呼び方の訂正で守らせる。 |
| どの情報が足りないのか | 人物にも観客にも未知はあるが、その配置は違う。 | 倉田に見えないミオの生活を観客には少し渡す。全員に対する謎にしない。 |
| 会話が何を変えるのか | 信念を説明するだけでなく、出る、残る、触る、借りる、断る行為が変わる。 | 台詞の前後で誰が何をできるようになったかを書く。 |
| 反復は何を変えるのか | 同じ時間・場所・言葉に、新しい相手と代価が入る。 | 催眠の文句を変えず、目的と相手の承諾を変える。 |
| 最後に何が戻らないのか | 告白、帰還、理解だけでは過去の結果は消えない。 | ミオが眠っても拒絶は消えず、布団屋へ戻っても倉田の睡眠は戻らない。 |

既読の早坂亮輔『ガチャライフ』で使える強みは、欲望の身勝手さを、本人にとっては筋の通る言い換えにすること。大きな非難に小さな訂正で応じる、問い詰められた側が自分の傷を持ち出す、同じ金額に反対の反応をする、生活の用事が恋愛の高揚を切る、といった技法である。

『あなたはだんだん眠くなる』でも、倉田の「いまは大丈夫です」、加奈の設定上は客だという主張、アベさんの返金への複雑な反応などを残す。文学的な静けさを足すために、この滑稽さを消さない。

ただし連続短編のように毎場に落ちや引きを置く必要はない。第22場の卵を焼く時間は、全台詞を伏線へ変えず、二人が実際に同じフライパンを見ている時間として確保する。楽しい日があったことを、後半の説明だけに頼らない。

ミオについて使うのは、都市の孤独、身近な相手の知らない時間、日常に混ざる一つの異変という高水準の要素。村上春樹の固有の文体や比喩、口調は再現しない。ミオを主人公の無意識の代理や、秘密を教えるためだけに現れる人にもしない。彼女には勤務時間、家賃、友人、帰宅先がある。

第37場の勝利は物語全体の勝利ではない。第39場で能力の届かない答えが示され、第43場で自分の身体に届かないことが残る。終盤は敵を大きくしていくのでなく、倉田の最も近い問題へ縮める。

## 9　二巡のレビューと改訂記録
実在の審査員五人や、独立した五人の初読結果ではない。一つの書き手による五つの審査視点での再読である。世界的な賞の選考水準を目標に厳しく見ることと、実際にその評価を受けたと称することは分ける。

第1巡：第二改訂稿から東京の途中稿へ。場所を変えるだけでは成立しない仕事・料金・深夜滞在・時系列を見直した。


| 視点 | 検出した弱点 | 実施した改訂 |
|---|---|---|
| 構成 | 不眠の崩壊が連続し、選択の地点が埋もれる。 | 第27場の離脱を中心にし、第28場を圧縮。第31場で能力の回復を実際に見せる。 |
| 人物 | ミオが眠らない男の下にいる女性としてしか見えない。 | 住所、友人、配達、賃金、退職を設け、退職は倉田の勝利より先に進める。 |
| 会話 | 短い質問と短い答えの均一化。説明が小分けになるだけの箇所。 | 労働や費用の交渉、早坂の小さな訂正と笑いを増やす。 |

第2巡：三作品の全文研究後。出来事の正確さだけでなく、各人物が同じ時間をどう経験するか、という視点を加えた。


| 視点 | 再読で残った問題 | 実施した改訂・確認 |
|---|---|---|
| 人物と欲望 | ミオの来訪が、説明と拒絶のための配置に見える危険。 | 第14場の友人との会話、第22場の卵を焼く時間を追加。来たかった気持ちと復縁しない気持ちを並べる。 |
| 経済と選択 | 第35場の契約は名目だけで、倉田が署名する魅力が弱い。 | 月額、夜間四回、電話とメッセージ対応を具体化。引き受ける仕事の実体を作る。 |
| 会話と作家性 | 全員が正しいことを少しずつ言うと、生活の身勝手さが消える。 | 返金を受け取りながら、その意味づけには異議を言うアベさんの会話へ変更。 |
| 因果と連続性 | 能力の回復からミオの退職、対決までが都合よく見えないか。 | 署名、紹介、ミオの帰り支度、受講生の拒否、催眠の行使を順に確認。靴の助数詞も修正。 |

第2巡後の判断：世界、選択、会話の差は強くなった。一方で9.5／10到達という判定は保留する。同じ書き手の再読は初読ではなく、名作との同等性を点数で保証できない。

次の独立初読で確認したいのは三点。①第35–36場の署名から一斉催眠への変化を、倉田自身の選択として追えるか。②ミオの訪問に親しさを感じながら、恋人として戻っていないことも受け取れるか。③終盤の長さが真壁への勝利で満足を閉じず、ミオと布団屋へ集中を残すか。この三点は、さらに言葉を増やす前に、読み合わせで確認する価値がある。

## 10　次作へ持ち越す創作メモ
参照名：早坂亮輔／脚本創作ノート／三作品全文研究／2026年9月30日。

これは今後の脚本作業で読み返せる保存資料である。モデルの重みへの恒久学習や、別の会話での必ずの自動想起を意味しない。次作の開始時にこの参照名の資料を確認し、その企画に必要な項目だけを使う。

### 改稿の順序
## 1　人物ごとに、主人公のいない日の予定を書く。仕事、移動、支払い、食事、連絡相手から二つ以上。全部を脚本に載せる必要はない。
## 2　各場の冒頭で欲しいことと、実際にすることを分ける。「分かってほしい」は目的だが、謝る、訂正する、契約を差し出す、相手の帰路を尋ねる、は行為である。
## 3　会話の途中で誰が話題・場所・終了時刻を決めているかを見る。一方が質問し続け、もう一方が設定を答え続ける場は、役割を反転するか、答える側の用事を入れる。
## 4　観客が知ること、主人公だけが信じること、作者が決めているが見せないことを別々に書く。曖昧さを設定の未決定の隠れ蓑にしない。
## 5　反復する行動は、相手、目的、負担、結果のいずれかを変える。同じ情報をもう一度言うだけの反復は減らす。
## 6　助ける側の善意と、助けられる側が受けた行為を別々に点検する。実際に助かったことがあっても、それ以前の拒否や不利益を消さない。
## 7　最後の大きな言葉の後に、身体・仕事・移動の選択を置く。言えたことではなく、何を引き受け、何を避けたかを確認する。
## 8　好きな作品の「雰囲気」に近づいたかより、自作の人物の利害が具体化したかで採否を決める。学んだ技法を全部使う必要はない。
### 会話のチェック
台詞を短くすればよい、という規則にしない。長い言葉には、今ここでその相手に言う理由と、聞いた相手が変える行動が要る。短い言葉には、相手が埋める空白と、その埋め違いの代価が要る。

人物を賢くすることと、作者の結論を言わせることを分ける。自分の状態を言い当てられる人も、その状態から抜け出せないことがある。見抜く力、選ぶ力、離れる力はそれぞれ別に設計する。

笑いは悲劇の邪魔とは限らない。欲望を捨てずに条件だけ変える、些細な語を訂正して本題から逃げる、同じ値段を別々に受け取る。これらが人物の生活上の必要から出ているなら、終盤の痛さを深くする。

### 採用しない短絡
無口な女性＝奥行き、沈黙＝上質、日用品＝伏線、曖昧な結末＝文学性、長い台詞＝説明過多、告白＝成長の完成、助かった結果＝行為の正当化、とはしない。

三作の水準から学ぶべきなのは、対立する感情や事実を、どちらも本当のまま持続させる精度である。『あなたはだんだん眠くなる』では、倉田の善意、加奈の不安、ミオの親しさと拒絶、真壁の虚偽と夜の相手になっていた事実を、一つの結論へ潰さない。
