# X2 ヴェネチア選考（新）8.2
最大の欠陥：#28〜#32が伏線の在庫整理（約15分）。#30はルール違反（便箋の字は肌に戻らない＝手首に戻るのは誤り）＋「丁寧に…モモちゃん。間。それだけ」の3回目は決まり文句。
修正：①#23 カザマに手紙を読み上げさせない→「カザマ、読む。唇が止まる。」モモ「……なんて」カザマ「……君を見てる字だ」（全文は#28でモモが鏡で読む）②#23「名前だけは、書かないでください」と#26「名前は、書かないでって／俺が、書きたかったから」削除→「カザマの手が落ちる。『モモ』。モモ、#2の手首を見る。長い間。いただきます」③#30短縮：大人は出さず、子どもが玄関を開け、モモは封筒を渡して去る。奥から「せんせー、爪切りどこー」。浮いた90秒で#31、熱を失ったカザマがボールペンで「彼女は」と書きかけて止まり、紙を束に挟む。
これだけは：ルールが答えられない問いを一つ残す＝「読むことからなら生まれるのか」。#32のナプキンの一行に想いがあるか映画は判定しない（食べずに畳むは正しい）。#28〜#30の回収を半分に。
