# 第111稿 改稿設計（X71の合議）

## 構造変更
1. 先生との再会（現#14の施設部分）を、#10（ファミレス早朝）の直後に移す。新#11。
   - 同じ日の午後。モモ、遅番の前に施設へ。爪切りを返す。
   - 先生「三人に書いたの」「一人だけに書くのは、ずるいでしょう」「出さなかったから、覚えてるのかもね」。
   - モモ「先生。わたし、あの手紙、食べました」先生（爪切りを止めずに）「……そう。甘かった？」モモ、答えない。「……自分で、切れます」最後の一本を自分で切る。
   - モモの十五年の確信（食べたから嫌われた）が揺らいだまま、夜の301へ。
   - 現#14の前半（アパートでノート「１５」を書く）は第3幕に残す（先生の場面を抜いたあとの#14をアパートだけにする）。
2. 旧#11（301の夜〜明け方）＝新#12。モモが食べる理由を紙の上に書く。
   - 明け方、カザマが置いた一枚を読んだあと、モモ「君が好きだ」を掲げる。
   - モモ「……これも、捨てる分ですか」
   - カザマ、答えない。目を、逸らさない。
   - モモ「……甘いか、知りたいです。先生のは、分からなくなったから」
   - 口を隠さずに食べる。
   - 旧#11の「先生は、もう二度と書きませんでした」「俺は、先生じゃない」は削る（先生の場面を先に見せたので不要）。
3. 旧#12（朝）＝新#13。対決に「味」を足す。
   - カザマ「……どうだった」モモ「甘かったです。先生のより」カザマ「……もう、分からない」。これを「ここが、平らだ」の前後に。
   - 「清掃員は」の三本線は一本にする。ナプキンを裏返す反復は削る。
4. 第3幕の追加：ホテルを辞める代償。旧#16（アパートで余白に書く）の後、結末の前に短い場面。
   - フロント（早朝）。モモ、マスターキーの札と、ロッカーのノート「１」〜「１４」を入れた紙袋。
   - ナツコ、財布から一頁（「ナツコさん　誕生日　ケーキ」）を出す。「これ、味する？」
   - モモ「……しなくても、持っててください」
   - ナツコ「捨てられないもの、あったじゃん」（#3の回収）
5. 結末（ファミレス・月曜の朝）：紙から声へ。
   - カザマが手帳に書く一行が、リサの言う「終わりの一枚」（本の最後の頁）だと分かるようにする（リサ「月曜の昼までに」を受けて、カザマ「……昼までに、渡す」など一言）。
   - 一行「清掃員は、口を隠さずに食べた。俺は、ここで一度、止まった」。
   - モモ、口元まで上げる。止める。
   - カザマ、紙を取り返しかけて、やめる。胸を一度叩いてから、声に出す。
     カザマ「君が食べたあと、ここは平らだった。平らなまま、毎朝来た。……それが、いまの俺の本当だ」
   - モモ、紙を、カザマのほうへ押し戻す。「……これは、本に」
   - カザマ「食べないの」モモ「声は、食べられないので」
   - 光。暗転。二つのペン音。
   - 結末の「わたしは、逸らさなかった」「恥ずかしい味」の再読は、どちらか一つだけにする（旧#16と重複）。
6. 説明台詞を削る：#10「逃げてばっかりだ。母さんからも〜」、リサ「読む人は、欠けたとこに、自分の好きな一行を入れるから」（「そこが、いちばん売れる」で止める）。

## 守ること
- 規則は一つ。新しい超常は足さない。「声は食べられない」は新規則ではなく、字しか食べられないことの帰結として台詞一つで示す（#10の「言うと、わたしが、恥ずかしいです」を活かす）。
- 撮れない内面のト書きは書かない。
- 物の所在（爪切りは新#11で先生に返る。旧#14からは消す）。
- 約130ペラ。
