# 第114稿 改稿設計（X74の合議：カザマの山場を画面の上に）

1. #13（金曜・朝）：対決の締めを台詞から行為へ。
   - 「焼却炉じゃないです」を削る。
   - 流れ：仕掛けの一枚を見つける→「いちばん上にありました」「……置いた」「捨てさせたんですね」「頼んだら、断っただろ」「断りました」「じゃあ、いま、頼んでください。声で」カザマ、口を開く。何も出ない。
   - モモ、その一枚を、口を隠さずに食べる。噛む。
     モモ「……味、しません」
   - カザマ、何も言わない。モモ、出ていく（一時の清掃の約束は残す）。
2. #14を再構成（点描の独り場面を減らし、二人の場面に）：
   - 【一日目】リサの来訪・延長・「再来週の月曜」・廊下で指輪。リサの「あなたの字の中には、いない」は削る。指輪を載せて去るところまで。
   - 【二日目】清掃。「君が好きだ」を書き直した一枚（いまの形を簡潔に）。
   - 【三日目・夜】独りで日記帳を読むくだりを、モモが清掃に来ている場面に移す。夜明けのファミレスの独りのカットは削る。
     カザマ、日記の最後の頁（「涼介」の練習と、丸で囲んだ書き損じ「良介」）を開いて、モモに差し出す。
     カザマ「母さんが、俺を好きだったか。……食べて、教えてくれ」
     モモ、頁を見る。長い間。
     モモ「……あなた宛てじゃないです。それに、本当だったら、消えます。お母さんから」
     モモ、頁を閉じて、返す。
     カザマ、原稿用紙を一枚引き寄せ、書く。モモが見ている前で。
     「母は最後に一度だけ、字を間違えた。間違えた字だけが、丁寧だった」
     書き終える。モモ、読む。食べない。
     カザマ、手の甲に「毎朝　ファミレス　二つ」を書く（ここで、モモの前で）。
   - 【四日目・夜】「全部、食べてくれ／燃やすのと、同じです」は削る。
     モモ「終わりの一枚、いま書いてください。わたしが見てるところで」
     カザマ、一マス目でペンが止まる。インクが一滴落ちる。
     モモ、見届けて、出ていく。
     カザマ、三日目の一枚（母の一行）を、束の最後に重ね、封筒に入れる。宛名はリサの会社。フロントで預けてチェックアウト。
3. #15（カフェ）：リサの警句を削る（「欠けたとこ、あなたが埋めたら〜売れるから」）。十年前の紙切れ「食べて。確かめて」は残す。リサに一度だけ赤ペンを当てさせる：
   リサ「ここ、嘘。味で書いてない。見たことを書いてる」
   モモ「……見たことしか、書けないです」
   （そのあと「名前を出してください」の流れへ）
   #9のリサ「表紙に名前が載るのは、書いた人だけだからね」も削る。
4. #17（フロント）：ナツコの財布の紙の問答を削る。マスターキーの返却、紙袋、「三階、また出なくなるね」だけ。
5. 結末（ファミレス）：
   - 冒頭近くに：
     モモ「わたしの三秒、送りましたね。わたしに聞かないで」
     カザマ「……聞いたら、食べられると思った」
     モモ「食べません。もう」
   - 手帳の一行をちぎる処理はやめる。カザマ、原稿用紙を出し、向かいの席で「終わりの一枚」を書く。インクは落ちない。
     「清掃員は、口を隠さずに食べた。俺は、ここで一度、止まった」
   - カザマ、顔を見る→手の甲→顔（台詞なし）。
   - 紙をモモに渡す。
     カザマ「……読んでくれ。食べないで」
   - モモ、読む。口元へは上げない。ノート「１６」の「ケース３０１」の頁に挟む。
     モモ「……確かめられないです」
     カザマ「うん」
   - 「……好きだ」は削る。光。暗転。二つのペン音。

守ること：規則は一つ（嘘や気持ちのない字は味がしない、を#13で使う）。撮れない内面のト書きを書かない。物の所在を前後でつなぐ（仕掛けの一枚は#13で食べられて無くなる。以後コピーや束に出てこないよう直す）。約128〜132ペラ。
