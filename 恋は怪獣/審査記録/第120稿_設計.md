# 第120稿 改稿設計（X80の合議：#15を短く、真実は「書く」経路で）

1. #15（金曜・朝）を半分にする。
   - 残す：「どうだった／甘かったです。先生のより／……もう、分からない」。三枚のくだり（短く）。紙とペンを引き出しへ（束だけ残す）。カザマ「返せ。……返せないなら、どんな味だったか、全部言え」。モモ「……わたしで、燃やしたんですね」。
   - モモの長台詞は一つに絞る：「十二歳の夜、〜甘かった。熱出したとき誰かがすってくれる、りんごの……すってもらったこと、ないけど」＋「……まだ、いるんです。ここに」。205/212の振り返り、「君が好きだ」の味の比喩（蛇口・ウインナー・お風呂）は削る（→#18の余白へ移す）。
   - カザマの独白（母の額、燃やした匂い、「本当のほう」、「上に置いたの、俺だ」）は全部削る。代わりに行為：カザマ、胸から焦げた紙を出す。裏返す。引き出しから万年筆だけ出す。「愛されたいと思った瞬間、俺は、」まで書く。ペン先が浮いたまま止まる。モモ、それを見る。食べない。
   - そのあと「いま、頼んでください。声で」→「……君が」「……君が、」→仕掛けの一枚を食べて「……味、しません」→紙ナプキンを抜いて出ていく。
2. #11の後（新・約30秒、#12の前）：カザマとリサの電話。
   リサの声「金曜、覚えてる？」
   カザマ「覚えてる」
   リサの声「……いま、止まらなかったね」
   （#10でモモがリサの一行を食べた結果を、ここで効かせる。場面番号を振り直す）
3. #16：【二日目・朝】のひとりのファミレスのカットを削る。「二つ。……二つ、です」は結末の冒頭（店員に頼むカザマ）へ移す。
   【一日目】廊下：指輪を載せたあと、カザマ「……リサ」、リサ「止まったね、いま」を足す（「一行も書かなかったね」〜105の欠けの発覚〜モモの告白〜指輪、の流れは保つ）。
4. #18（コピーの余白）：
   - 番号の飛んでいる頁の空白（仕掛けの一枚／「君が好きだ」を食べたあと）に、モモの字で：「ここに、一枚あった。はじめ、公園の蛇口の味。しょっぱくて。それから、ぬるくて、甘いの」
   - あらすじをなぞる書き込み（「四日目に、カラスを見て、笑った」「頼まれずに、食べた」）は削る。「わたしは、逸らさなかった。三秒。」と最後の「わたしが、食べた。」は残す。
5. #12（ファミレス）の「きれいなのは、だいたい嘘だよ」を削り、行為に：カザマ、焦げた紙をコーヒーの受け皿に伏せる。モモが笑うきっかけは別の小さな行為（伏せた受け皿がかたんと鳴る、など）で。「逃げない練習」も削る。
6. 結末：カザマがコピーの束の余白（公園の蛇口の頁）を読む一拍を入れる（読んで、黙る。台詞で解説しない）。燃えた一行の「本当のほう」は誰にも口で言わせない。

守ること：規則は一つ。撮れない内面のト書きを書かない。物の所在を前後でつなぐ。約128〜132ペラ。
