# 第122稿 改稿設計（X82の合議）

1. 先生の場面（現#13）を#9（リサ来訪・定規の発覚）の直後へ移す（同じ火曜の午後〜夕方）。時系列と曜日の見出しを整える。
   - 先生の場面に一行足す：先生「……出さなかったから、覚えてるのかもね」のあと、
     モモ「……覚えてるのは、字だけですよね」
     先生、答えられない。爪切りの手が止まる。
   - これでモモは「自分が食べたから、先生は自分を好きじゃなくなった」と知ったうえで、その夜（#10）リサの一行を食べ、後に「君が好きだ」を食べる。
2. #14（明け方）：時間の跳躍「✕」を消し、選択を紙の上に書く。
   カザマ、「君が好きだ」を定規でちぎり、黙って差し出す。
   モモ「……約束です」
   カザマ、差し出したまま。
   モモ「食べたら、あなた、わたしのこと、分からなくなります」
   カザマ「……だから、渡してる」
   長い間。モモ、受け取る。口を覆わない。食べる。
3. #15（朝）：「返せ。……返せないなら、どんな味だったか、全部言え」と「知ってました。だから、食べました」を削る。りんごの独白を行為に：モモ、舌の先で、上の歯の裏をなぞる。何かを剥がすように。台詞は「……甘かった」の一言。カザマの「……残るのが、こわかった」は残してよい（単独で）。
4. #12（ファミレス）：カザマの自己解説を削る（「母さんのことを、そう書いた。二百八十枚かけて〜」「嘘だ」「……それを、いい一行にして、燃やした」）。代わりに：カザマ、続きを口にしかける。やめる。焦げた紙を、裏返して受け皿に伏せる（既存の「かたん」へつなぐ）。
5. #7：規則を読み上げる台詞（「俺は、見てるときしか書けない。書いたら、君が食べる。消える。また見る。また書く」「減った分、書く」）を削る。取り決めは「俺は君を見て書く。君は、食べたい行だけ食べる」の一行＋既存の「好きって書いたのは、食べません」で。
6. #11（212の女・一度目）：女の「再来週の月曜の朝、もう一度だけ寄ります」を削り、代わりにメモ用紙に電話番号を書いてナツコに渡して去る。
   #19（月曜・早朝）：モモが自分で電話して呼んだ形に（ト書き一行か冒頭で示す）。対決にする：
   女、頁を読む。「……わたしの字じゃ、ないですね」
   女「味なんか、聞いてない。……返してって、言ったんです」
   モモ「……食べました」
   女、頁をモモの手に押し返して、出ていく。
   （そのあとマスターキー返却「名前を出すので、ここにはいられません」「清掃　一名」へ）

守ること：規則は一つ。撮れない内面のト書きを書かない。物の所在（爪切りは先生の場面で返る→以後の記述を合わせる）。場面番号を振り直す。約126〜132ペラ。
