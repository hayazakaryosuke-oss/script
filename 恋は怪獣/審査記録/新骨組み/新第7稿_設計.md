# 新第7稿 設計（N6を受けて／監督の決定を反映）
決まりは一つ（食べた彼の手書きの字が、彼女の肌に浮かぶ）のまま。

【監督の決定】
- 最後の一文：「愛されたいと思った瞬間、君は　窓のほうを向くのを、やめた。」（#25でモモが打つ。「見返したい」→「見返した」の一字消しの件と、「先生の手紙の言葉をつなぐ」形はやめる）
- 9.5まで続ける。

【N6の一致点】
1. 変身の瞬間を紙に書く（全5人）。#23、噛み跡の場面の直後、廊下のリサへ切る前に、部屋の中を半頁書く。
   - 「モモの歯が、半月の噛み跡の反対側に食い込む。半月が、閉じて、円になる。」（宿の名「ムーンライト」と結ぶ）
   - 「カザマの眼鏡のレンズに、開いていく口が映る。唇の内側の字が、頬の裏へ、喉の奥へ続いている。」
   - 「モモの肩の骨が、シャツの下で一つ、位置を変える。」「口が、レンズに収まりきらなくなる。」
   - 「カザマ、眼鏡に手をやらない。まばたきを、しない。」
   - 影は「壁を上り、天井を這う」を削る（照明任せのため）。看板の消灯は最後の一行だけ残す。
2. #23の詰め込みを減らす（2人）。鏡で背中を読むのは最後の二行だけ（「歯」「粥」「泥棒」の再読は削る）。
3. カザマの罪を背骨に（米・仏）：
   - #19：背中を打つカザマの目が、うなじまで上がる。「『彼女は十二で、先生の手紙を食べた』。指が止まる。……打つ。」観客だけが、カザマがモモの秘密を原稿に打ったと知る。
   - #21：「お母さんに、最後、何て言ったんですか」の後、カザマ「……ありがとう、って」。まばたき、二回。モモ、それを見ている。何も言わない。（#23の「……涼介です」が嘘の訂正になる）。同シーンの「痛いですか／書けるから、いい／指輪は、忘れ物の箱に／うん」は削る（指輪の件は#22で足りる）。
   - #21の「それは、打たないで」とカザマが「先生、」を一字ずつ消す手元は、観客には嘘の芝居として見える（残す）。
   - #23：「打たないでって、言ったのに」「打ってない。……食べさせた」「同じです」の三行を削る。モモは鏡の中で読み、何も言わずに肩紐を戻す。判決は次の行為（束を食べる）で下す。
4. #16：リサが赤ペンのキャップを歯で外し、母の頁に付箋を貼って一字「嘘」と書く。消そうとして、消さない（#23の「嘘」の付箋の仕込み）。尺はコピー機の電源のくだりと相殺。
5. #24：食べ終えたモモの腕の字は「びっしり」ではなく、読める一行を一つだけ見せる：焦げた一行の続きとして、カザマが#23で最後に書いた（モモが食べた）字「愛されたいと思った瞬間、君は、口を開けていた」。#25でモモはそれを打たない。自分の一文（監督の決定）を打つ。
   - そのため#23で、カザマが「君は」の後ろに続きを書く一瞬を入れる（付箋「風間涼介」の前か後。モモは開かずに食べる／観客にも見せない）。
6. 「十二万部刷って、誰の体にも残らなかった。……残ってる」は残す（監督の初稿の芯）。
尺は130〜138ペラ。
