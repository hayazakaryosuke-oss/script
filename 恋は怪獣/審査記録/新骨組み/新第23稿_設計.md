# 新第23稿 設計（N22を受けて）
決まりは一つ。決まりを説明する台詞は足さない。「十二万部刷って、誰の体にも残らなかった。……残ってる」は一字も変えない。案ハ（先生の手紙）と26場の骨組みは変えない。カザマに罪の中身を声で告白させない。「……食べて」は戻さない。凍結：まばたき、奥歯、「どちらさまですか」。

1. #25 リサの入稿を画面の中で決着させる（4人一致。米批評家の案）
   - モモが文庫本の最後の頁を食べ、何も浮かばず、本を返した後：
     リサ、紙袋から、印刷所の名の大判封筒（#14で封をしなかったもの）。写しの最後の頁を抜く。自分の赤字「……ありがとう、と俺は言った。」。
     赤ペンのキャップを、歯で外す。
     その赤字の上に、二重線を引く。（#14で「嘘」の付箋に引きかけて引かなかった二重線を、今度は自分の字に引く）
     頁を封筒に戻す。封をする。
   - 台詞なし。モモは見ている。
   - ＝刷られる本の最後は、線を引かれた嘘の一行。何が刷られるかは言わない。

2. #20 モモの告白を短く、カザマに一行返させる（米批評家・日本女性批評家・日本脚本家）
   - モモ「……違います」
     モモ「うちの子にしたいと、書いてありました。……返事を、しませんでした」（「食べました」「先生は、聞かずに、いなくなりました」は削る）
   - その後、カザマ（一行だけ）：「……俺は、返事をした。違う返事を」
     （母に「どちらさまですか」と返したこと。中身は言わない）
   - リサ、二人を見る。

3. #19 モモの「……わたしの話なのに、味がしない」を削る（決まりを口で説明している。米批評家）。

4. #24 文庫本を祭壇に置くくだりと、腕時計の「九時を、過ぎている」を削る（米批評家）。文庫本は#25で初めて出す（リサの紙袋から）。眼鏡は遺影の前に置く（文庫本の横、ではなく）。

5. 尺：130〜138ペラ。26場のまま。
