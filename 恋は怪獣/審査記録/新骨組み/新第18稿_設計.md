# 新第18稿 設計（N17を受けて・告白は一度／「さがさないでね」をクライマックスへ／閉じすぎを減らす）
決まりは一つ（食べた彼の手書きの字が、彼女の肌に浮かぶ）のまま。決まりを説明する台詞・新しい決まりは足さない。
変えないもの：#15の反転、#16の文庫本と「嘘」、#21の「はい」、#23の削除、#23を二場に割った構成（#23リサがいる／#24未明の二人）、「モモへ」、変身の書き切り、祭壇の場、「十二万部…残ってる」、#27の「涼介へ／さがさない。ここに、いる。」。「……食べて」は戻さない。

1. #23 告白を一度にする（韓国・フランス・英国・メキシコ）
   - うなじの「母に噛まれて、手を引いた。それきり、行かなかった」をト書きで見せる行を削る。うなじの一行は、観客にも最後まで読めない字として残す（#19で読まない、#20でナツコが読まない、#23でカザマが「読まない。書いたの、俺だから」）。
   - 告白は、余白に書く「ありがとうは、言ってない」→モモが食べる→首に浮く→リサが読む、の一度だけ。
   - ※#13の隠し書き二行の中身は、脚本の中で全文を出さなくてよい（「その下の二行は、左手で隠して書く」のまま）。#19の「彼女は十二で、先生の手紙を食べた」は#19・#20で見せてよい。母の一行は全編を通して全文を出さない。

2. まばたきの合図を減らす（韓国・英国・メキシコ）
   - #21：「……ありがとう、って」の後の「カザマ、まばたき。二回。」を削る。モモが横顔を見ている、は残してよい。
   - #13：「まばたきは、しない」（先生の不在を言うモモ）を削る。#3の仕込みと#13のモモの「忘れました」の二回だけ残す。

3. 「さがさないでね」をクライマックスへ（韓国・イスラエル。英国・メキシコも#24で明かす方向）
   - #17：封筒を裏返す→「……指が、止まる。」で切る。閉じ口の字は見せない。口に運びかけて、やめる。ポケットへ。
   - #24：モモが封筒を差し出す→カザマ、受け取って、裏返す。閉じ口に、丸い、大人の字。「さがさないでね」。カザマ、モモを見る。モモ、目を逸らさない。
     → カザマは「モモへ」と最後の一行を書き、その封筒に入れて差し出す（「モモへ」が閉じ口への返事になる）。モモ、封筒から出して、開いて、読む。「……いただきます」。
   - 台詞でモモに言わせない（声で言う案は採らない）。

4. #24 カザマが一度だけ手を引き、選び直す（フランス）
   - 口の中へ入っていく途中：「カザマの腕が、一度、引かれる。……止まる。自分で、もう一度、差し入れる。」

5. 閉じすぎを減らす（フランス・英国・メキシコ）
   - #13：「十二の子に、それ書く大人は、先生じゃないよ」を削る（先生を脚本が裁かない）。「カザマの笑いが、消える。／間。／モモ『……おいしかったんです』」に。
   - #25（朝）：前半の目録（シーツの染み〜「書いた原稿は、一枚もない」、歯・爪・腕の字の描写の重複）を削り、左手の甲の「モモへ」、眼鏡・紙片・封筒を拾う、電話へ直行。
   - #26：「……来たんだ」を削り、リサが遺影の前の眼鏡の外を向いたつるを、指で内側に戻す（イスラエル）。モモの「……風間の、家の者です」は、リサの所作の後に置くか、なくしてもよい（脚本家判断。台詞ゼロの場にしてもよい）。
   - #27：表紙「モモ」を印字するくだりを削る（終わりを減らす）。「涼介へ／さがさない。ここに、いる。」を保存・印字し、二つに折って封筒に入れる。窓の前。どしん、を身体とつなぐ（メキシコ）：「モモ、両手を、みぞおちに当てる。／どしん。／手のひらの下で、もう一度。どしん。」（#1の「……あったかい」でみぞおちに手を当てた所作の回収）。「どしん」の台詞化はしない。

6. 尺：130〜138ペラ。シーン数は27のまま。
