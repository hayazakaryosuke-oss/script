# 新第8稿 設計（N7を受けて・骨組みを一段変える）
決まりは一つ（食べた彼の手書きの字が、彼女の肌に浮かぶ）のまま。決まりを説明する台詞は足さない。
最後の一文は監督決定「愛されたいと思った瞬間、君は　窓のほうを向くのを、やめた。」を変えない。
「十二万部刷って、誰の体にも残らなかった。……残ってる」も残す。

【骨組みの変更：「差し出される女」→「知ったうえで、拒まれて、奪う女」】
N7全5人一致：モモは一度も許可なしに食べていない。#23の変身が「……食べて」＝男の許可で始まる。
→ 三つの段で、主導権をモモに移す。

1. 発覚を#20に前倒し（英）
   - #20 ナツコが背中を読む。「母の歯も、小さかった」の後、うなじの一行も読んでしまう：
     ナツコ「……『彼女は十二で、先生の手紙を食べた』」
     モモ、動かない。ナツコ「……これ、あんたのこと？」モモ「……」（答えない）
   - モモは自分の背中を見られない。他人に読まれて、何を書かれたかを知る。#20の締め「わたしが入ります」「だろうね」は残す。
   - #23の鏡の場面は「発見」でなくなる → 鏡で読む二行は削る（うなじの一行は#20で済んでいる。母の一行は#23では出さない）。鏡の場面ごと削ってよい。

2. #21 中盤の衝突（ブラジル・香港・日本）
   - モモは知っている。そのうえで「……一枚、ください」「これは、食べちゃだめなやつ」。
   - モモ、カザマが席を立った隙に（トイレ／インク瓶を取りに）、印字した山の中ほどから一枚を抜いて食べる（許可なしの初めての摂食）。印字の字。肌には何も浮かばない。
     モモ「……わたしの話なのに、味がしない」（香港）
     ト書きで、その頁に同じ一行がすでに刷られていると見せる（英(3)）：抜いた頁に「彼女は十二で、先生の手紙を食べた」。
   - 戻ったカザマ、山の欠けに気づく。何も言わない。（または「……何枚目」と数える）
   - 「……お母さんに、最後、何て言ったんですか」「……ありがとう、って」の後の「まばたき。二回。」は削る（日本）。
   - 「それは、打たないで」は、彼を試す台詞になる（もう刷られているのを、モモは知っている）。カザマ「先生、」を一字ずつ消す → モモ、それを見ている。刷られた山を見る。何も言わない。
   - 尺は、「あなたの目が好きです…見返したい」の二往復のどちらかを刈って相殺してよい（ただし「先生の手紙の言葉が画面に打たれる」流れは残す）。

3. #23 カザマが拒み、モモが奪う（全5人）
   - 冒頭の鏡の場面を削る（#20で発覚済み）。「どちらさまですか／……涼介です」は残す。置き場所は、モモが万年筆を取る前。
   - リサの束：カザマがリサから受け取ってモモに差し出す流れをやめる。
     カザマ、リサの束に手を伸ばす → 止める。「……これだけは、刷りたい」（母の頁の付箋のところに、手を置く）。
     モモ、リサの胸から束を取る。リサの指が一度、離さない。……離す。リサ「それ、わたしの十年だよ」 モモ「……知ってます」（旧カザマの「知ってる」をモモへ）
   - 付箋を並べる（「嘘」）。「母」の頁でカザマの手が伸びる。止まる。下ろさない。モモ、その頁から先に食べる。
     モモ（「嘘」の付箋を見て）「……嘘って、どこですか」 リサ「『ありがとう』」（一語だけ。十年前云々の説明は入れない）。カザマ、まばたきをしない。
   - 頁番号のモンタージュ「１０。３０。６０。１０８。」を削る（日本）。
   - カザマが「君は」の裏に続きを書いて畳む → これは残す（#24の右肘の一行のため）。ただしカザマが差し出すのでなく、畳んで胸ポケットに入れようとする。モモが手首を掴んで取る。開かずに食べる。
   - 付箋「風間涼介」：カザマが自分で書く。だが最後に名前を惜しみ、指を一度引く（日本）。「これも。ぜんぶ、って言ったよね」「……食べて」は削る。
     モモは離さない。目を開けたまま、自分で食べる。
   - 「まずい？／まずいのがいい」は削る（回収の積みすぎ・2人）。
   - 噛み跡の円、変身の描写（レンズ・口・顎・肩・背骨・指）、リサが音を聞いて去る、看板が消える、どしん — は残す。
     ただし噛み跡に口を当てるのもモモから（カザマが手を差し出す、を削り、モモが手首を取って包帯をほどく）。
   - 「……まだ、見える？」「見てる」は残す（「見てて」の回収）。

4. #14「食べると、いなくなるので」は残す（#23でモモが引き受ける言葉に反転する）。
