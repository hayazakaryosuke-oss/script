# 新第17稿 設計（N16を受けて・#23を二つに割る／告白を字で／封筒で往復書簡）
決まりは一つ（食べた彼の手書きの字が、彼女の肌に浮かぶ）のまま。決まりを説明する台詞・新しい決まりは足さない。
変えないもの：#15の反転、#16の文庫本と「嘘」、#21の「はい」、削除、「モモへ」、変身の書き切り、「十二万部…残ってる」、#24の変わった体、祭壇の場、#26の「涼介へ／さがさない。ここに、いる。」。「……食べて」は戻さない。

1. #23を二つに割る（韓国批評家。5人全員が過積載を指摘）
   ■#23A「３０１号室（金曜・前夜）」：リサがいる場
   - リサの赤ペン、束、クリップ、「母」の頁を隠さず食べる、は残す。
   - 告白を台詞から字へ（韓国批評家・仏・日本女性P）：
     「読んで。そこだけ、打たなかったとこ」→カザマ「……読まない。書いたの、俺だから」→（ここまで残す）
     その後、カザマは口で言わない。「嘘」の付箋の貼られた「母」の頁の余白に、万年筆で一行書く：「ありがとうは、言ってない」
     モモ、それを隠さず食べる。首筋に、その字が浮く。
     リサ、それを読む（#15で拭いても消えなかった首と対）。氷を一つ口に入れて、噛まない。出ていく。
     ＝リサの退場が「読んだ結果」になる。
   - 母の一行「母に噛まれて、手を引いた。それきり、行かなかった」は、台詞ではなく、この直前にカザマが「読まない」と言ったうなじの行として残る（観客には#26まで全文を出さなくてもよいし、#23Aでカザマが一度だけ声に出してもよい。脚本家判断。ただし台詞は最小限）。
   - 削除の「はい」はリサの前で。
   - モモの「……じゃあ、交換」「先生、さがさないでね、って書いてた」は削る（仏・韓国：台詞で明かさない）。
   ■#23B「同・３０１号室（金曜・未明）」：二人だけの短い場
   - 付箋もリサもいない部屋。
   - モモ、パーカーのポケットから黄ばんだ封筒「モモちゃんへ」を出す（#17の末尾に「封筒を、パーカーのポケットへ」を足す）。差し出す。（イスラエル）
   - カザマ、「君は」の頁のいちばん上に「モモへ」、行頭に最後の一行。二つに折る。封筒に入れる。
   - モモ、封筒から出して、初めて開いて、読む。「……いただきます」。紙ごと、指ごと。
   - 噛み跡が円になる、変身の書き切り、看板、どしんは、この#23Bに。
   - #23Bは静かに、短く。回収を足さない。

2. 先生の手紙の最後の行（「さがさないでね」）は台詞で言わない。封筒の裏で見せる（仏・韓国の「言うな」とイスラエル・日本批評家の「行為で」の両立）
   - #1：少女が便箋を読み、食べる。封筒はパジャマの中へ。その封筒の裏、閉じ口に、大人の丸い字で一行あることは#1では見せない。
   - #17：引き出しから出てきた封筒を、モモが裏返す。閉じ口に「さがさないでね」。口に運びかけて、やめる。（モモ自身の行為で観客に初めて明かす。中盤の後半でモモ側の秘密が出る）
   - #23Bで、その封筒にカザマの手紙が入る。#26で、モモの「涼介へ」の一枚もその封筒に入る（日本批評家）。
   - ※#1の「最後の行で、止まる」と整合させる（便箋の最後の行で止まる→封筒の裏にも同じ言葉、でよい。あるいは便箋の最後の行＝封筒の閉じ口の一行、と読めるように）。

3. #25 祭壇の場（4人一致＋α）
   - モモの「……さがしに、じゃないです」を削る。
   - リサ「……来たんだ」に、モモ「……風間の、家の者です」（日本女性P）。→#24の電話のモモの台詞は「……はい。……どちらに、伺えば」に。
   - リサ、パイプ椅子の上のバッグを膝に移す。隣の席が空く。モモ、座る。最前列に二人（日本批評家）。
   - リサが焼香台の脇に置くのは、古い「君は」の一枚ではなく、十二万部の文庫本（韓国批評家）。モモ、文庫本を見る。印刷の字。食べない。→#23でリサが古い「君は」の一枚をバッグにしまうくだりは削る（#22・#23の束の整合を取る）。
   - 眼鏡を遺影の前に置く、は残す。

4. #21 カザマの転換の芽（日本女性P）
   - リサの電話を切った後：カザマ、伏せた原稿用紙の山から一枚を取り、振り向かずに後ろへ差し出す（#12と同じ動作）。モモ、受け取る。食べずに、膝に置く。
   - 尺は#19「右の小指に通す。第一関節で止まる」を削って相殺してよい。

5. リサの説明台詞を削る：#22「あの一行、書いたとき、わたし、嬉しかったんだよ」（イスラエル・仏）。#22は氷の音で終える。

6. #26：印字した「涼介へ」の一枚を二つに折り、「モモちゃんへ」の封筒に入れる（封筒は#23Bの後どうなったか整合：モモが食べたのは中身の紙で、封筒は残る）。最後の一行は「涼介へ／さがさない。ここに、いる。」のまま。
