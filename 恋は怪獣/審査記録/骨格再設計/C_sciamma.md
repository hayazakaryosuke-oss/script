# 骨格案C（シアマ／濱口級）「気持ちを食べる」
核：恋人の体でなく、恋人が自分を好きな「気持ち」を食べてしまった女が、それを一字ずつ写して返し、怪獣から書き手になる。
ルール追加：食べると、書いた人からその気持ち（好きの熱）が消える。出来事は覚えている（読んだ本みたいに）。十二のとき、あの人は次の面談で初めて会う子を見る目をした。
#27 ワンカットで「モモ」まですくう。体は一口も食べない。カザマの目から見る熱だけが引く。
#28 早朝 カザマ「……清掃の方ですか」モモ「……はい。失礼します」。リサが連れ帰る。ナツコ解雇、眼鏡を忘れ物ボックス「三ヶ月」。
#29 マンションの窓、二人が校正。入らない。影が人の形を失う。
#30 紙の119枚を写す、肌の数十行は写さない（写せば今の暮らしを壊す）。黒い小指の爪。
#31 カフェ：リサ「出す。あの人の文章を、あなたの名前で」。著者名。自分の名を書けば鎖骨の「モモ」が彼の鎖骨へ戻る。書く。
#32 カザマ洗面台の鏡、鎖骨に自分の筆跡の「モモ」、覚えはない。表紙「恋は怪獣　モモ」。「……モモ」。
弱点：エターナル・サンシャイン型の記憶喪失に見える→熱だけが消える、に限定。
