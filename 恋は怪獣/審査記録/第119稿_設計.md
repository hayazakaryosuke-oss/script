# 第119稿 改稿設計（X79の合議）

1. #15（金曜・朝）を、この映画でいちばん長い場面（6〜7ペラ）に作り直す。紙とペンを使わない声の対決。
   - 冒頭：「どうだった／甘かったです。先生のより／……もう、分からない」は残す。書き直す「君が好きだ」三枚のくだりは短くし、そのあとカザマは原稿用紙と万年筆を引き出しにしまう（部屋から紙とペンが消える）。
   - カザマ「返せ。……返せないなら、どんな味だったか、全部言え」
   - モモ（口を隠さない）「あなたが上に置いたんです。食べさせたかったのは、あなたです。……わたしを、一斗缶にしましたね」
   - モモが途切れずに話す（十行以上、口を隠さずに）：十二歳の夜、職員室の懐中電灯、先生の手紙を口に入れたこと、翌週の同じ目、見られなかったこと、他人の本当を食べて生きてきたこと、自分宛ての本当を食べてしまったこと、「君が好きだ」がどんな味だったか。説明調にしない。具体の物と感覚で。
   - カザマが話す（美しくない言葉で、言い損じながら）：母のこと、額ではなく手の甲、燃やした二百八十枚、「嘘だ」と言った一行の本当、リサからも逃げてきたこと。警句にしない。
   - モモ「いま、頼んでください。声で」
   - カザマ「……君が」間。「……君が、」（声が出ない）
   - モモ、束のいちばん上の仕掛けの一枚を取る。口を隠さずに食べる。「……味、しません」。出ていく（紙ナプキンを抜く一行は残す）。
   - 尺：#16【二日目】の音読（「二度目は、平らだ」）を削る。
2. #16：
   - 【二日目】の代わりに短いカット：翌朝のファミレス。カザマ一人。二皿を頼み、冷めた二皿の前で手の甲を見る。「二つ。……二つ、です」（まだ手の甲に字は無い／あるなら#16三日目より前にしない。整合をとること）
   - 【三日目】日記帳の場面：モモ（清掃中）が、#8で食べた一行の味を言う。
     モモ「……噛まれたとき、あなた、お母さんを、知らない人の目で見てた。……そういう味でした」
     カザマ、日記の丸を見る。（食べた者が、書いた者の失った気持ちを味として持っている、を一度だけ示す）
3. 本部の監査の筋を削る。
   - #11 ナツコ：「記録、残るんだよ。……わたしは、読まない」
   - #19：ナツコの札を押し戻すやりとりを外す。モモ「名前を出すので、ここにはいられません」。ナツコ、札を受け取る。台帳に一行書く。「清掃　一名」。ペンが止まる。モモ、会釈する。
   - ２１２の女の再訪（「わたしの字じゃ、ないですね」）は残す。「再来週の月曜」の重なりが不自然にならないよう、女の再訪理由は#11の台詞のまま。
4. 結末：カザマが書く「終わりの一枚」と、それを押し返すくだりを削る。カザマ、万年筆のキャップを外しかけて、置く。モモ「……声で」→ 顔・手の甲・顔 → 「好きかどうか、もう分からない。分からないまま、明日も、二つ頼む。……来てくれ」「……頼まれました」→光→暗転→二つのペン音。

守ること：規則は一つ（気持ちは書いた人から消え、食べた人は味としてそれを知る）。撮れない内面のト書きを書かない。物の所在を前後でつなぐ。約130〜135ペラ。
