# 『恋は怪獣』壁打ち・第3回（第24稿を読んで）

## 1. 診断：骨は通ったのに、なぜ初読が下がるのか

先に結論。**私の原理は「見る」だったが、脚本が実装したのは「言う」と「並ぶ」だった。** 被害者を見るとは、相手のために、あるいは相手に逆らって、自分の持ち物を手放すことだ。第24稿でモモがしたのは、リサの背中を見ること（#21）と、控室で真相を口にすること（#25）。カザマがしたのは削除ボタン（#21）。どちらも何も失っていない。リサは#14で写しを作っているから削除は身振りで、モモは秘密を言うが束は全部食べる。手放したのはリサだけだ（自分の赤字に二重線、十年）。第24稿で選択をしている人物はリサ一人で、審査員が「リサがいちばん生きている」と書くのは当然だ。

初読が下がった理由は三つ。
- **情報量が増えて、山場が謎解きになった。** 案ハで「先生の手紙」「うなじの誤読」「母の嘘」「誰が最後の一行を書いたか」の四つの伏せ札ができ、#17・#20・#22・#25の四か所で順に開く。初読者は感じる前に解く。再読者は解けているから+0.3。この差がそのまま点差になっている。
- **モモの反転を、モモが台詞で報告している。** #20「違います」までは身体で語り、その先を四文の説明（#25）で処理した。批評家の言う「自分の方法を手放している」は正しい。
- **リサに許可を出させた。** #21「それは、あなたの十年じゃないもんね」でカザマの唯一の選択が、許可後の動作になった。

ただし良い兆候が一つある。N13以前は装置の要求（地下室、取調べ）が散っていたが、N22〜24の五人の初読者は同じ三点を指している（#20の説明台詞、#21の無代価、入稿の行方が不明）。問題が局所化した。骨は通り、肉の付け方を間違えている。

## 2. 振り子への裁定（以後凍結）

**① 手紙の中身をどこで出すか → #1で観客にだけ見せる。#20は「違います」の一言、#25の台詞は削る。**
理由：この映画の力は「観客が人物より先に知っている」ときに出る（#8の薄目、#19の消す／打ち直す）。#1で便箋の折り目に「うちの子に」の四字を見せれば、#12「忘れました」のまばたきは謎ではなく嘘として見え、#17の誤読は観客だけが誤読と分かる。中盤が全部「知ったうえで見る」場面に変わり、#20は謎解きでなく選択の場になる。#20か#25かの二択は、両方はずれ。

**② うなじの誤読を#17で見せるか → 見せる（第24稿のまま）。**
理由：伏せれば#20がまた開示の場になる。見せれば、#19でモモが「先生」の行を消す動作に理由が立ち、初読者は「彼は彼女を間違って刷ろうとしている」と分かって#20に入る。

**③ カザマの声の告白 → 声では言わせない。ただし、母への本当の最後の言葉を、自分の手で、本の最後の一行として書き、リサに渡す。**
理由：この映画で告白の媒体は字で、告白の証人は「読む人」だ。声で言えば方法を裏切り、紙に伏せてモモが食べれば恋の中に消える（スウェーデンの指摘どおり）。第三の道は、本の結末として書き、世に出す側の人間に渡すこと。これで告白は公的になり、代価（本の売れ行き、リサの次）が生じ、声を使わない。「言わせろ」派の要求の中身（罪を自分で引き受ける）を満たしつつ、「削れ」派の理由（文体）も守れる。

## 3. 第25稿の変更（効く順、最大5つ）

**(1) #20〜21を「最後の一行を誰が書くか」の三人の場面に組み直す。**
削る：削除ボタンの芝居、「それは、あなたの十年じゃないもんね」、リサが「嘘」の付箋を万年筆の横に貼る動作、リサの「赤字は付箋にした」の説明。
入れる：リサがうなじを読む→モモ「……違います。返事を、しなかっただけです」→カザマ、万年筆を取り、「君は」の一枚の余白ではなく、新しい原稿用紙に書く。
　「愛されたいと思った瞬間、君は」
　その下、行頭。左手は隠さない。
　「どちらさまですか、と俺は言った。」
　リサに差し出す。
リサ「……これ、刷ったら。あなたの次は、ない」
カザマ「うん」
リサ「わたしの次も」
カザマ「……うん」
　リサ、受け取る。束の最後に重ねる。クリップ。何も言わずに出る。
ここでカザマは本を失い、リサは自分の十年（自分が書いた「ありがとう」）を否定される。二人が代価を払う。

**(2) #21後半：モモが束を食べない。**
削る：束と写しを全部食べる長い一連。
入れる：リサが出たあと、ベッドに残った「背中の頁」（彼女について書かれた数枚）を、モモが揃える。廊下へ出る。ドアに背をつけているリサの紙袋に、黙って差し込む。戻る。何も食べない。カザマ「……食べないの」モモ「……わたし宛てじゃないので」。
これが「被害者を見る」の実装で、宛名の主題が初めて行動になる。モモの飢えは#22まで持ち越され、変身の欲求が上がる。#22で彼が「モモへ」を書く動機も、ここで立つ。

**(3) #25を無言にし、刷られた頁を見せる。**
削る：モモの台詞「先生の手紙。……」全部。古い文庫本。リサの二重線。
入れる：リサ、印刷所の封筒から校了紙を一枚。最後の頁。
　「愛されたいと思った瞬間、君は」
　「どちらさまですか、と俺は言った。」印字。
　モモ、破って食べる。何も浮かばない。本を閉じてリサに返す。
リサの選択（嘘を刷らない）が紙の上で見え、印字が体に残らないことで「残ってる」が映像で証明される。台詞ゼロ。

**(4) カザマとリサの二人だけの場面を半頁、#13と#16の間に置く。**
料亭の廊下。リサ、カザマの薬指を見る。
リサ「あのときの最後の一行、わたしが書いたね」
カザマ「……知ってる」
リサ「今度は、書かない」
これで#14の赤字とゲラの説明的な小道具（「嘘」の付箋も含む）を半分に削れる。尺は#7と#15の隣人マリ／ユウタを切って作る（壁の音はテレビで足りる）。

**(5) 締めの小道具を三つ減らす。**
削る：奥歯（#18と#26の両方）、#26の「文書がありません」、#26で焦げた紙片を開く動作、#17の「母の歯も、小さかった」、#11の「母は風呂場で、俺の手を噛んだ」（噛み跡の由来は「母親の」の一言で足りる）。
残す：#26は「涼介へ」「はい」→印字→封筒→窓→どしん、だけ。

## 4. 正直な見立て

上の5つで、初読は8.7〜8.9に届くと見る。9.0を出す初読者は一人か二人出る。平均9.0を超えるかは五分。**平均9.5は、この物差しでは届かない。** 理由は脚本の欠陥ではなく、物差しと作品の価値観が一点で衝突しているからだ。三作はどれも「言わずにいた人が、最後に言う」映画で、審査員はその決壊を9点台の条件にしている。本作は「言わないまま、体に残る」映画で、言わせた瞬間に方法が崩れる（N22の批評家がそう書いた）。(1)の「書いて渡す」はこの矛盾を最も薄める解だが、消しはしない。五人平均という採点法も、割れる作品に不利なまま残る。

あと何が起きれば9.0を超えるか。起きるべきことは一つで、**この映画が「最後の一行を三人で争う作者性の映画」として読めること**だ。(1)〜(3)はそのためにある。これ以上の大手術（案A、ナツコ軸）はやらない。第25稿が8.7以上なら、第26稿は細部の凍結解除ではなく削るだけにして止める。8.5以下なら、この物差しの天井と認め、監督に報告する。

## 5. 監督への問い

**カザマは、食べられる前に、自分の意志で何を失いますか。**
今の答えは「何も」で、だから彼は最後まで見る人で終わり、変身は起きた出来事にしかならない。答えが「本」なら(1)が書ける。答えが「失わせたくない」なら、この映画はカザマの話ではなく、モモとリサが一人の男の字を分け合う話として組み直すべきで、それはそれで撮れる映画だ。どちらかを、監督が決めてください。
