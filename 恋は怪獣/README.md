## 骨格（第15稿で作り直した規則）

1. 想いのある手書きの字だけが、モモの肌に浮かぶ。食べると、書いた人の「熱」が消える。記憶は残る。
2. また見れば、熱は生まれうる。ただし名前を含む字を食べられているあいだは、その人への熱は生まれない。モモが書き写すと名前の字だけ戻る。熱は戻らないが、もう一度見れば新しく生まれうる。
3. モモが書き写すと、書いた人が生きていれば字と熱が返る。
4. その場で食べれば飢えは鎮まる。溜めてから食べるとあふれて怪獣になる。溜めた字はインクになって血に混じる。
